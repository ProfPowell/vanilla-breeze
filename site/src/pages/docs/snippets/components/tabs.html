Tabs

Tab interface examples using tab-set with native details/summary. Progressive enhancement with native semantics and keyboard navigation.

Overview

The tabs component uses the <tab-set> web component built on native HTML <details> and <summary> elements with the name attribute for exclusive behavior. Progressive enhancement: tabs work without JavaScript.

Key features:

  • Progressive enhancement with native details/summary
  • Horizontal and vertical orientations; horizontal tabs wrap on narrow screens
  • Support for icons and badges in tab labels
  • Native button semantics with aria-expanded, aria-controls and named <section> panels
  • Keyboard navigation with arrow keys (mirrored in right-to-left text)

Basic Tabs

A simple horizontal tab interface. The name attribute groups the details elements for exclusive behavior.

 <tab-set aria-label="Content tabs"> <details name="basic-tabs" open> <summary>Tab One</summary> <section> <p>Content for the first tab panel.</p> </section> </details> <details name="basic-tabs"> <summary>Tab Two</summary> <section> <p>Content for the second tab panel.</p> </section> </details> <details name="basic-tabs"> <summary>Tab Three</summary> <section> <p>Content for the third tab panel.</p> </section> </details> </tab-set>

Tabs with Icons

Add icons alongside tab labels for visual context. Use <icon-wc> inside the summary element.

 <tab-set aria-label="Feature tabs"> <details name="icon-tabs" open> <summary> <icon-wc name="home" size="sm"></icon-wc> Home </summary> <section> <p>Main dashboard content goes here.</p> </section> </details> <details name="icon-tabs"> <summary> <icon-wc name="settings" size="sm"></icon-wc> Settings </summary> <section> <p>Configure your preferences.</p> </section> </details> </tab-set>

Vertical Tabs

Add data-orientation="vertical" for a sidebar-style tab layout: tabs in a column at the inline start, the panel beside them, and ArrowUp/ArrowDown to move between tabs.

 <tab-set aria-label="Account settings" data-orientation="vertical"> <details name="vertical-tabs" open> <summary>General</summary> <section> <p>General settings and preferences.</p> </section> </details> <details name="vertical-tabs"> <summary>Security</summary> <section> <p>Security and privacy options.</p> </section> </details> <details name="vertical-tabs"> <summary>Notifications</summary> <section> <p>Notification preferences.</p> </section> </details> </tab-set>

Configuration

The <tab-set> element accepts these attributes:
Attribute Values Description
aria-label String Names the set. A labelled tab-set gets role="group" so the name is announced.
data-orientation horizontal vertical Tab layout direction. Default is horizontal.

Details Element

Each tab panel uses a <details> element:
Attribute Values Description
name String Groups details elements for exclusive behavior (recommended for the no-JS accordion; on upgrade a missing or page-shared name is replaced with a unique one).
open Boolean (presence) Sets the initially selected tab.

Usage Notes

  • Name attribute: All details elements in a tab group should share one name value, unique on the page
  • Panels: One <section> panel per details element, after the summary
  • Initial selection: Add open to one details element to set the default tab
  • Accessibility: Provide an aria-label on the tab-set element; it becomes a named group
  • Badges: Add <span class="badge"> inside summary for notification counts
  • Keyboard: Use arrow keys to navigate between tabs when focused
