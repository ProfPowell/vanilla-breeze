The approach

Each layout does one job. A stack puts things in a column with even gaps. A grid makes as many equal columns as fit. A sidebar puts a narrow column beside a wide one. You build a page by nesting them: a grid of cards inside a stack inside a sidebar.

The layouts are CSS only. They need no script and no breakpoints of your own: most of them wrap or stack when their own space runs out, so the same markup works in a full-width page and in a narrow column.

Every layout can be written two ways. As an element, <layout-stack>, when you need a wrapper. As an attribute, data-layout="stack", on an element you already have. Both use the same rules and take the same modifiers.

Three more elements share the layout- prefix but give a surface and not an arrangement: <layout-card> (a padded box with a background), <layout-canvas> (a raised sheet for page content) and <layout-badge> (a small status chip). Put them inside the layouts above.

Close calls

  • Grid or switcher. A grid drops one column at a time as it narrows, so three cards become two and one. A switcher never does that: its children are all in one row or all stacked. Use a switcher for a small, fixed number of things that belong together.
  • Grid or cluster. Grid children are all the same width. Cluster children keep the width of their content.
  • Cluster or reel. A cluster wraps onto a new line. A reel stays on one line and scrolls.
  • Sidebar or page layout. data-page-layout places the page regions (header, nav, main, aside, footer) and goes on <body>. <layout-sidebar> is for two columns anywhere below that.
  • Center or text. Center caps the width of a block of mixed content and centers it. Text caps the width in characters for reading and spaces headings and paragraphs. Content width compares them.
  • Imposter or dialog. An imposter only positions. It does not trap focus or close on Escape. For anything a reader interacts with as a modal, use <dialog>.

Modifiers

A layout is adjusted with data-layout-* attributes on the same element. The names are shared: data-layout-gap means the same thing on a stack, a grid and a sidebar.

data-layout-nowrapStops the layout wrapping or stackingCluster, sidebar, split, page layouts

A modifier applies only to the element it is on. A grid nested in a grid with data-layout-gap="3xl" still gets the default gap. The data-layout reference lists every modifier and value.
