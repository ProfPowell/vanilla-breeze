How every tutorial is structured

The same four layers, in the same order. Each layer is optional: a page stops at the last one it needs, and the landing page stops at the third.

  1. Semantic HTML. Write the content with native elements such as <header>, <section>, <form> and <table>. With the stylesheet linked, this already reads as a finished document.
  2. Layout attributes. Add data-layout and its modifiers to the elements you already have. No wrapper elements and no utility classes.
  3. Custom elements. Use CSS-only elements such as <layout-card> and <form-field> where a part of the page needs a shape or a structure an attribute can't give it.
  4. Web components. Add <data-table>, <chart-wc> or <toast-msg> only where the page needs behavior that HTML and CSS can't provide. The page still works when the script doesn't load.

Before you start

You need a text editor and a browser. There is nothing to install and no build step: each tutorial starts from one HTML file that links the Vanilla Breeze stylesheet. If you haven't used Vanilla Breeze before, the Quick Start covers the same ground on a single page in ten minutes.
