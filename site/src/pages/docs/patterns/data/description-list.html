Overview

Description lists provide a structured way to present pairs of labels and values. Using the semantic <dl>, <dt>, and <dd> elements ensures proper accessibility and document structure while providing flexibility for visual styling.

Key features:

  • Semantic HTML for accessibility and SEO
  • Flexible layouts: vertical stacking or horizontal rows
  • Grouped sections for organized data presentation
  • Consistent styling with muted labels and clear values
  • Responsive design that adapts to screen size
  • Uses @scope for encapsulated, semantic CSS selectors

Simple Vertical Layout

A basic vertical description list with terms stacked above their descriptions, using data-variant="stacked". The <dl-item> custom element groups each <dt>/<dd> pair.

 <dl data-variant="stacked"> <dl-item> <dt>Full Name</dt> <dd>Alexandra Chen</dd> </dl-item> <dl-item> <dt>Email Address</dt> <dd>alexandra.chen@example.com</dd> </dl-item> <dl-item> <dt>Phone Number</dt> <dd>+1 (555) 123-4567</dd> </dl-item> <dl-item> <dt>Status</dt> <dd> <layout-badge data-color="success" data-variant="subtle" data-size="l">Active</layout-badge> </dd> </dl-item> </dl>

No custom CSS: data-variant="stacked" mutes and shrinks each <dt>, drops the <dd> indent and spaces the groups.

Horizontal Layout

A horizontal layout with labels on the left and values on the right. This format works well for detail panels, settings pages, and profile information where you want to scan labels quickly.

 <dl data-variant="horizontal" data-bordered> <dl-item> <dt>Full Name</dt> <dd>Alexandra Chen</dd> </dl-item> <dl-item> <dt>Email</dt> <dd>alexandra.chen@example.com</dd> </dl-item> <dl-item> <dt>Phone</dt> <dd>+1 (555) 123-4567</dd> </dl-item> <dl-item> <dt>Status</dt> <dd> <layout-badge data-color="success" data-variant="subtle" data-size="l">Active</layout-badge> </dd> </dl-item> </dl>

No custom CSS: data-variant="horizontal" puts terms and descriptions in two columns that line up across every row (each <dl-item> is a subgrid), and falls back to a stacked flow below 16rem of available width. data-bordered draws the row separators; swap it for data-striped to alternate row backgrounds, or add data-density="compact" for dense data.

Grouped Sections

Multiple description lists organized into logical sections with headings. Each section is a <layout-card> whose <header> child gives it a divided title bar. Ideal for profile pages, order details, or settings displays.

 <layout-stack data-layout-gap="l"> <!-- Personal Information Section --> <layout-card data-padding="l"> <header> <h2>Personal Information</h2> </header> <dl data-variant="horizontal" data-bordered> <dl-item> <dt>Full Name</dt> <dd>Alexandra Chen</dd> </dl-item> <dl-item> <dt>Date of Birth</dt> <dd>March 15, 1992</dd> </dl-item> </dl> </layout-card> <!-- Contact Details Section --> <layout-card data-padding="l"> <header> <h2>Contact Details</h2> </header> <dl data-variant="horizontal" data-bordered> <dl-item> <dt>Email</dt> <dd>alexandra.chen@example.com</dd> </dl-item> <dl-item> <dt>Phone</dt> <dd>+1 (555) 123-4567</dd> </dl-item> </dl> </layout-card> </layout-stack>

No custom CSS: a <layout-card> with a <header> child switches to its structured mode, which pads the header, sizes its heading and draws the divider.

Configuration

Description list patterns use these elements and CSS techniques:

HTML Structure

Element Purpose Description
<dl data-variant> Container The description list. data-variant="stacked" or "horizontal" sets the layout; data-bordered, data-striped and data-density="compact" combine with either.
<dl-item> Row grouping Groups a <dt>/<dd> run; the variants style it exactly like the spec's <div> wrapper.
<dt> Label The description term (label).
<dd> Value The description details (value).

Term Column Width

Property Default Description
--dl-term-min 10ch Minimum width of the term column in the horizontal variant
--dl-term-max 40% Maximum width of the term column; terms wider than this wrap

Usage Notes

  • Semantic HTML: Always use <dl>, <dt>, and <dd> elements for proper accessibility. Screen readers announce these as description lists.
  • No classes: The layouts are data-variant values on the <dl> itself, so the list stays plain <dl>/<dt>/<dd> markup.
  • Item grouping: The <dl-item> custom element groups each term/description pair. This is valid HTML5 and enables grid layout for horizontal display.
  • Multiple values: A single <dt> can have multiple <dd> elements for multiple values (e.g., multiple phone numbers).
  • Responsive design: The horizontal variant is a container query: it stacks when the list itself is narrower than 16rem, wherever it sits on the page.
  • Value formatting: Use badges, icons, or formatted text in <dd> elements to enhance readability.
  • Empty values: Display a dash or "Not provided" for empty values rather than leaving blank.
  • Long values: For long text values, consider truncation with a "show more" toggle or allowing text to wrap naturally.
  • Actions: You can include edit links or buttons within <dd> elements for inline editing capabilities.
