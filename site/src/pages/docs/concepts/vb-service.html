VBService is how VB components talk to servers. A component asks for a role (notify, email, newsletter); VBService turns the role into a URL. By default every role lives under /go/, and one configure() call moves any of them to your own backend.

Getting it

// Any page that loads Vanilla Breeze VB.service.configure({ baseUrl: '/api' }); // Or as a module import { VBService, VBServiceError } from 'vanilla-breeze/js'; // also exported by core-js

Configuration is shared by every bundled copy, including the ones inside autoloaded components, so configure once, early, before components fetch.

Pointing VB at your backend

How a role becomes a URL

  1. services[role], if set (trailing slash removed).
  2. Otherwise {baseUrl}/{role}. The default baseUrl is /go.

configure() merges: unspecified options keep their values, and headers and services are merged key by key. VB.service.resolve('notify') shows the URL a role resolves to.

Making requests

const notify = new VB.service('notify'); const page2 = await notify.get('/messages', { page: 2 }); // GET {base}/messages?page=2 await notify.post('/read', { ids: ['msg-1'] }); // POST JSON await notify.patch('/prefs', { digest: 'weekly' }); // PATCH JSON await notify.delete('/messages/msg-1'); // DELETE
  • Paths are relative to the role's URL; a missing leading slash is added. Query parameters with null or undefined values are dropped.
  • Bodies are sent as JSON with content-type: application/json.
  • The resolved value is the parsed JSON when the response is application/json, otherwise the response text.

Errors

Any non-2xx response rejects with a VBServiceError carrying status, body (parsed like a success), role and path. Network failures reject with the browser's own error.

try { await new VB.service('newsletter').post('/subscribe', { email }); } catch (err) { if (err instanceof VB.ServiceError && err.status === 409) { showMessage('Already subscribed'); } else { throw err; } }

Roles VB uses

RoleUsed byContract
notify<notification-wc> (when src is a role name), data-watch-pageService contracts

A component given a full URL (for example <notification-wc src="/api/notify">) fetches it directly and skips role resolution.
