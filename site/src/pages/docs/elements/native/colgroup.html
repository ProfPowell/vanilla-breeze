Description

The <colgroup> element groups one or more columns in a <table> for structural or styling purposes. It must appear after the <caption> (if present) and before any <thead>, <tbody>, or <tfoot> elements.

A <colgroup> can either use the span attribute to cover multiple columns as a single group, or contain individual <col> elements for per-column control. These two modes are mutually exclusive: if <col> children are present, the span attribute is ignored.

When to Use

  • Column widths: set fixed or proportional widths for specific columns
  • Column highlighting: apply background colors to draw attention to specific columns
  • Semantic grouping: group related columns together (e.g., "H1 columns" vs "H2 columns" in a multi-header table)

When Not Needed

  • Simple tables: where all columns have equal treatment and auto-sized widths
  • Cell-level styling: when styles need to vary within a column, target cells directly with CSS

Examples

A multi-level header: each quarter is a real <colgroup span="2">, and its header cell uses scope="colgroup" with a matching colspan. That pairing is what tells assistive technology the “Q1” header applies to both Revenue and Profit below it. The Q2 group gets a token-relative tint and both groups a dividing border.

See <th> for the full set of scope values, and <col> for per-column styling with <col> children.

span or <col> children

Use span when the whole group is treated alike (as above). Use <col> children when columns inside the group need different widths or backgrounds. You cannot mix them: with <col> children present, the group's span is ignored.

Column Widths

Set proportional or fixed widths on <col> elements for consistent column sizing.

.budget col:nth-child(1) { inline-size: 30%; } .budget col:nth-child(2), .budget col:nth-child(3) { inline-size: 25%; } .budget col:nth-child(4) { inline-size: 20%; }

CSS Limitations

The CSS specification only allows a limited set of properties on <colgroup> and <col> elements.

Property Supported Notes
background Yes Background color and images
width Yes Column width (fixed or percentage)
border Partial Only with border-collapse: collapse (VB default). Conflicting borders are resolved by width, then style, then origin: a cell border beats a row, row group, column, column group and finally table border of the same width and style
visibility Yes Only the collapse value
padding No Apply to <th>/<td> instead
text-align No Use data-numeric / data-align on cells, or target cells with CSS

For properties not supported on column groups, target cells with CSS selectors or use VB's data-numeric attribute for right-aligned columns.

/* Only these properties work on col/colgroup: */ /* background, width, border (with collapse), visibility: collapse */ /* For text-align, padding, color, font — target cells instead: */ td:nth-child(2), th:nth-child(2) { text-align: end; } /* Or use VB's data-numeric attribute: */ /* Amount */

Attributes

Attribute Value Description
span Positive integer Number of columns the group spans. Cannot be used when <col> children are present.

Accessibility

  • No role: <colgroup> and <col> are not exposed to assistive technology. Tints and borders are visual only
  • The one AT effect: a <th scope="colgroup"> applies to every cell in the column group it heads, so a real <colgroup> makes group headers announce correctly
  • Not a replacement for headers: <colgroup> does not replace proper <th> headers with scope attributes
  • Contrast: keep text readable against column tints in every color scheme
