Description

The <i> element represents text in an alternate voice, mood, or quality — a span of text that is offset from normal prose without conveying extra emphasis or importance. Common uses include foreign language phrases, technical terms, thoughts, and ship names.

VB styles <i> with font-synthesis: weight style and font-optical-sizing: auto for variable fonts.

A real italic face always wins. If the active font has none, the browser synthesizes a slanted version, so the <i> stays visible; load an italic face if you want true italic letterforms. CJK fonts almost never ship italics, so VB swaps italic for a calligraphic face and a dotted underline in those languages (see CJK alternate voice).

Inside text that is already italic — a blockquote, a work title, another <i> — <i> toggles back to upright so it still stands out (see Italic contexts).

When to Use

  • Foreign words: et cetera, c'est la vie (add lang attribute)
  • Thoughts: Internal monologue in fiction
  • Ship names: USS Enterprise, Titanic
  • Taxonomic names: Tyrannosaurus rex, Homo sapiens
  • Technical terms: First use of a term in a non-definitional context

When NOT to Use

  • For stress emphasis — use <em>
  • For importance — use <strong>
  • For defining terms — use <dfn>
  • For work titles — use <cite>
  • Purely for visual styling — use CSS font-style: italic
  • For icons — see Not for icons

Not for icons

The icon-font habit of <i class="icon-star"></i> borrows an element that means “alternate voice” for a picture. Use <icon-wc>, or <span data-icon> for a CSS-only icon. VB tolerates <i data-icon aria-hidden="true"> as a decorative convention — it is hidden from assistive technology, so the element's meaning never reaches anyone — but prefer the options above in new markup.

i vs em

Both render as italic, but they have different semantics:

Element Semantics Screen Reader
<i> Alternate voice — no meaning change Not announced differently
<em> Stress emphasis — changes meaning May be announced with emphasis

The word persona is Latin for "mask."

I love chocolate. (not just "like")

Italic Contexts

Italic text inside text that is already italic would disappear. VB uses the classic typographic toggle: <i> and <em> inside an italic context — <blockquote>, <cite>, <dfn>, <var>, or another <i>/<em> — switch back to upright. The toggle goes one level deep.

Only contexts that are actually italic count:

  • <address> and <cite data-variant="quoted"> are upright, so <i> inside them stays italic.
  • A blockquote's attribution line (blockquote > footer, blockquote > cite) is upright, so <i> there is italic again.
  • Themes with an upright blockquote (brutalist, cyber, super2026, swiss) re-assert italic inside it; the editorial theme's italic <h1> and <h3> toggle like a blockquote does.
  • The dyslexia theme makes <em> upright and semibold, so an <i> inside it stays italic.

The quote is italic, so the ship Endurance is upright.

CJK Alternate Voice

Chinese, Japanese and Korean fonts generally have no italic face, and a slanted CJK glyph reads poorly. When the content language is zh, ja or ko, VB sets <i> upright in a calligraphic face (kai / mincho; override with --font-cjk-alternate) with a dotted underline. It deliberately does not use emphasis marks — those belong to <em>, which is stress, not an alternate voice. <dfn> (heavier weight) and <cite> (wavy underline) each get their own cue.

Romanised text (lang="ja-Latn", zh-Latn, ko-Latn) is Latin script and keeps the real italic.

船の名前は日本丸です。

他心想：这不可能。

Nihon Maru stays italic.

CSS Reference

em, i { font-style: italic; font-synthesis: weight style; /* real face wins; synthesize if missing */ font-optical-sizing: auto; } /* Toggle: i/em inside an italic context is upright */ :where(blockquote, cite:not([data-variant~="quoted"]), dfn, var, em, i) :is(em, i) { font-style: normal; } /* Upright islands (attribution, quoted cite) restore italic */ :where(blockquote > :is(footer, cite), cite[data-variant~="quoted"]) :is(em, i):not( :where(blockquote > :is(footer, cite), cite[data-variant~="quoted"]) :where(em, i, cite:not([data-variant~="quoted"]), dfn, var) * ) { font-style: italic; } /* CJK: calligraphic face + dotted underline (i18n styles) */ i:is(:lang(zh), :lang(ja), :lang(ko)):not(:lang(zh-Latn), :lang(ja-Latn), :lang(ko-Latn)) { font-style: normal; font-family: var(--font-cjk-alternate); /* kai / mincho stack */ text-decoration: underline dotted var(--color-text-muted); text-underline-position: under; }

Accessibility

  • <i> does not convey emphasis to screen readers — it is purely visual
  • For foreign words, always add the lang attribute so screen readers can switch pronunciation
  • Do not rely on italic alone to convey meaning — combine with context

Related

  • <em> — Stress emphasis that changes meaning
  • <b> — Draw attention without importance (bold counterpart to <i>)
  • <cite> — Titles of creative works (also italic)
  • <dfn> — Defining instance of a term (italic + semi-bold)
  • <strong> — Strong importance (bold counterpart to <em>)
