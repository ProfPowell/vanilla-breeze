Description

The <th> (table header) element defines a cell that acts as a header for a group of table cells. Headers can apply to columns, rows, or groups of either.

Vanilla Breeze gives every header cell a semi-bold font weight (600). Column headers (in <thead>, or with scope="col" / scope="colgroup") also get a raised background (var(--color-surface-raised)) and a thicker bottom border (var(--border-width-medium)). Row headers (<th scope="row"> in <tbody>) keep the data-cell look, a transparent background and a thin rule, so row hover, stripe and selection tints run across the whole row.

When to Use

  • Column headers: In <thead> rows with scope="col"
  • Row headers: First cell of data rows with scope="row"
  • Group headers: Headers spanning multiple columns/rows with scope="colgroup" or scope="rowgroup"

When to Use td Instead

  • Data cells: Cells containing actual data values
  • Summary cells: Totals in <tfoot> (though the label cell may be <th>)

The scope Attribute

The scope attribute is essential for accessibility. It tells assistive technologies which cells the header applies to. Always include it.

Value Description Use Case
col Header applies to all cells in the column Column headers in <thead>
row Header applies to all cells in the row Row headers in first cell of <tbody> rows
colgroup Header applies to multiple columns Group headers used with colspan
rowgroup Header applies to multiple rows Section headers spanning all columns

Sortable Headers

data-sort on a <th> is read by two different enhancements, and it means a different thing to each:

Used with data-sort means Sort type from Cell value override
<data-table> The sort type: string, number or date data-sort itself data-sort-value on the <td>
table[data-sortable] The column key (any name) data-sort-type="text|number|date" on the <th> data-sort-value (or data-value) on the <td>

Either way the behaviour follows the APG sortable table: the <th> keeps its columnheader role and carries aria-sort, and the script wraps the header text in a native <button data-sort-button> that takes focus and Enter/Space. VB styles that button to read as header text with a focus ring, and draws the direction glyph (⇅, ↑, ↓) from aria-sort, so the visual and accessible state cannot drift.

A bare <th data-sort> without either enhancement has no behaviour, so VB draws no sort affordance on it. On a server-sorted static table you can still mark the sorted column with aria-sort="ascending" or "descending"; VB shows the matching arrow.

Numeric and Alignment Attributes

data-numeric

Use data-numeric on header cells for numeric columns. This aligns the header text to the inline end (right in left-to-right text, left in right-to-left) and applies font-variant-numeric: tabular-nums for proper digit alignment.

Quantity Unit Price Total

data-align

Use data-align for explicit text alignment when the default (start) or data-numeric (end) are not appropriate.

Name Status Amount

VB Data Attributes

Attribute Values Description
data-numeric Boolean attribute Aligns content to the inline end (right in LTR, left in RTL) and uses tabular numerals
data-align start, center, end Explicit text alignment override
data-sort <data-table>: string, number, date; [data-sortable]: a column key Marks a sortable column; see Sortable Headers for the two meanings

Standard HTML Attributes

Attribute Values Description
scope col, row, colgroup, rowgroup Specifies which cells the header applies to (required for a11y)
colspan Positive integer Number of columns the header spans
rowspan Positive integer Number of rows the header spans
abbr String Abbreviated version of header content for screen readers

CSS Reference

th { padding: var(--size-s) var(--size-m); font-weight: 600; text-align: start; color: var(--color-text); } /* Column headers get the header band; row headers read as cells */ :is(thead th, th:is([scope="col"], [scope="colgroup"])) { background: var(--color-surface-raised); border-block-end: var(--border-width-medium) solid var(--color-border); } tbody th:not([scope="col"], [scope="colgroup"]) { border-block-end: var(--border-width-thin) solid var(--color-border); vertical-align: top; } /* Numeric alignment (end: right in LTR, left in RTL) */ :is(td, th)[data-numeric] { text-align: end; font-variant-numeric: tabular-nums; } /* Explicit alignment */ :is(th, td)[data-align="start"] { text-align: start; } :is(th, td)[data-align="center"] { text-align: center; } :is(th, td)[data-align="end"] { text-align: end; } /* Sort glyphs ride on the injected button, driven by aria-sort */ th[data-sort] > button[data-sort-button]::after { content: " ⇅" / ""; opacity: 0.3; } th[data-sort][aria-sort="ascending"] > button[data-sort-button]::after { content: " ↑" / ""; opacity: 1; } th[data-sort][aria-sort="descending"] > button[data-sort-button]::after { content: " ↓" / ""; opacity: 1; }

Accessibility

  • Always use scope: The scope attribute is essential for screen readers to associate headers with data cells
  • Screen reader announcement: When navigating to a data cell, the associated headers are announced
  • Complex tables: For tables with multiple header levels, consider using the headers attribute on <td> elements
  • Implicit roles: <th> has an implicit ARIA role of columnheader (with scope="col") or rowheader (with scope="row")
  • Sort state: When a column is sorted, use aria-sort="ascending" or aria-sort="descending" on the <th>. Never give the <th> itself role="button": that replaces the columnheader role, aria-sort is then ignored, and the column's cells lose their header. Put a <button> inside the header instead.
