Progressive Enhancement

The anchor element is the fundamental building block of the web. It works in every browser with zero CSS or JavaScript.

  • HTML-first: Links function without any styling — the browser provides default blue/purple colors and underlines
  • CSS-enhanced: Vanilla Breeze adds interactive colors, hover effects, auto-detected link-type indicators, and focus rings
  • Works without JavaScript: Styling and auto-detection are CSS; the only script is the optional noopener upgrade for new-tab links

When to Use

  • Navigation: Links in site navigation, menus, and breadcrumbs
  • In-page links: Table of contents linking to sections
  • External resources: Linking to external sites and references
  • Downloads: Use with download attribute for downloadable files
  • Contact links: Use mailto: and tel: protocols

When NOT to Use

  • Actions: Use <button> for toggles, dialogs, form submission, or state changes
  • Dialogs: Use <button commandfor="..." command="show-modal"> via the Invokers API

Auto-Detection

Vanilla Breeze automatically detects and adds visual indicators to special link types using CSS only. The glyphs are decorative: they carry empty alternative text, so screen readers read only the link text.

Link Type Detection Indicator
External href^="http" or href^="//" ↗ arrow after text
Download [download] ↓ arrow after text
Email href^="mailto" ✉ envelope before text
Phone href^="tel" ☎ phone before text
PDF href$=".pdf" PDF badge after text (a download link to a PDF shows the download arrow instead)

External detection is a string match on the URL, so an absolute link to your own site (https://your-site.com/…) also gets the arrow. Use root-relative URLs for internal links, or add data-no-icon.

Custom Link Icons

Use icon-wc inside links for custom icons. A link with an <icon-wc> child drops its auto-detected glyph, so you never get two icons. data-no-icon suppresses the indicator explicitly.

Suppressing Auto-Icons

Use data-no-icon to suppress automatic icons. Links inside <nav>, <header>, and <footer>, and button-styled links, suppress every auto-icon — no attribute needed.

Variants

Use data-variant to change link appearance.

default link muted link plain link

Use plain sparingly. Without an underline, a link inside running text is distinguished by colour alone, which fails WCAG 1.4.1. Keep it for places where context already says "this is a link": card titles, lists of links, navigation.

Button-Styled Links

Use class="button" on a link to give it button styling. This is for links that navigate to another page but need the visual weight of a button — hero CTAs, sign-up links, prominent calls to action.

All button variants and sizes work: .secondary, .ghost, .small, .large, and .full-width. Auto-icons are automatically suppressed on button-styled links.

When links wrap images, pictures, figures, or cards, the underline is automatically removed via the CSS :has() selector.

Context Overrides

Auto-icons are suppressed in certain contexts to keep UI clean:

/* Links in nav/header/footer suppress every auto-icon */ :is(nav, header, footer) a:is([href^="http"], [href^="//"], [download], [href$=".pdf"])::after, :is(nav, header, footer) a:is([href^="mailto"], [href^="tel"])::before { content: none; } /* An authored replaces the auto-detected glyph */ a:is([href^="mailto"], [href^="tel"]):has(> icon-wc)::before, a:is([href^="http"], [href^="//"], [download], [href$=".pdf"]):has(> icon-wc)::after { content: none; } /* Button-styled links suppress every auto-icon */ a.button:is([href^="http"], [href^="//"], [download], [href$=".pdf"])::after, a.button:is([href^="mailto"], [href^="tel"])::before { content: none; }

Safe new-tab links

When a page contains <a target="_blank">, a small enhancement loads and adds rel="noopener" to any such link that doesn't already declare an opener policy. Add data-link-privacy="strict" to <html> to also add noreferrer. It is opt-in because referral analytics depend on the Referer header.

Key Attributes

Attribute Description
href The URL the link points to (required for a functional link)
target Where to open the link (_blank for new tab)
rel Relationship to the linked resource (noopener, external, help…)
download Prompts download instead of navigation (same-origin URLs only)
hreflang Language of the linked document
ping URLs notified with a POST when the link is followed
referrerpolicy How much referrer information to send
data-variant Visual variant: muted | plain
data-no-icon Suppress auto-detected link type icons

Link States

Hover

Underline thickness increases from 1px to 2px on hover.

Focus

A visible focus ring appears when navigating via keyboard (uses :focus-visible with var(--color-interactive) outline).

Visited

Vanilla Breeze deliberately does not style :visited links, so links look the same wherever they appear. This is a design choice: browsers already limit which properties :visited can change, to prevent history sniffing, whether or not a stylesheet uses it.

Accessibility

  • Descriptive link text: Avoid "click here" or "read more" — use meaningful text that describes the destination
  • Visual distinction: Links have underlines by default — color alone is not sufficient to identify links
  • Focus visibility: Links have visible focus rings for keyboard navigation
  • New tab warning: When links open in new tabs, inform users
  • Skip links: Use anchor links to create "skip to content" navigation
