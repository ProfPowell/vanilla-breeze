Description

The <bdo> (Bidirectional Text Override) element forces the characters inside it to be laid out in a specified direction, overriding the Unicode Bidirectional Algorithm. The dir attribute is required and must be ltr or rtl.

You rarely need it. The bidirectional algorithm already displays Hebrew, Arabic and other right-to-left text correctly inside a left-to-right paragraph (and vice versa). <bdo> is only for the uncommon cases where you want to override that and force a character order. For isolating text of unknown direction (user names, user-generated content), use <bdi> instead.

When to Use

  • Showing characters in storage order: displaying how right-to-left text is stored in memory, for teaching or debugging
  • Displaying reversed text deliberately, such as mirror writing
  • Correcting direction when the algorithm gets it wrong, typically for text that has lost its directional context (e.g. data from a legacy system stored in visual order)

When NOT to Use

  • To embed right-to-left text in a left-to-right paragraph — the bidirectional algorithm handles that; mark the text with <span lang="he" dir="rtl"> or <bdi>
  • For user-generated content — use <bdi> (auto-detection is safer)
  • For entire page direction — use dir="rtl" on <html>

Examples

Normal text: Hello World

Reversed: Hello World

Displayed normally: שלום

Characters in storage order: שלום

The Hebrew word for "peace" is שלום.

Outer RTL: Hello Inner LTR: World Back to RTL

Always add lang to text in another language, such as Hebrew (lang="he"), so screen readers pronounce it correctly (WCAG 3.1.2, Language of Parts).

Attributes

Attribute Description
dir Required. Text direction: ltr (left-to-right) or rtl (right-to-left). dir="auto" is not allowed on <bdo>, because an override needs an explicit direction.

Also supports global attributes.

CSS

bdo { unicode-bidi: isolate-override; /* UA default */ }

VB adds no styling and no unicode-bidi rules. The browser's default, isolate-override, forces the direction inside the element and isolates it from the surrounding text.

Accessibility

<bdo> affects visual presentation only. Screen readers read the text in its logical (source) order, not the visual order: reversed “Hello World” is still read as “Hello World”. Be cautious using <bdo> purely for visual effects, because sighted and non-sighted users get different content.
