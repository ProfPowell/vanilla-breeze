Description

The <meta> element carries document metadata that has no dedicated element. It is a void element that normally lives in <head>. Each <meta> does exactly one job, chosen by which of these attributes it has:

  • charset: declares the character encoding
  • name + content: a named metadata value (description, viewport, theme-color, author…)
  • http-equiv + content: a pragma directive that acts like an HTTP header
  • itemprop + content: a microdata property (allowed in the body too)

A <meta> must have exactly one of charset, name, http-equiv or itemprop. Open Graph tags use the RDFa property attribute instead of name; browsers ignore them, but crawlers and some VB components read them.

Basic Example

The tags almost every page needs. charset must come first, within the first 1024 bytes of the document.

See <head> for the full recommended VB head, including theme flash prevention, social metadata and favicons.

Attributes

AttributeValuesDescription
charset utf-8 Character encoding. utf-8 is the only valid value. At most one per document.
name metadata name What the content value describes: description, viewport, theme-color, color-scheme, author, keywords, robots, referrer, generator, or an extension name such as vb:provenance.
content string The value. Required with name, http-equiv and itemprop; not allowed with charset.
http-equiv content-security-policy, refresh, default-style, x-ua-compatible, content-type A pragma directive. Prefer real HTTP headers where you control the server; a meta CSP cannot use frame-ancestors, report-uri or sandbox.
media media query Only meaningful on name="theme-color": the first tag whose query matches wins. Used for a light/dark pair.

The element also supports global attributes and the microdata itemprop attribute.

Theme colour and ThemeManager

<meta name="theme-color"> tints the browser’s address bar and tab strip. Author a single value or a media-scoped light/dark pair as the first-paint default.

Once the VB bundle runs, ThemeManager takes over. After every mode, brand or accent change, and when the system colour scheme changes while the mode is auto, it sets every meta[name="theme-color"] to the page’s painted background colour as #rrggbb and removes their media attributes, because the mode is known by then. Pages without a theme-color meta are left alone.

So the authored pair only matters before JavaScript runs. Don’t write scripts that look for the media attribute later; it will be gone.

Metadata VB reads

VB follows a published meta-tag contract (v1.1). Its rule is public-first: where a standard name exists (HTML, Open Graph, Schema.org microdata), VB reads that name. The vb:* namespace is used only for VB-specific extensions that no standard covers. Crawlers and social tools can then understand a VB page without knowing anything about VB.

<page-info> author, last-modified, keywords, license, property="article:*", itemprop="version", repeated concept, and vb:provenance, vb:review, vb:status, vb:ai-tools, vb:version-url, vb:signature, vb:signature-algorithm
Signing (canonical document) Reads by name, property and itemprop: og:title, keywords, concept, license and others, so the signature covers the metadata
Analytics Every meta[name^="vb:"] plus all concept tags, folded into each event as taxonomy

<share-wc> description, og:title, og:description as share-text fallbacks
<page-stats> last-modified

Topics are repeated <meta name="concept"> tags holding SKOS concept ids. Contract v1.1 removed the old dotted-path vb:topic. For the field families and how signing works, see Document provenance.

Accessibility

  • Never block zoom. Don’t put user-scalable=no or maximum-scale=1 in the viewport meta. They stop pinch-zoom and fail WCAG 1.4.4 Resize Text. width=device-width, initial-scale=1 is enough.
  • No timed refresh or redirect. <meta http-equiv="refresh" content="30"> reloads the page, or sends the user elsewhere, without their control. That fails WCAG 2.2.1 Timing Adjustable and 3.2.5 Change on Request. Redirect on the server. If you must use meta refresh as a redirect, use a delay of 0.
  • Describe the page. A specific description is what search results and link previews show, which helps every user choose the right page.
  • color-scheme: lets dark-mode users get a dark canvas and native controls from the first paint, with no bright flash.
