Description

The <source> element is an empty element that specifies media resources for <picture>, <video>, and <audio> elements. It allows browsers to choose the most appropriate media file based on format support, media queries, or other criteria.

The browser evaluates <source> elements in order and uses the first one that matches. This enables progressive enhancement with modern formats while maintaining compatibility with older browsers.

When to Use

  • Format fallback - Serve modern formats (WebP, AVIF, VP9) with older format fallbacks
  • Art direction - Different images for different viewport sizes (with picture)
  • Media conditions - Different files for different viewports, or for print
  • Codec support - Alternative video/audio codecs for browser compatibility

Usage with Picture

In <picture>, use srcset (not src) to specify image sources. The browser picks the first <source> whose type it supports and whose media matches; if none match, it uses the <img>.

Format Switching

Serve modern image formats to supporting browsers. Every format source needs a type: it is the only way the browser can skip a format it cannot decode.

Art Direction

Different image crops for different viewport sizes.

Combined: Format + Art Direction

Resolution Switching

When only the size changes (same image, same crop), you do not need <picture> or <source> at all. Put srcset with width descriptors and sizes on the <img>, and let the browser pick a file for the layout width and pixel density. Keep <source> for format fallback and art direction; a <source> takes the same srcset/sizes when you need both.

Dark Mode Images

Caveat for VB sites: prefers-color-scheme follows the operating system only. VB's own light/dark switch sets data-mode on <html> and does not change which <source> is picked, so a visitor who chose dark in the site settings on a light OS gets the light logo. For theme-aware artwork, prefer an inline SVG coloured with currentColor or tokens (which use light-dark()), or switch two images with CSS keyed on data-mode.

.logo-dark { display: none; } :root[data-mode="dark"] .logo-light { display: none; } :root[data-mode="dark"] .logo-dark { display: inline; }

Usage with Video

In <video>, use src to specify video sources.

Format Fallback

Video Codecs

Format Type Notes
MP4 (H.264) video/mp4 Universal support, good quality
WebM (VP9) video/webm; codecs="vp9, opus" Better compression, modern browsers
WebM / MP4 (AV1) video/webm; codecs="av01.0.05M.08" Best compression. AV1 needs the full codec string (profile, level, tier, bit depth); a bare av01 is reported as unsupported, so the source is always skipped.
Ogg (Theora) video/ogg; codecs="theora" Removed from Chromium and no longer reliable. Do not ship Theora; use VP9 or AV1.

Responsive Video

Different video files for different screen sizes (via media query).

Usage with Audio

Provide multiple audio formats for broad browser support.

Format Type Notes

AAC audio/aac Good quality, wide support
Ogg Vorbis audio/ogg Open format
Opus audio/opus Best quality/size, modern browsers
WAV audio/wav Uncompressed, large files
FLAC audio/flac Lossless compression

Attributes

Attribute Context Description
src video, audio URL of the media file
srcset picture URL(s) of image files with optional descriptors
type all MIME type, optionally with a codecs parameter. Required on format-fallback sources in picture
media all Media query for when this source applies
sizes picture Image sizes for responsive images
width picture Intrinsic width of the image
height picture Intrinsic height of the image

Best Practices

Order Matters

Browsers use the first matching source, so order from most preferred to least preferred.

Always Include Type

In <picture>, a <source> with no type and no media always matches. The browser picks it and never looks at later sources or the <img>, so a browser that cannot decode the file shows a broken image rather than falling back. type is what makes format fallback work.

Include Codec Information

For video, specify codecs in the type for more accurate format selection. Quote the codecs value (it contains commas), and use the full codec string the encoder reports. You can test a string in the console with document.createElement('video').canPlayType(type): an empty string means the source will be skipped.

Accessibility

The <source> element itself has no accessibility implications - it's purely a mechanism for resource selection. Accessibility considerations apply to the parent elements:

  • Picture: Ensure the <img> has appropriate alt text
  • Video: Provide <track> elements for captions
  • Audio: Provide transcripts for audio content

CSS Reference

The <source> element is not rendered and has no visual appearance. Vanilla Breeze sets display: none as a precaution.

source { display: none; }
