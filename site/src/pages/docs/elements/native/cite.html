Description

The <cite> element represents the title of a creative work: a book, paper, essay, poem, song, film, TV show, game, painting, musical, exhibition, legal case, website, or blog post. It is rendered in italic by default.

The element should contain only the title of the work, not the author's name (though the author can appear nearby).

When to Use

  • Book titles: The Great Gatsby
  • Film/TV: Inception, Breaking Bad
  • Music: Album titles like Abbey Road
  • Art: Starry Night, The Thinker
  • Games: The Legend of Zelda
  • Attribution: The work's title inside a figure.quote <figcaption> (see In quotations)

When NOT to Use

  • For author names alone — use plain text
  • For inline quotations — use <q>
  • For emphasis — use <em>

Examples

My favorite book is The Great Gatsby by F. Scott Fitzgerald.

Do not type a dash before the attribution: figure.quote adds one with CSS and hides it from screen readers.

In quotations

  • Preferred pattern: <figure class="quote"> with the <blockquote> and a <figcaption>. The attribution stays outside the quotation, as the HTML spec requires, and the figcaption gets a silent leading dash.
  • Legacy pattern: a <cite> or <footer> that is a direct child of <blockquote> is styled as a block attribution line with the same silent dash. A <cite> elsewhere inside the quoted text stays an inline title.
  • Element vs attribute: the <cite> element is a visible work title. The cite attribute on <blockquote>, <q>, <ins> and <del> is a source URL that browsers do not display.

Variants

data-variant="quoted"

Sets the title in quotation marks instead of italics (font-style: normal plus open-quote/close-quote). House styles often reserve quotes for short works — articles, songs, episodes — and italics for long ones. The marks follow the same :lang() quote table as <q>, so a German page gets „…“.

Tonight's episode is The One with the Embryos.

The article Why CSS is Awesome changed my perspective.

Chinese, Japanese and Korean

CJK scripts have no true italics, and browsers fake them by slanting the glyphs. Under :lang(zh), :lang(ja) and :lang(ko), <cite> is upright with a muted wavy underline instead. The quoted variant keeps its quotation marks and drops the underline.

CSS Reference

cite { font-style: italic; } /* Quoted variant — quotes instead of italics */ cite[data-variant="quoted"] { font-style: normal; } cite[data-variant="quoted"]::before { content: open-quote; } cite[data-variant="quoted"]::after { content: close-quote; }

Accessibility

  • <cite> has no ARIA role — screen readers announce it as plain text, without the italics
  • The italic styling is a visual convention only; make sure the sentence makes clear the text is a title

Related

  • <blockquote> — For longer quotations (cite provides the source title)
  • <q> — For inline quotations with locale-aware quote marks
  • <figure> — For self-contained content with optional <figcaption>
  • <em> — For emphasis (not titles)
  • <i> — For alternate voice text (taxonomic names, thoughts)
