Description

The <del> element indicates text that has been removed from a document. It is semantically meaningful for document revision tracking, edit histories, and showing changes over time. VB styles it with a red line-through and a subtle red background tint so deletions are visually distinct from <s> strikethroughs.

The element can optionally include cite and datetime attributes to provide machine-readable context about the deletion.

When to Use

  • Document revisions: Track changes in legal documents, contracts, or policies
  • Edit history: Show what was changed in collaborative documents
  • Diff displays: Show removed code or text in version comparisons
  • Corrections: Indicate corrected information while preserving the original
  • Track changes: Similar to "track changes" in word processors

When NOT to Use

  • Visual strikethrough only: Use <s> for content that is no longer relevant but was not editorially deleted
  • Price reductions: Use <s> unless you are tracking actual revision history

Block-Level Deletion

When <del> wraps block content (paragraphs, lists, tables, headings, <pre>, <blockquote> and similar), VB detects it with :has() and turns the change into a block with the tint, padding, and an inline-start edge bar, so the styling covers the whole change instead of breaking across each child. No class is needed.

This entire paragraph has been removed from the document.

Multiple paragraphs can be deleted together.

Annotated Changes

data-reason shows a small uppercase tag before the change. data-author appends the author's name after it; the name appears on hover, when focus is inside the change, always on touch screens, and in print.

Announced Changes

Most screen readers do not announce <del> at all by default, so a listener hears the deleted words with no hint that they are an edit. Add data-announce to the change, or to any ancestor such as an article, to insert visually hidden “deletion start” / “deletion end” text around it.

The release ships on Friday Monday.

Translate the announced words with custom properties holding quoted strings, set on the element or any ancestor:

:lang(fr) { --del-announce-start: "début de suppression"; --del-announce-end: "fin de suppression"; --ins-announce-start: "début d’insertion"; --ins-announce-end: "fin d’insertion"; }

When the change also has a visible data-reason or data-author, that annotation stays visible and carries the announcement as its alternative text.

Key Attributes

Attribute Description Example
datetime Date and time of the deletion in ISO 8601 format. Not visible, and not exposed by browsers to assistive technology; available to scripts. Show the date in visible text if readers need it. datetime="2024-01-15T10:30:00"
cite URL to a document explaining the change. Not rendered by the browser but useful for audit trails. cite="https://example.com/changelog"
data-reason VB: short visible tag before the change (e.g. correction, review). data-reason="correction"
data-author VB: author name shown after the change on hover, focus, touch screens, and in print. data-author="Ana"
data-announce VB: on the element or any ancestor, adds visually hidden “deletion start/end” text for screen readers. data-announce

del vs s

Both elements produce a strikethrough, but they carry different semantics and VB gives them different visual treatments to match:

Element Meaning VB Styling
<del> Editorial change — text was removed from the document Red strikethrough + red background tint
<s> No longer accurate/relevant — not an edit Muted strikethrough only (no background)

Use <del> when the content was editorially removed (contracts, changelogs, diffs). Use <s> for prices, expired offers, or outdated info.

CSS Reference

del { text-decoration: line-through; background: var(--color-error-subtle); text-decoration-color: var(--color-error); } /* Pill-shaped diff tokens */ :is(del, ins).diff { display: inline-block; padding-inline: var(--size-2xs); border-radius: var(--radius-s); } /* Wrapping block content: automatic block styling */ :is(del, ins):has(> :is(p, ul, ol, dl, div, section, article, aside, blockquote, pre, table, figure, h1, h2, h3, h4, h5, h6)) { display: block; padding: var(--size-s); border-inline-start: var(--size-3xs) solid var(--_change-color); } /* data-announce: visually hidden start/end text */ :is(del[data-announce], [data-announce] del)::before { content: var(--del-announce-start, "deletion start") " "; }

The tint and strikethrough come from the theme's --color-error-subtle and --color-error tokens, so they follow light and dark modes and every theme. The .diff variant adds inline-block display with padding for pill-shaped diff tokens.

Accessibility

  • Not announced by default: Most screen reader and browser combinations read <del> content as ordinary text, with no indication that it was deleted. Where the edit matters to the meaning, add data-announce (see Announced Changes) or say so in the surrounding text
  • Dual visual cues: Strikethrough and background color together ensure visibility, including for users who may not perceive color
  • Don't hide important info: Ensure any still-visible deleted content remains accessible
  • Datetime is not exposed: Browsers do not pass datetime to assistive technology; put the date in visible text when it matters

Screen Reader Behavior

With data-announce, users hear something like:

"deletion start, This content has been deleted, deletion end"
