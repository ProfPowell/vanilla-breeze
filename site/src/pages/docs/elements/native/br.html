Description

The <br> element produces a line break in text. It is a void element (no closing tag). Use it only where the line break is an intrinsic part of the content — addresses, poetry, song lyrics — not for visual spacing between blocks.

When to Use

  • Postal addresses: Line breaks between street, city, postal code
  • Poetry and lyrics: Line breaks within stanzas
  • Structured text: Where line breaks carry meaning in the content

When NOT to Use

  • Spacing between paragraphs: Use <p> elements or <layout-stack>
  • Visual gaps: Use CSS margin or gap
  • Separating sections: Use <hr> for thematic breaks

Examples

John Smith
123 Main Street
Springfield, IL 62704

Use <address> only when the address is contact information for the nearest <article> or for the page as a whole (for example, the author's or organization's contact details). An arbitrary postal address in running content, such as a venue or a shipping address, belongs in a <p>.

Example Co.
123 Main Street
Springfield, IL 62704
hello@example.com

Roses are red,
Violets are blue,
Sugar is sweet,
And so are you.

CSS and Alternatives

VB adds no styling to <br>. Some alternatives to consider:

  • white-space: pre-line: preserves the line breaks typed in the source while still collapsing other spaces. Handy for poems or text from a database that already contains newlines, without inserting a <br> per line.
  • Separate elements: if each line is its own item (a list of features, the stanzas of a poem), <li> or <p> elements are usually more robust than breaks.
  • The clear attribute is obsolete: <br clear="all"> was used to drop below floats. Use CSS clear: both on the following element instead.
.poem { white-space: pre-line; }

Accessibility

  • Each <br> starts a new line in the reading order, so screen reader users moving line by line hear each address line or verse line separately
  • Consecutive <br> elements produce empty lines, which some screen readers announce as “blank” — noise with no content
  • Use <p> elements for distinct paragraphs so screen readers can navigate by paragraph

Related

  • <hr> — Thematic break between sections
  • <address> — Contact information for the nearest article or page
  • <wbr> — Word break opportunity (optional break, not forced)
  • <layout-stack> — Vertical spacing between elements
