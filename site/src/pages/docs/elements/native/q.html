Description

The <q> element marks an inline quotation. The browser inserts quotation marks automatically via CSS quotes. VB's i18n system starts from quotes: auto (the browser picks marks for the quotation's language) and pins explicit marks for English, German (incl. Swiss), French, Italian, Spanish, Portuguese (Brazil and Portugal), Polish, Japanese, Chinese (Simplified and Traditional), Korean, Russian, and Arabic.

For longer quotations that require paragraph breaks, use <blockquote>.

When to Use

  • Short quotations: Quotes within running text
  • Attributed speech: "She said..." patterns
  • Multilingual content: Quotes that need locale-correct marks

When NOT to Use

  • For long, block-level quotations — use <blockquote>
  • For titles of works — use <cite>
  • For scare quotes or air quotes — type the quote characters directly

Examples

She said Hello, world! and smiled.

He asked, Did she really say I'll be there?

According to the documentation, this feature is experimental.

Locale-Aware Quotes

VB's i18n stylesheet sets the CSS quotes property per language using :lang() selectors. Set lang on the <q> itself or on any ancestor and the matching quotation marks appear. The nearest lang wins, so a foreign-language quotation inside English text gets its own marks, and a <q lang="en"> inside Japanese text gets English marks.

CSS Reference

/* Base: the browser's own table for the element's language */ :is(q, cite[data-variant="quoted"]) { quotes: auto; } /* q:lang(x), not :lang(x) q — so lang on the itself works too */ :is(q, cite[data-variant="quoted"]):lang(en) { quotes: "\201C" "\201D" "\2018" "\2019"; } :is(q, cite[data-variant="quoted"]):lang(de) { quotes: "\201E" "\201C" "\201A" "\2018"; } :is(q, cite[data-variant="quoted"]):lang(de-CH) { quotes: "\00AB" "\00BB" "\2039" "\203A"; } :is(q, cite[data-variant="quoted"]):lang(fr) { quotes: "\00AB\202F" "\202F\00BB" "\2039\202F" "\202F\203A"; } :is(q, cite[data-variant="quoted"]):lang(zh) { quotes: "\201C" "\201D" "\2018" "\2019"; } :is(q, cite[data-variant="quoted"]):is(:lang(zh-Hant), :lang(zh-TW), :lang(zh-HK), :lang(zh-MO)) { quotes: "\300C" "\300D" "\300E" "\300F"; } /* … full table in src/native-elements/i18n/styles.css */ q::before { content: open-quote; } q::after { content: close-quote; }

French quotes include narrow non-breaking spaces (\202F) inside the guillemets, matching French typographic convention. The same table applies to <cite data-variant="quoted">.

Copy and paste: the marks are generated by CSS (::before / ::after content), so copying a quotation copies the words without the quotation marks. If the marks must survive copying or plain-text export, type them in the text instead of using <q>.

Attributes

AttributeDescription
cite URL pointing to the source of the quotation (not displayed, but available to scripts)
lang Language of the quotation — drives locale-appropriate quote marks

Accessibility

  • Whether a screen reader speaks the generated quotation marks depends on its punctuation verbosity setting; do not rely on the marks alone to convey that text is quoted when it matters (say who is speaking in the text)
  • The semantic markup distinguishes quoted text from regular content
  • Nested quotes alternate between outer and inner quote styles
