Description

The <img> element is the primary way to embed images in HTML. Vanilla Breeze styles images to be responsive by default, constraining them to their container width while maintaining aspect ratio. Additional variant classes provide shapes, borders, and aspect ratio control.

Images are block-level elements with max-inline-size: 100% and block-size: auto, ensuring they never overflow their container while preserving their natural proportions. They are never upscaled past their intrinsic width unless you ask for it with .full.

When to Use

  • Content images - Photos, illustrations, and graphics that are part of the content
  • Avatars - User profile pictures using the .circle variant
  • Thumbnails - Small preview images with borders
  • Hero images - Large banner images using .full variant
  • Product images - E-commerce product photos with consistent aspect ratios

When to Use Other Elements

  • Use <picture> for art direction or serving different formats
  • Use <figure> to wrap images that need captions
  • Use <svg> for icons and vector graphics
  • Use CSS background-image for decorative images that don't convey content

Variants and Aspect Ratios

Vanilla Breeze provides variant classes for common image treatments: .rounded, .circle, .thumbnail, .full, and aspect ratio classes .ratio-square, .ratio-video, .ratio-landscape, and .ratio-portrait.

Variant Classes

Inside a <figure> an image fills the figure's width; to keep a small image (an avatar or thumbnail) at its own size, don't wrap it in a figure, or give it a wrapper that doesn't stretch it.

Aspect Ratio Classes

Each class sets aspect-ratio and crops with object-fit: cover, so any source fits the ratio.

Class Aspect Ratio Use Case
.ratio-square 1:1 Profile photos, app icons
.ratio-video 16:9 Video thumbnails, hero images
.ratio-landscape 4:3 Classic photo format
.ratio-portrait 3:4 Book covers, portraits

For other ratios, or to set the focal point, use a [data-media] wrapper, which uses the same data-ratio vocabulary as <iframe>, <embed> and <object>.

Object Fit

.contain letterboxes the whole image inside its box; .cover crops to fill it. They combine with the ratio classes.

Ratio Boxes with data-media

A [data-media] wrapper is a ratio box whose child image fills it. data-ratio picks the ratio (1:1, 4:3, 3:2, 16:9, 21:9, 2:3, 3:4, 9:16), data-fit the object-fit (cover, contain, fill, none), data-position the focal point and data-radius the corners. On a <figure> with a caption, the ratio applies to the image and the caption flows below.

Sizing and Layout Shift

Always set width and height to the image's intrinsic pixel size. The browser uses them to reserve the right-shaped box before the file arrives, so nothing jumps when it loads (Cumulative Layout Shift). VB's block-size: auto keeps the ratio from those attributes while max-inline-size: 100% shrinks the image to fit.

Responsive Sources: srcset and sizes

Offer several widths with srcset and tell the browser how wide the image will display with sizes; it picks the smallest file that looks sharp. Use <picture> only when you need different crops (art direction) or formats.

Loading and Priority

Native lazy loading defers loading images until they approach the viewport. VB adds no loading background, so transparent PNG and SVG logos render cleanly.

  • loading="lazy" - Defer until near the viewport. Use for below-the-fold images only; lazy-loading the Largest Contentful Paint image delays it.
  • fetchpriority="high" - Fetch ahead of other images. Use on the one LCP image; low for carousels' hidden slides.
  • decoding="async" - Let the browser decode the image without blocking other content.

Missing Images

An <img> with no src, or an empty one, gets a raised-surface background and a 100px minimum height, so the gap reads as "image goes here" instead of collapsing. A src that fails to load shows the browser's broken-image icon and the alt text, which is one more reason to write meaningful alt text.

Outline

data-outlined draws a faint outline just inside the image edge, so light or transparent imagery keeps its shape on light and dark surfaces. It uses outline, so layout doesn't change. Works on <img> and on <picture data-outlined>. See Feel.

Prototyping with data-mock

Add data-mock to an <img> without a src to get a sized placeholder. Presets such as hero, card and logo produce a local SVG. A few presets fetch from external services: photo (picsum.photos), placehold (placehold.co), and avatar, portrait, profile and headshot (CC0 portraits from the jsDelivr CDN). Use them for prototypes only, not shipped pages or offline demos.

Image Links

When an <img> is the direct child of an <a>, Vanilla Breeze automatically removes the underline decoration via a:has(> img) { text-decoration: none }. This prevents an unsightly underline bar beneath linked images.

See the <a> element docs for more on link styling and auto-detected link types.

Accessibility

Alt Text Guidelines

Every image must have an alt attribute. The content depends on the image's purpose:

Image Type Alt Text Approach Example
Informative Describe the content and meaning alt="Golden retriever playing fetch in a park"
Functional Describe the action or destination alt="Submit form"
Decorative Empty alt attribute alt=""
Complex Brief summary + detailed description nearby alt="Q3 sales chart. Details in table below."

Best Practices

  • Keep alt text concise (under 125 characters when possible)
  • Don't start with "Image of" or "Picture of" - screen readers announce this
  • Include relevant text that appears in the image
  • For decorative images, use alt="" (not omitting the attribute). That alone hides the image from assistive technology; role="presentation" adds nothing

Complex Images

Charts, diagrams and maps carry more than fits in alt. Give a short alt that names the image and its key point, then put the full description in visible text: a caption, a linked description, or a disclosure.

If the data matters, a <table> beside the image is better still.

Dark Mode and Forced Colors

VB doesn't recolor images in dark mode or forced-colors mode: photos should look the same everywhere. For a logo or diagram that needs a dark variant, serve one with <picture> and <source media="(prefers-color-scheme: dark)">, or use inline <svg> with currentColor.
