Description

The <link> element relates the current document to another resource. It is a void element: there is no closing tag and nothing renders on the page. The rel attribute says what the relation is, and href says where the resource is. Both are required, apart from a few special cases such as rel="preload" with imagesrcset.

Most links live in <head>. A few kinds are "body-ok" and may also appear in <body>: stylesheet, preload, modulepreload, prefetch, preconnect and dns-prefetch. Microdata links use itemprop instead of rel.

rel is a space-separated list of tokens, matched case-insensitively. <link rel="author license" href="/about/"> declares both relations at once.

Relation Types

Loading resources

rel Effect
stylesheet Loads and applies a CSS file. A stylesheet in <head> blocks rendering until it arrives, unless its media does not match.
preload Fetches a resource the current page will need soon, at high priority, without applying it. Requires as. A preload that goes unused triggers a console warning.
modulepreload Fetches, parses and compiles an ES module (and may fetch its imports) before a <script type="module"> asks for it.
preconnect Opens the DNS + TCP + TLS connection to another origin ahead of time. Only worth it for origins the page will request from within a few seconds.
dns-prefetch Resolves only the DNS name. Cheaper than preconnect; a common fallback next to it.
prefetch Low-priority fetch of a resource a future navigation is likely to need.

Describing the document

rel Meaning
icon, apple-touch-icon Favicon and home-screen icon. type and sizes help the browser pick one.
manifest The web app manifest (name, icons, display mode) for installable sites.
alternate Another version of this page: a translation (with hreflang), a feed (with type="application/rss+xml" or application/feed+json), or a print version (with media).
canonical The preferred URL for this content, so query-string and trailing-slash variants do not count as duplicates.
author A page about the author (a profile page or a mailto: URL).
license The license that covers the main content of the page.

See the rel attribute page for the full list, including the values that apply to <a> and <form>, and link relations for how VB uses them.

Preloading and Resource Hints

  • Match the later request. A preload is only reused when its URL, as and CORS mode match the real request. A font preload without crossorigin downloads the font twice. In the same way, a preconnect with crossorigin opens a connection that plain <img> requests cannot use.
  • Preload sparingly. Every preload competes with the resources the parser already found. Preload late-discovered, render-critical files (fonts, a CSS background hero, a module entry), not everything.

Attributes

Attribute Applies to Description
rel All Space-separated relation tokens.
href All URL of the linked resource. Resolved against the document base URL (see <base>).
media stylesheet, preload, alternate, icon Media query. A stylesheet whose media does not match is still downloaded, at low priority, and does not block rendering.
as preload, modulepreload Destination of the resource: style, script, font, image, fetch, … Required for preload; sets the priority and the Accept header.
crossorigin Fetching rels Fetch in CORS mode (anonymous or use-credentials). Must match how the resource is used later.
fetchpriority Fetching rels high, low or auto: a hint relative to other resources of the same type.
blocking stylesheet, preload, modulepreload blocking="render" holds first paint until the resource loads. Only needed for links that would not block anyway, such as ones inserted by script.
integrity stylesheet, preload, modulepreload Subresource Integrity hash. The browser refuses the file if its content does not match. Cross-origin files also need crossorigin.
referrerpolicy Fetching rels How much of the page URL to send as the Referer header.
type All MIME type hint. Lets the browser skip a preload or icon it cannot use.
hreflang alternate Language of the linked resource.
sizes icon, apple-touch-icon Icon dimensions, e.g. 32x32 or any.
imagesrcset, imagesizes preload with as="image" Preload the same responsive candidate the <img srcset> will choose.
disabled stylesheet Leaves the stylesheet unapplied.

This element also supports global attributes.

Vanilla Breeze and <link>

Loading VB and themes

Link the VB stylesheet, optionally a decorative theme, and preload the JS entry you load:

Link order between VB files does not matter. Every theme file declares @layer bundle-theme itself and the CDN build prepends VB's layer-order statement, so a theme linked before or after the main stylesheet lands in the same layer. Your own unlayered CSS beats every VB layer wherever you link it. See loading Vanilla Breeze for the bundle choices.

The theme link is optional: when data-theme on <html> names a decorative theme, the JS bundle loads it on demand. Linking it yourself avoids a late repaint and works without JavaScript.

Theme link attributes

VB's theme loader marks the links it inserts, and adopts links you author with the same attributes instead of loading the theme a second time.

Attribute Values Meaning
data-vb-theme Theme name This stylesheet is the named theme. The loader waits for an existing link with this attribute instead of inserting its own.
data-vb-theme-state loading, ready, error, timeout Load state, set by the loader and the boot snippet. The docs site hides <body> while a loading theme link is present, to avoid a flash of the default theme.
data-vb-theme-preload Theme name A rel="preload" hint the theme picker adds on hover or focus. At most one per theme; it is removed once the theme stylesheet is inserted.

Links VB reads

Some components read relations from <head>, as defined by VB's meta-tag contract. They match rel as a token list, so combined values such as rel="author license" work.

rel Read by
canonical <share-wc> (the URL it shares when no url attribute is set) and <page-info>. Both resolve a relative href to an absolute URL.
author <page-info> author link, and the signed canonical document, when article:author is absent.
license <page-info> license link and the signed canonical document.
author-key <page-info> signature verification: the URL of the public signing key (JWK). See document provenance.

The contract also defines rel="tag" (one per topic) and rel="glossary". VB emits them for crawlers and other clients; no VB component reads them.

Links VB inserts

Apart from themes, a few features add a <link> to <head> when they are first used. All of them resolve against the same CDN base as the theme files:

  • data-math adds <link rel="stylesheet" href="…/cdn/fonts/math-fonts.css" data-vb-math-font> for the Latin Modern Math face.
  • Pack themes add their effects stylesheet (data-vb-pack-effects) after the theme loads.
  • <geo-map> adds a preconnect to its tile server when a reader is about to activate the map.

Accessibility

  • <link> renders nothing and is not exposed to assistive technology.
  • Give alternate stylesheets and feeds a clear title. Browsers and feed readers list them by that title.
  • A render-blocking stylesheet that is slow or fails leaves readers with a blank page. Keep critical CSS small, and do not add blocking="render" to resources the first paint does not need.
  • Do not use disabled stylesheets or media tricks to hide content that assistive technology still reads.
