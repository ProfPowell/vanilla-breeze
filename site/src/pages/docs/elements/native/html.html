Description

The <html> element is the root of an HTML document. In Vanilla Breeze, it serves as the attachment point for theming, fluid scaling, page layout, and accessibility configuration via data attributes.

Because CSS selectors like :root[data-theme] and :root[data-mode] target this element, the <html> element acts as VB's global control surface. Data attributes set here cascade through the entire document via custom properties, while individual elements can override them locally for scoped theming.

How It Works

Cascade Model

VB stores configuration as data attributes on <html>. CSS activates token overrides using :root[data-*] selectors. Theme selectors use the ~= operator (word-match) so multiple themes can be space-separated. Mode and fluid selectors use = (exact match) since only one value is valid at a time.

/* Theme CSS uses :root[data-theme~="name"] — the ~= operator matches individual words in a space-separated list */ :root[data-theme~="modern"] { --radius-s: 0.5rem; --shadow-s: 0 2px 8px oklch(0% 0 0 / 0.08); } /* Mode uses exact match since only one value is valid */ :root[data-mode="dark"] { color-scheme: dark; }

html vs body

VB splits responsibilities between these two elements:

Attribute Element Purpose
data-mode <html> Light/dark color scheme (global config)
data-theme <html> Brand and aesthetic tokens (global config)
data-accent <html> or any element Colour accent (brand hues), a separate axis from the theme
data-fluid <html> Fluid typography and spacing scaling
data-backdrop, data-backdrop-chrome <html> Canvas backdrop: page regions as cards on a tinted canvas
data-sticky <html> Sticky site header system
data-page <html> Site section identifier for scoped CSS
data-page-layout <body> Page grid structure (sidebar, holy-grail, etc.)

Scoped Overrides

Both data-theme and data-mode can be placed on any descendant element to create a scoped region. A scoped data-mode="light" or "dark" element re-derives the colour tokens (primary, surfaces, text, borders, hover and focus colours) from its own seeds, and VB's reset gives every scoped data-theme / data-mode element its own background-color: var(--color-background) and color: var(--color-text). A dark aside on a light page therefore paints a dark surface instead of light text over the white page. The reset rule has zero specificity, so your own background wins.

Limits: a scoped light region inside a dark page uses the framework's light seeds, not a brand theme's; a theme's own dark-mode overrides apply only where data-theme and data-mode sit on the same element (or on <html>). Component tokens that alias colours at :root (for example a button background) keep the page's values.

Vanilla Breeze Attributes

Vanilla Breeze uses data attributes on the <html> element to control theming and layout.

data-mode

Controls light/dark mode. When omitted, mode follows the user's system preference (auto).

Value Description
(omitted) Auto mode - follows system preference via prefers-color-scheme
light Force light mode regardless of system preference
dark Force dark mode regardless of system preference

data-theme

Sets the color theme. Accepts a space-separated list of theme tokens. When omitted, uses the default purple/blue theme. See the Themes page for the full catalogue and live previews.

Category Values
Extreme swiss, brutalist, organic, kawaii, cyber, terminal, 8bit, nes, win9x, vaporwave, art-deco, bauhaus, memphis, editorial, claymorphism, neumorphism, glassmorphism, cottagecore, rough, genai, and more
Editor solarized, dracula, nord, gruvbox, rose-pine, tokyo-night, catppuccin-mocha, catppuccin-latte, catppuccin-frappe, catppuccin-macchiato, dusk, midnight, dawn, high-noon
Industry government, financial, clinical, startup, modern, minimal, classic
Accessibility a11y-high-contrast, a11y-large-text, a11y-dyslexia

Themes can be combined. Accessibility themes layer on top of personality or extreme themes. The [data-theme~="name"] word-match selector enables this stacking — each token is matched independently, so data-theme="modern a11y-large-text" activates both rulesets simultaneously. Colour accents are a separate attribute, data-accent.

Which CSS each value needs:

  • Bundled: modern, minimal, classic and the three a11y-* themes ship inside vanilla-breeze.css and vanilla-breeze-core.css. The attribute alone is enough.
  • Everything else loads on demand: the JS bundle's ThemeManager fetches themes/<name>.css from the CDN folder the bundle came from (default /cdn/, override with window.__VB_THEME_BASE) when it sees the value. Without JS, link the file yourself (<link rel="stylesheet" href="/cdn/themes/swiss.css">, or vanilla-breeze/themes/swiss from npm). Order does not matter: theme files declare @layer bundle-theme themselves.
  • Pack themes: kawaii and memphis are fuller as packs (/cdn/packs/kawaii.full.css + .full.js) with effects and components on top of the theme tokens.
  • Fixed schemes: some themes ignore data-mode. a11y-dyslexia is light-only (a warm paper surface), and dark-first themes such as the editor palettes render dark whatever the mode. Check the Themes page previews.

data-accent

Colour accent: swaps the brand hues (primary, secondary, accent) and keeps everything else — shape, shadows, typography. A separate axis from data-theme, so it tints the seed-based themes (default, modern, minimal, classic); themes that fix their own palette keep it. Works on <html> or on any element, including inside a dark page (the dark-mode seed variants follow).

Values: ocean, forest, sunset, amber, emerald, lavender, indigo, slate, rose, coral. See Themes for swatches.

<theme-picker> and ThemeManager.setAccent() write the same attribute on <html>.

data-page

Identifies which site section a page belongs to. This is a scoping hook for your own CSS — VB does not define a fixed enumeration. Values are whatever makes sense for your site (e.g., docs, lab, blog, admin).

Aspect Detail
Purpose Section-scoped CSS via attribute selectors
Values User-defined. Examples: docs, lab, blog
Set by Template layout or page front matter (dataPage variable)
/* Site-specific CSS can target sections */ [data-page="docs"] .sidebar { position: sticky; top: var(--size-m); } [data-page="lab"] main { max-inline-size: none; }

For page-level grid layouts, use data-page-layout on <body> instead.

data-fluid

Activates fluid scaling. Typography and spacing scale continuously between 320px and 1440px viewports. Always present in the Vanilla Breeze base layout.

Value Description
(boolean / omitted value) Default preset — Major Second → Major Third type ratio
default Same as boolean — explicit default preset
compact Tighter spacing and smaller type ratio (Minor Second → Minor Third)
spacious Generous spacing and larger type ratio (Minor Third → Perfect Fourth)

data-backdrop and data-backdrop-chrome

data-backdrop turns the page into a canvas: the body gets padding and a tinted background, and its direct header, nav, main, aside and footer children become rounded, elevated cards. Values: (boolean) or default, flush (no gap, flat), elevated (stronger shadows).

data-backdrop-chrome decides how the header and footer sit on that canvas. Space-separated: card (default, chrome is a card like the rest), stretch (full-width bars), integrated (chrome sits on the canvas without a card), plus fixed to pin the header. It only has an effect together with data-backdrop.

See body for how the backdrop interacts with the page background.

data-sticky

Opts the page into VB's sticky header system: the JS bundle marks the site banner header sticky and keeps its height in --sticky-offset on :root so anchors, sidebars and other sticky elements offset below it. <settings-panel> toggles it. Details on the data-sticky page.

data-scrollbar

Scrollbar styling, on <html> for the page scrollbar or on any scroll container. Values: hidden, auto (full-width scrollbar), primary (brand-coloured thumb), minimal (thin, border-coloured). Without it, the page uses the themed thin scrollbar from the reset.

Authored attributes and saved preferences

Attributes you write on <html> are the page's defaults. ThemeManager (in every JS bundle) only replaces data-fluid, data-accent, data-border-style, data-icon-set, data-backdrop, data-backdrop-chrome or a brand in data-theme when the visitor has chosen something else in <theme-picker> / <settings-panel> (a saved preference) or a setter is called. Resetting the settings restores your values. data-mode is always written: it reflects the effective light/dark mode.

data-motion-reduced

User-toggled reduced motion, a per-site complement to the prefers-reduced-motion media query. When present on <html>, VB:

  • sets every --duration-* token to 0ms, so token-driven transitions finish instantly;
  • turns smooth anchor scrolling off (scroll-behavior: auto);
  • disables view-transition animations, the theme colour transition, and the effects that check it (glitch, typewriter cursor, gradient text, spotlight, pack effects).

Animations with hard-coded durations in your own CSS are not affected; read the attribute in your selectors (:root[data-motion-reduced] .x { animation: none }). <settings-panel> writes it from its motion switch and the docs boot script restores it before first paint.

data-border-style

Overrides the global border aesthetic. Can also be set on any descendant element for scoped styling. It restyles bordered containers that carry their own padding (.card and the preview panels); forms, blockquotes and other bare elements keep their own borders.

Value Description
cleanCrisp, minimal borders (default)
sharpZero-radius hard edges
softLarge radius, gentle rounding
sketchHand-drawn look with slight irregularity
roughRough, imperfect edges
markerThick marker-stroke borders
kawaiiRounded, playful, pastel-friendly
pixelStepped pixel-art corners
neonGlowing neon border effect
doubleClassic double-line border
bubblyExtra-round, bubbly shapes
organicNatural, irregular organic shapes

data-icon-set

Sets the default icon library for all <icon-wc> components on the page. Defaults to lucide when omitted. Individual <icon-wc> elements can override this with their own set attribute.

data-icon-path

Sets the base path for loading icon SVG files. Useful when icons are hosted at a custom CDN path. Individual <icon-wc> elements can override with their own path attribute.

data-ruby

Controls the visibility of ruby annotations (<rt> elements). Annotations are visible by default. data-ruby also works on any other element (a section, a paragraph, the <ruby> itself); the nearest one wins. See <ruby>.

Value Description
(absent) Annotations visible (browser default)
show Annotations visible; undoes an outer hide or auto
hide Annotations visually hidden, still in the accessibility tree
auto Show annotations whose own language is ja, zh, ko, yue or wuu; visually hide the rest

data-print-raw

When present, disables all Vanilla Breeze print optimizations. The page prints as-is without VB's @media print adjustments. Set automatically by the <print-page> component in "raw" mode.

Developer Utilities

These attributes are for development and debugging only. Both need the dev add-on: vanilla-breeze-dev.css (and vanilla-breeze-dev.js for content-model checks); the main bundles ignore them.

data-debug

Activates debug mode. Shows an overlay banner and highlights HTML content model violations (e.g., block elements inside inline elements). Can also be activated with localStorage.setItem('vanillaBreeze.debug', 'true').

data-wireframe

Renders the page in wireframe view, stripping visual styling to expose layout structure.

midMedium fidelity — visible element boundaries
hiHigh fidelity — detailed wireframe with labels
annotateAnnotated wireframe with element names

Theme Manager

Every JS bundle includes ThemeManager, which persists theme choices (through VBStore, key vb:theme:current) and writes the root attributes. The bundle runs init() on load, so pages just call the setters. Most sites never touch it directly: <theme-picker> and <settings-panel> drive it.

It is available as window.VB.themeManager and as the ThemeManager export of vanilla-breeze.js, vanilla-breeze-core.js and vanilla-breeze-autoload.js.

const ThemeManager = window.VB.themeManager; // or: import { ThemeManager } from 'vanilla-breeze'; // Change mode ThemeManager.setMode('dark'); // Force dark ThemeManager.setMode('light'); // Force light ThemeManager.setMode('auto'); // Follow system // Change brand theme (loads /cdn/themes/<name>.css when needed) await ThemeManager.setBrand('swiss'); await ThemeManager.setBrand('default'); // Back to the page's default // Change colour accent (writes data-accent on <html>) ThemeManager.setAccent('ocean'); ThemeManager.setAccent('default'); // No accent // Toggle between light and dark ThemeManager.toggleMode(); // Forget saved choices; the page's authored attributes come back ThemeManager.reset(); // Get current state const { mode, brand, accent, fluid, effectiveMode } = ThemeManager.getState(); // Listen for changes window.addEventListener('vb:theme-change', (e) => { console.log(e.detail); // { mode, brand, accent, fluid, …, effectiveMode } });

ThemeManager also keeps <meta name="theme-color"> (when the page has one) in step with the page's actual background after every mode or theme change.

CSS Reset

VB's reset applies these rules to <html> automatically:

Property Effect
text-size-adjust: 100% Stops automatic landscape font inflation on mobile browsers without blocking the user's own text zoom
scrollbar-width: thin Thin scrollbars on supported browsers
scrollbar-color Themed scrollbar thumb and track via custom properties
background var(--page-bg-color, var(--color-surface)), so the canvas (overscroll areas included) follows the theme and mode
cursor var(--cursor-custom-default), a hook for themes with custom cursors
scroll-behavior: smooth Smooth anchor scrolling (on html:focus-within only)

Smooth scrolling is turned off when prefers-reduced-motion: reduce matches or data-motion-reduced is set.

html { text-size-adjust: 100%; /* no landscape inflation, zoom still works */ scrollbar-width: thin; scrollbar-color: var(--scrollbar-thumb) var(--scrollbar-track); background: var(--page-bg-color, var(--color-surface)); cursor: var(--cursor-custom-default); } html:focus-within { scroll-behavior: smooth; /* smooth anchor scrolling */ } @media (prefers-reduced-motion: reduce) { html:focus-within { scroll-behavior: auto; /* respect motion preference */ } } :root[data-motion-reduced], :root[data-motion-reduced]:focus-within { scroll-behavior: auto; /* the per-site switch too */ }

Not in the reset, but recommended: html { scrollbar-gutter: stable; }. VB's modal dialogs lock page scrolling while open; with a reserved gutter the page does not shift sideways when the scrollbar disappears.

System Preference Detection

VB responds to these @media queries at the :root level. No configuration needed — these activate automatically based on the user's system settings.

Query Effect
prefers-color-scheme Automatic light/dark via light-dark() color function
prefers-reduced-motion Sets all --duration-* tokens to 0ms and turns off smooth scrolling (data-motion-reduced does the same per site)
prefers-contrast: more Stronger borders, bolder text colors, wider focus rings
prefers-reduced-transparency Fully opaque overlays, no backdrop-filter
forced-colors: active Maps tokens to Windows system colors (Canvas, CanvasText, etc.)
pointer: coarse 44px minimum height on buttons and inputs (--size-touch-min)
hover: none Disables hover-based motion effects

The data-mode attribute overrides prefers-color-scheme, and data-motion-reduced complements prefers-reduced-motion for per-site control.

Custom Properties at :root

VB defines its design token system as custom properties on :root. This table shows the major categories — see the Design Tokens page for the full reference.

Category Example Properties
Colors --color-primary, --color-text, --color-surface
Typography --font-sans, --font-mono, --line-height-normal
Spacing --size-xs through --size-3xl
Borders --border-radius, --border-width, --color-border
Shadows --shadow-xs through --shadow-xl
Motion --duration-fast, --duration-normal, --ease-default
Sizing --size-touch-min, --focus-ring-width

Two standalone :root properties are worth noting: color-scheme: light dark enables the light-dark() CSS function for automatic mode switching, and interpolate-size: allow-keywords enables smooth transitions to and from keyword sizes like auto.

Standard Attributes

lang

Sets the document language. Required for accessibility — screen readers use it to select the correct pronunciation engine.

VB's i18n layer responds to lang through :lang() selectors, automatically applying script-appropriate typography:

Language Effect
zh, ja, ko CJK font family, line-height: 1.8, word-break: break-all. Japanese adds font-feature-settings: "palt" for proportional punctuation.
ar, fa, ur, ps Arabic script font family, line-height: 1.9, slight word-spacing
he, yi Hebrew font family, line-height: 1.75
th Thai font family, line-height: 2, no word breaks
hi, mr, sa, ne Devanagari font family, line-height: 1.75

Additional lang-driven behaviors:

  • Quotation marks: The <q> element renders locale-correct quotes (English “”, French «», Japanese 「」, German „“, Russian «»)
  • Ruby annotations: With data-ruby="auto", only annotations in a CJK language are shown
  • Translation protection: there is no CSS way to stop machine translation — put the HTML translate="no" attribute on <code>, <pre> and other content that must not be translated

dir

Sets the text direction. VB's layouts and components are written with CSS logical properties (inline-start/inline-end rather than left/right), so dir="rtl" mirrors them. Check third-party widgets and your own CSS for physical properties.

Value Description
ltr Left-to-right (default for most languages)
rtl Right-to-left
auto Direction determined by the first strong character. Useful for user-generated content (chat messages, comments, form inputs).

VB adds no bidi rules of its own: the browser's stylesheet already isolates every element with a dir attribute (unicode-bidi: isolate), and <bdi> / <bdo> work natively.

Accessibility

  • Always set lang: Screen readers use this to select the correct pronunciation. VB's i18n layer also reads it to apply script-specific typography, locale-aware quotation marks, and ruby annotation visibility.
  • Theme considerations: The data-mode attribute works with color-scheme CSS to ensure proper contrast and respect user preferences
  • Motion preferences: Vanilla Breeze respects prefers-reduced-motion at the system level. The data-motion-reduced attribute provides a per-site opt-out (durations, smooth scrolling, view transitions and effects) for users who want motion elsewhere but not on your page.
  • Accessibility themes: The a11y-high-contrast, a11y-large-text, and a11y-dyslexia theme tokens can be combined with any brand theme via data-theme.
  • System preferences: VB automatically responds to prefers-contrast, prefers-reduced-transparency, forced-colors, and pointer: coarse — no opt-in required.
  • Touch targets: On coarse-pointer devices, buttons, selects and inputs get a 44px minimum height (the WCAG 2.5.5 AAA figure; 2.5.8 AA asks for 24px). Links and inline sizes are up to you.
  • Text zoom: the reset uses text-size-adjust: 100%, not none, so mobile text zoom keeps working.
