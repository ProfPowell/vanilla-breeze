Description

The <sup> element displays inline text as superscript. VB always renders it at 0.75em, raised with a relative offset and line-height: 0, so the superscript does not push the line taller. This works in every font. Fonts with designed OpenType superscript glyphs can opt in to them with data-variant="opentype". VB also styles footnote patterns with sup.footnote-ref and .footnotes.

When to Use

  • Exponents: E = mc2, r2
  • Ordinal numbers: 1st, 2nd, 3rd
  • Footnote references: Inline citation markers
  • Trademark symbols: ProductTM, Brand®

Examples

E = mc2

Area = πr2

1st place gold, 2nd silver, 3rd bronze.

According to studies[1], this approach is more effective[2].

For automatic footnote management, use the <foot-notes> web component which handles numbering, linking, and accessibility.

OpenType glyphs (opt-in)

Some fonts include designed superscript glyphs. Add data-variant="opentype" to use them with font-variant-position: super. VB then removes its own size and offset, because the glyphs are already small and positioned.

E = mc2

Only use this when you know the current font has the glyphs. Browsers do not synthesise them, and @supports cannot detect them. In a font without them (Georgia, Verdana, Courier New and most display fonts), opted-in text renders at full size on the baseline. That is why the default reduced size and offset are always applied.

CSS Reference

sub, sup { font-size: 0.75em; line-height: 0; /* keeps the line box from growing */ position: relative; vertical-align: baseline; } sub { inset-block-end: -0.25em; } sup { inset-block-end: 0.5em; } /* Opt-in: the font's own OpenType subs/sups glyphs */ :is(sub, sup)[data-variant~="opentype"] { font-size: inherit; position: static; inset-block-end: auto; } sub[data-variant~="opentype"] { font-variant-position: sub; } sup[data-variant~="opentype"] { font-variant-position: super; }

The size and offset always apply. An earlier version reset them inside @supports (font-variant-position: super), but that check only shows the browser understands the property, not that the font has superscript glyphs. In most fonts, exponents and ordinals then rendered at full size on the baseline.

sup.footnote-ref { font-weight: 500; /* size comes from sup: 0.75em, once */ & > a { text-underline-offset: 0.15em; padding: 0.2em 0.15em; /* larger hit area, same line box */ } } :is(ol, ul).footnotes { font-size: var(--font-size-s); color: var(--color-text-muted); border-block-start: var(--border-width-thin) solid var(--color-border); padding-block-start: var(--size-m); margin-block-start: var(--size-xl); } .footnotes a[href^="#fnref"] { text-decoration: none; font-size: 0.85em; }

Accessibility

  • Screen readers may not announce superscript formatting
  • For footnotes, the link text (e.g., "[1]") provides navigable context
  • The .footnotes list uses an <ol> so screen readers announce numbered items
  • Back-to-reference links (↩) let users return to where they left off. The arrow has no useful name of its own (screen readers say “leftwards arrow with hook” or nothing), so give each link an aria-label such as “Back to reference 1”
