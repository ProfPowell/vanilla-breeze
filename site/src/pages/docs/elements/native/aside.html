Usage

Use the <aside> element for:

  • Sidebar navigation or supplementary content
  • Pull quotes that highlight key text from an article
  • Related links or "See also" sections
  • Advertising or promotional content
  • Glossary definitions or explanatory boxes

Content in an aside should be related to the surrounding content but not essential to understanding it. The page should make sense if the aside is removed.

For alert-style notifications (warnings, tips, success messages, errors), use <status-message> instead.

.float

Floating aside for pull quotes that flow with text. It floats to the inline end at 40% of the container's inline size. Below 40rem it un-floats and spans the full width, so the quote never gets too narrow to read.

Lorem ipsum dolor sit amet, consectetur adipiscing elit...

"Design is not just what it looks like and feels like. Design is how it works."

— Steve Jobs

Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris...

Content after a floated aside wraps around it. If a following block (a heading, a figure, a new section) must start below the quote, give it clear: both.

.sidenote

Margin annotation that floats alongside text on wide viewports. On narrow viewports, collapses to a bordered inline block. Requires the parent container to have margin space (e.g., inside <layout-text>).

Place the aside before the paragraph it annotates. A float starts at its own position in the flow, so putting it first lines the note up with the top of that paragraph.

1831–1836. The ship was a Cherokee-class 10-gun brig-sloop commanded by Captain Robert FitzRoy.

Darwin's voyage on the Beagle lasted nearly five years...
Tip: For automated sidenotes with numbering and progressive enhancement, use <foot-notes data-mode="sidenotes"> instead. The .sidenote class is for manual, CSS-only placement.

Accessibility

  • An aside is a complementary landmark only when it is scoped to <body> or <main>, or when it has an accessible name. Inside <article>, <section>, <nav> or another <aside>, an unnamed aside is exposed as a generic element and does not appear in landmark navigation.
  • When you want the aside to be a landmark (for example a page sidebar), name it with aria-labelledby pointing at its heading, or with aria-label. Give each landmark aside a distinct name.
  • Small inline asides such as pull quotes, notes and sidenotes do not need to be landmarks. Leave them unnamed rather than adding a label that means nothing.
  • Include a heading to label longer asides
  • Keep aside content concise and focused on a single topic
