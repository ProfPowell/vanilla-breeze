Description

The <blockquote> element represents a section quoted from another source. VB styles it with an inline-start border and muted italic text.

The HTML specification is explicit that attribution for the quotation, if any, must be placed outside the <blockquote> element. The recommended pattern is a <figure class="quote"> that holds the blockquote and a <figcaption> with the attribution. VB prefixes the caption with an em dash that is decorative only (it is not read out by assistive technology).

VB also adds typographic refinements: hanging-punctuation: first last for Safari, and a de-emphasis reset for <em>/<i> inside blockquotes (since the blockquote is already visually offset, double-italic would be redundant).

When to Use

  • Extended quotations: Quotes from books, articles, speeches
  • Testimonials: Customer quotes and endorsements, with the customer named in a <figcaption>
  • Academic citations: Referenced passages with source attribution
  • Epigraphs: Opening quotes in articles or chapters

When NOT to Use

  • For short inline quotes — use <q>
  • For pull quotes that repeat text from your own page — that is not a quotation from another source; use <aside class="float">
  • For content that isn't a quotation (even if you want the visual style)
  • For indenting content — use CSS margins or <layout-stack>

Attribution Patterns

Put the attribution in a <figcaption> next to the blockquote, inside <figure class="quote">. Use the <cite> element for the title of the work, not for the person's name.

PatternUse Case
<figcaption>Author, <cite>Work</cite></figcaption> Author + work (recommended)
<figcaption>Author Name</figcaption> Person only
<figcaption><cite>Work Title</cite></figcaption> Work title only
cite="URL" attribute on <blockquote> Machine-readable source URL (not displayed) — see the cite attribute

Legacy: attribution inside the blockquote

Older markup often puts a <footer> or <cite> inside the blockquote. That makes the attribution part of the quoted content, which the specification does not allow, so prefer the figure pattern for new content. VB still styles the legacy form so existing content does not break: a <footer> or <cite> that is a direct child of the blockquote becomes a block-level line with an em dash. A <cite> nested inside that footer, or used inline in the quoted prose, keeps its normal inline styling.

Pull Quotes

A pull quote repeats a line from the article you are already reading to draw the eye. Because it does not come from another source, it is not a <blockquote>. Use <aside class="float">, which floats the excerpt beside the text:

Article text…

Good defaults beat clever configuration.

More article text, including the sentence “Good defaults beat clever configuration.”

Screen reader users will hear the repeated sentence twice. If that is a concern, give the aside aria-hidden="true", since the same text is in the article body.

Academic Citations

For academic and research writing, use the cite attribute with a DOI or URL for machine-readable provenance, and put the full bibliographic reference in the figcaption:

The cite attribute is not displayed, and screen readers do not announce it, but it is available to scripts, search engines, and citation tools. Future VB features may auto-generate bibliography sections from cite attributes.

Foreign Language Quotes

Use the lang attribute when quoting in another language. It lets screen readers switch pronunciation and lets the browser choose the right hyphenation rules. Inside the quote, VB's i18n system gives <q> the locale's quotation marks (for example, «guillemets» for French). Locale-specific font families and line heights apply only to the scripts that need them: Chinese, Japanese, Korean, Arabic-script languages, Hebrew, Thai and Devanagari languages. A French quote keeps the page's font.

CSS Reference

blockquote { padding-inline-start: var(--size-m); border-inline-start: var(--border-width-thick) solid var(--color-border); color: var(--color-text-muted); font-style: italic; } /* Recommended attribution: figure.quote > figcaption (figure/styles.css) */ figure.quote { & > blockquote { margin: 0; } & > figcaption { font-style: normal; &::before { content: "— "; content: "— " / ""; /* decorative: empty alt text */ } } } /* Legacy attribution: direct-child footer or cite only */ blockquote > footer, blockquote > cite { display: block; margin-block-start: var(--size-s); font-style: normal; font-size: var(--font-size-s); &::before { content: "— "; content: "— " / ""; } }

Prose Refinements

/* Hanging punctuation for typographic refinement (Safari) */ blockquote { hanging-punctuation: first last; } /* Italic de-emphasis inside blockquotes */ :where(blockquote) :where(i, em) { font-style: normal; font-weight: var(--font-weight-medium); }
FeatureImplementation
Inline-start border border-inline-start (RTL-safe)
Em-dash attribution ::before { content: "— " / "" } on figure.quote > figcaption and on direct-child footer/cite (silent alt text)
Hanging punctuation hanging-punctuation: first last (progressive, Safari)
Italic de-emphasis em/i inside blockquote reset to normal + medium weight

Accessibility

  • Blockquotes are exposed with a blockquote role. Some screen readers announce the start and end of a quote, and some offer a shortcut to jump between quotes; others read it as ordinary text.
  • The cite attribute is not announced, so always give visible attribution for external quotations
  • Keep the attribution in the <figcaption>, outside the quote, so it is not presented as part of the quoted words
  • The em dash before the attribution is decorative and has empty alternative text, so it is not read out
  • Use lang for quotes in different languages so screen readers switch pronunciation
