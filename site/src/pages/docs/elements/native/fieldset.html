When to Use

  • Grouping related form fields (e.g., billing address, shipping address)
  • Radio button or checkbox groups that belong together
  • Sections of a multi-part form
  • Any time you need to provide a group label for accessibility

Always include a legend as the first child to provide a caption for the group.

Basic Usage

A fieldset with a legend creates a visually and semantically grouped form section.

Contact Information

Style Variants

Default (Bordered)

Standard fieldset with a visible border and legend that breaks the border line.

data-variant="minimal"

Borderless fieldset for subtle grouping. The legend appears as a heading. (This replaces the former .minimal class.)

Notification Preferences

Radio Button Groups

Fieldset is essential for grouping radio buttons. Screen readers will announce the legend before each radio option.

Preferred Contact Method

Disabled Fieldset

The disabled attribute on a fieldset disables all form controls within it. VB marks the group with muted text and a dashed border. The fieldset itself is not faded: its controls are disabled too and already dim themselves (buttons at half opacity, inputs on the raised surface), so fading the fieldset as well would compound to an unreadable quarter opacity. In forced-colors mode the group uses the system GrayText colour.

Disabled Section
Note: No pointer-events: none is needed — the browser natively prevents interaction with controls inside a disabled fieldset. The toggle button in the demo is placed outside the fieldset so it remains clickable.

Status Variants

Use data-status to apply a subtle border tint indicating the state of the fieldset's contents. Uses the same vocabulary as inline semantics.

Pair the status with words. The tint is colour only, which colour-blind users and screen readers do not get. Say the state in the legend (as the demo does: "Payment Complete", "Validation Errors") or in a message inside the group. In forced-colors mode VB switches to a heavier border whose style differs per state: solid for success, dotted for warning, double for error.

Checkbox Group Validation

On a fieldset of checkboxes, data-min-checked and data-max-checked set how many boxes must be ticked. The form coordinator checks the count, sets data-invalid on the fieldset when it is out of range, and writes the message into the fieldset's direct-child <output>. Override the default messages with data-message-min-checked and data-message-max-checked.

Topics

Do not set data-invalid by hand: the coordinator (and form-field styles) provide both the red border and the text message, so the error is never conveyed by colour alone. Keep the <output> in place for that message.

Accessibility Notes

  • Always include a legend: The legend provides the accessible name for the group
  • Legend must be first child: For proper rendering, legend must be the first element inside fieldset
  • Screen reader behavior: The legend is announced before each control in the group
  • Required for radio groups: Radio buttons should always be in a fieldset for accessibility
  • Avoid nesting too deep: Limit nesting to maintain comprehension
  • Status is not colour alone: Pair data-status with legend text or a message; forced-colors mode gets a border-style cue

CSS Reference

fieldset { border: var(--border-width-thin) solid var(--color-border); border-radius: var(--radius-m); padding: var(--size-m); margin: 0; } /* Minimal/borderless fieldset */ fieldset[data-variant="minimal"] { border: none; padding: 0; } fieldset[data-variant="minimal"] > legend { padding: 0; margin-block-end: var(--size-s); font-size: var(--font-size-m); } /* Disabled: dim once (controls dim themselves) */ fieldset:disabled { color: var(--color-text-muted); } fieldset:disabled:not([data-variant="minimal"]) { border-style: dashed; } /* Status border variants */ fieldset[data-status="success"] { --fieldset-status-color: var(--color-success); } fieldset[data-status="warning"] { --fieldset-status-color: var(--color-warning); } fieldset[data-status="error"] { --fieldset-status-color: var(--color-error); } fieldset[data-status] { border-color: color-mix(in oklab, var(--fieldset-status-color) 40%, var(--color-border)); } /* Forced colors: a non-colour cue per state */ @media (forced-colors: active) { fieldset:is([data-status], [data-invalid]) { border: 3px solid CanvasText !important; } fieldset:is([data-status="error"], [data-invalid]) { border-style: double !important; } } legend { padding-inline: var(--size-s); font-weight: 600; font-size: var(--font-size-s); }
