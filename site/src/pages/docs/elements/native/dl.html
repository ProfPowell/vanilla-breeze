Description

The <dl> element (description list, formerly "definition list") contains groups of terms (<dt>) and their descriptions (<dd>). It represents an association list of name-value pairs.

Unlike <ul> and <ol>, which use <li> elements, definition lists use the <dt> and <dd> pair structure.

When to Use

  • Glossaries — Terms and definitions
  • Metadata — Author, date, category displays
  • FAQ sections — Question-answer pairs
  • Product specifications — Specs and details
  • Contact information — Label-value pairs

When Not to Use

  • For simple sequential items — use <ol>
  • For unordered collections — use <ul>
  • For tabular data with multiple columns — use <table>

Striped Variant

Add the data-striped attribute for alternating row backgrounds, making it easier to scan long definition lists.

On flat lists the stripe follows each odd <dt> and the run of up to four <dd> after it. Because flat striping counts terms, a group with several <dt> elements shifts the alternation — wrap each group in <div> (or <dl-item>) and the whole group is striped as one row.

Entries hidden with the hidden attribute (for example by a filter) are skipped, so the alternation holds on the rows that remain. The stripe is the --color-row-stripe token, the same wash as table[data-striped]; set it once to restyle both.

Layout Variants

Attributes on <dl> switch it to built-in key-value layouts. They work on flat pairs and on <div> or <dl-item> group wrappers.

Attribute Effect
data-variant="horizontal" Term column + description column; every <dd> sits in the description column. Stacks below 24rem of available width.
data-variant="stacked" Muted label above its value(s), no indent
data-bordered Separator lines between wrapped groups
data-density="compact" Tighter spacing (not data-layout-density, which swaps the spacing scale for a whole region)

CSS Properties

dl { display: block; } dt { font-weight: 600; } dd { margin-inline-start: var(--size-l); } /* Space between groups — flat pairs, and wrapped groups in a plain dl (one without a class or data-layout) */ dd + dt, :where(dl:not([class], [data-layout])) > :is(div, dl-item) + :is(div, dl-item) { margin-block-start: var(--size-m); } /* Striped variant — flat pairs */ dl[data-striped] > dt, dl[data-striped] > dd { padding-inline: var(--size-s); padding-block: var(--size-2xs); } dl[data-striped] > dd { margin-inline-start: 0; padding-inline-start: var(--size-xl); } dl[data-striped] > dt:nth-of-type(odd), dl[data-striped] > dt:nth-of-type(odd) + dd, dl[data-striped] > dt:nth-of-type(odd) + dd + dd /* … up to four dd */ { background: var(--color-surface-raised); } /* Striped variant — wrapped groups */ dl[data-striped] > :is(div, dl-item) { padding-inline: var(--size-s); padding-block: var(--size-2xs); } dl[data-striped] > :is(div, dl-item):nth-of-type(odd) { background: var(--color-surface-raised); }

Accessibility

Screen Reader Behavior

  • Exposed as a list (or "description list") in browser accessibility trees; whether a screen reader announces it as such, and with what count, varies by browser and screen reader
  • <dt> is exposed with the term role and <dd> with the definition role
  • Support for announcing the term–description association, or for jumping between groups, is inconsistent — don't rely on it to convey meaning the text itself doesn't

Grouping with div

HTML allows wrapping each <dt>/<dd> group in a <div> for styling purposes. In a plain <dl> wrapped groups get the same spacing as flat pairs (a <dl> with a class or data-layout is left to manage its own spacing), and every variant applies to them — this is especially useful with the striped variant when groups have several terms or descriptions. VB's <dl-item> is a named alternative wrapper, but it is not conforming HTML.
