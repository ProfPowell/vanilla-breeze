Usage

Use the <main> element for:

  • The primary content area of a page
  • Content that is unique to this specific page
  • The target for skip links ("Skip to main content")

Important: There should only be one visible <main> element per page. If using multiple for SPA views, only one should be visible at a time (hide others with hidden attribute).

In VB layouts

  • Query container: every <main> gets container-type: inline-size, so components inside respond to main's width with @container queries rather than the viewport's.
  • Page grid: as a direct child of a data-page-layout body, main goes to grid area body-main and is named region-main, so you can write @container region-main (width > 40rem).
  • Skip link target: give main id="main" and put a skip link first in the body. Copy the markup and styles from Accessibility Utilities › Skip link; VB does not ship a .skip-link class.

Accessibility

  • The main element creates a main landmark for screen reader navigation
  • Only one visible main element per page (others must have hidden attribute)
  • Skip links should target the main element: <a href="#main">Skip to main content</a> (see the skip link recipe)
  • Add id="main" so the skip link has a target. Optionally add tabindex="-1" so following the link focuses main itself, not just moves the Tab starting point; some screen readers only follow real focus
  • Main should not be nested inside article, aside, footer, header, or nav
