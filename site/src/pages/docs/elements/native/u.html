Description

The <u> element represents an "unarticulated annotation": a non-textual annotation that is rendered visually but not spoken. HTML5 redefined it from the old "underline" element to serve two specific use cases named in the spec: marking misspelled words, and the proper-name mark in Chinese text.

VB styles it with a wavy underline in var(--color-error), the familiar spell-check convention. The colour comes from the theme, so it follows light, dark and custom themes.

In Chinese, Japanese and Korean text (lang="zh", ja, ko) the same element draws a solid underline in the text colour, placed under the line. This is the proper-name mark (專名號). A red wavy line there would make every personal or place name look like a typo, and would clash with VB's CJK <cite>, which uses a wavy line as the book-title mark. Romanised tags (zh-Latn, ja-Latn, ko-Latn) are Latin text and keep the spell-check style.

When to Use

  • Spelling errors: Mark misspelled words in educational content
  • Spell-check demonstrations: Show how spell-checking works
  • Chinese proper names: The proper-name mark for people, places and dynasties
  • Grammar examples: Highlight errors for teaching purposes

When NOT to Use

  • For emphasis — use <em> or <strong>
  • For plain underlining — readers take an underline for a link. Use CSS text-decoration only where the context makes it clear
  • For book titles — use <cite>
  • For inserted text — use <ins>

Examples

Common misspellings: recieve (receive), seperate (separate), occured (occurred).

李白是唐代著名诗人。

VB Text Decorations

VB gives each decorated text element its own treatment, so readers can tell their meaning apart at a glance. Underlines and line-throughs are listed together:

Element Style Color Use Case
<u> Wavy underline var(--color-error) Spelling errors, annotations
<u> in CJK Solid underline, under the line currentColor Proper-name mark
<a> Solid underline (1px→2px on hover) var(--color-interactive) Hyperlinks
<abbr> Dotted underline var(--color-text-muted) Abbreviations with tooltip
<ins> Solid bottom border var(--color-success) Inserted text (editorial)
<s> Line-through var(--color-text-muted) No longer relevant
<del> Line-through + background var(--color-error) Deleted text (editorial)

CSS Reference

u { text-decoration: underline; text-decoration-style: wavy; text-decoration-color: var(--color-error); } /* Chinese, Japanese, Korean: proper-name mark */ u:is(:lang(zh), :lang(ja), :lang(ko)):not(:lang(zh-Latn), :lang(ja-Latn), :lang(ko-Latn)) { text-decoration: underline solid currentColor; text-underline-position: under; text-decoration-thickness: from-font; }

The wavy style matches the spell-check convention used by browsers, word processors and IDEs. To change the colour, set --color-error in your theme.

Forced colours: in Windows High Contrast and other forced-colour modes the colour is replaced with CanvasText, but the wavy shape stays. It still differs from a link, which is a solid underline in LinkText.

Accessibility

  • Screen readers typically do not announce the underline
  • The visual is a cue only — provide text context for important annotations
  • For educational content, add visually-hidden context:

The word "recieve" (misspelled) should be spelled "receive."

Related

  • <ins> — Inserted text (success-coloured border underline)
  • <del> — Deleted text (error-coloured strikethrough + background)
  • <s> — No longer relevant (muted strikethrough)
  • <a> — Hyperlinks (solid underline in the link colour)
  • <abbr> — Abbreviations (dotted muted underline)
  • <cite> — Work titles (wavy book-title mark in CJK text)
  • <mark> — Highlighted text (background, not underline)
