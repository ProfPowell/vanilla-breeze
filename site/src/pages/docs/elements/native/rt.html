Description

The <rt> element specifies the ruby text — the small annotation that appears above (or beside) base text. It must be contained within a <ruby> element.

VB styles <rt> at 0.5em with centered alignment. Annotations are visible by default on every page. CJK readings get the CJK script face; romanised readings tagged -Latn (pinyin, romaji, Jyutping) keep the body face. data-ruby on any ancestor can hide them — see Visibility Control.

When to Use

  • Inside <ruby> to provide pronunciation guides
  • Japanese furigana (hiragana readings for kanji)
  • Chinese pinyin (romanized pronunciation) or bopomofo
  • Pronunciation guides for words in any language

Examples

漢字 かんじ 東京 (とうきょう) 漢 かん 字 じ 中文 zhōngwén 中 ㄓㄨㄥ

CSS Reference

rt { font-size: 0.5em; line-height: 1; ruby-align: center; } /* CJK readings: CJK script face */ rt:is(:lang(ja), :lang(zh), :lang(ko), :lang(yue), :lang(wuu)):not(:lang(ja-Latn), :lang(zh-Latn), :lang(ko-Latn), :lang(yue-Latn), :lang(wuu-Latn)) { font-family: var(--font-cjk); } /* Romanised readings (pinyin, romaji, Jyutping): body face */ rt:is(:lang(ja-Latn), :lang(zh-Latn), :lang(ko-Latn), :lang(yue-Latn), :lang(wuu-Latn)) { font-family: var(--font-sans); }

Visibility Control

<rt> is visible unless a data-ruby attribute on an ancestor (or on the <ruby>) says otherwise; the nearest one wins. hide hides every annotation visually, auto hides those whose language is not CJK, and show undoes an outer setting. See the ruby element page for details.

Accessibility

  • Screen readers handle ruby differently: some read the base text then the annotation, some read only one, and some let the user choose
  • Ruby text is valuable for language learners and those with reading difficulties
  • When data-ruby="hide" (or auto) hides an <rt>, it collapses to zero size and is clipped, but stays in the accessibility tree — it is not visibility: hidden or display: none
