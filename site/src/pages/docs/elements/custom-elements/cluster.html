Attributes

Attribute Values Default Description
data-layout-gap none, 3xs, 2xs, xs, s, m, l, xl, 2xl, 3xl s Gap between items, on the shared size scale.
data-layout-justify start, end, center, between start Main-axis distribution.
data-layout-align start, end, center, stretch, baseline center Cross-axis alignment.
data-layout-nowrap (boolean) — Keep everything on one line; no wrapping.
data-layout-overlap (bare), xs, s, m, l s Overlap items (avatar groups) in DOM order, later items on top, each with a surface-coloured ring. Forces gap 0. Bare attribute = s.
data-container (on main, article, section, aside) (boolean) — Opt a semantic child back into container queries. The layout removes container-type from such children so they size to content; this restores it.

Element or Attribute

The same layout is available as data-layout="cluster" on any element. Prefer the attribute when a semantic element already wraps the items — a <nav>, <ul>, <footer> or <menu> — so you don't add a wrapper just for layout. Use <layout-cluster> when there is no meaningful element to carry it. All data-layout-* modifiers work on both forms. See data-layout for the full comparison.

Overlap Variant

The data-layout-overlap attribute creates overlapping items — useful for avatar groups and stacked card effects. Items stay in DOM order, so what sighted users see matches reading and focus order; each later item stacks above the one before it, and a hovered or focused item is lifted to the top.

  • Gap is forced to 0. The overlap comes from negative inline margins, so data-layout-gap has no effect.
  • Surface-coloured ring. Each item gets a 2px box-shadow ring in var(--color-surface) to separate it from its neighbour. On a different background, override the ring colour on the items.
