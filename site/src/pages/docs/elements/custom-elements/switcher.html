Attributes

Attribute Values Default Description
data-layout-gap none, 3xs, 2xs, xs, s, m, l, xl, 2xl, 3xl m Gap between items, on the shared size scale.
data-layout-threshold s, m, l m Container width at which the row becomes a column: 25 / 30 / 40rem. One-off: style="--layout-threshold: 35rem".
data-layout-limit 2, 3, 4 — Force the column layout once there are more than this many items.
data-layout-reverse (boolean) — Reverse the visual order when stacked: the last item goes on top. The row keeps DOM order. Visual only; see Reverse when stacked.

Reverse when stacked

data-layout-reverse flips the order of the stacked items, so the last item ends up on top. Side by side, the items keep their DOM order. It works with or without data-layout-threshold and with data-layout-limit. A common use: put the text first in the DOM so it is read first, and show the image above it on narrow screens.

Text (first in DOM, read first)

Accessibility: the reversal is visual only. Keyboard focus and screen readers still follow the DOM order, so when stacked, focus moves from the lower item up to the upper one (WCAG 2.4.3 Focus Order). Use it only when the stacked order is presentational, for example a decorative image above text, and not when the items contain focusable controls in a meaningful sequence.
