Overview

Represents a single conversation turn. Uses a grid layout to optionally accommodate a <user-avatar> alongside a <chat-bubble>. The data-role attribute controls alignment and bubble color.

Attributes

Attribute Values Description
data-role user, agent, system Controls alignment and color
data-from string Participant id (resolved by chat-window)
data-from-label string Sender name rendered via CSS ::before. Visible on agent messages. On user messages it is visually hidden, but screen readers still read it
data-status typing, error Message state: typing dots on an empty bubble, or an error border
data-model string AI model identifier (informational)

Layout Rules

Role Alignment Bubble Style
user Right Primary color background
agent Left Sunken surface background
system Center Transparent, muted text

User Message

Right-aligned with primary color. No avatar needed. A data-from-label (e.g. "You") is hidden visually but still read by screen readers, so each turn says who sent it.

Hello, I need help with my order.

Agent Message

Left-aligned with optional <user-avatar>. The data-from-label attribute renders a sender name above the bubble.

SC

Hi! I can look into that for you.

System Message

Centered, full-width, with muted styling.

Sarah joined the conversation.

Typing State

Set data-status="typing" and give the <chat-bubble> no visible content. CSS draws animated dots while the bubble is empty or holds only a visually hidden [data-chat-typing] label. Include that label: it is the text screen readers announce, because an aria-label on chat-message is not read. When content arrives, replace the bubble's contents (the dots stop as soon as it has content) and remove the status attribute. chat-window builds this markup for you; with a custom transport, finish it with chatWindow.resolveTyping().

SC Sarah Chen is typing

The animation respects prefers-reduced-motion and degrades to a static indicator.

Model Attribution

Add data-model for AI contexts. This is informational metadata.

Here's what I found...

Error State

Messages with data-status="error" receive an error border.

This message failed to send.

Avatar Integration

Place a <user-avatar> as a direct child. The grid layout automatically creates a two-column arrangement. When no avatar is present, the layout collapses to a single column.
