Simple Alerts

Alerts can be simple single-line messages without title.

File uploaded successfully!

With Dismiss Button

Add a <button data-dismiss> as a direct child to make the message closable. Activating it hides the message with the hidden attribute (use data-dismiss="remove" to remove it from the DOM instead). If focus was inside the message, it moves to the element matched by data-dismiss-focus, or else to the next focusable element after the message, so keyboard users keep their place.

Before hiding, the message fires a bubbling, cancelable status-message:dismiss event. Call preventDefault() to keep the message (for example to animate it out yourself).

Dismissable Alert

Activate the X to dismiss.

Accessibility

Variant titles and compact text use the --color-*-text tokens, which meet WCAG AA on the subtle backgrounds; filled messages keep a visible border in forced-colours mode.

Live regions announce changes, not content that is already on the page. A message present at page load with role="status" is usually not announced, and role="alert" on page-load content is announced immediately by some screen readers and not at all by others. For messages that appear in response to an action, keep an empty role="status" (or role="alert") container in the page from the start and insert the <status-message> into it when the event happens.
