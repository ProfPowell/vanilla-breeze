Custom Elements

CSS-only layout primitives that work without JavaScript. These elements use pure CSS for layout and styling.

Custom elements in VB are CSS-only — zero JavaScript, no call to customElements.define(). The browser treats unknown tags as inline elements by default; VB's CSS gives them layout superpowers. This means they work in HTML emails, server-rendered pages, and anywhere CSS loads.

The layout primitives (<layout-stack>, <layout-grid>, <layout-sidebar>, etc.) are composable building blocks inspired by Every Layout. Nest them freely to build complex layouts from simple parts.

Most layout elements have an equal attribute form: data-layout="stack" on an <article>, <nav> or <form> applies exactly the same layout, with the same data-layout-* modifiers, without adding a wrapper. Neither form is the lesser one. Use the attribute when a semantic element is already the container, and the element when there is none. A few differ: <layout-text>'s attribute value is prose, <layout-canvas>'s attribute form is data-canvas, and <layout-imposter> and <layout-card> are element only. Each element page has an "Element and attribute forms" section; data-layout lists every value and modifier, and the Semantic Layouts guide explains when to use each.

The remaining custom elements (<form-field>, <status-message>, <user-avatar>, etc.) are UI primitives that solve common patterns with pure CSS. No JavaScript means no hydration cost and no render-blocking scripts.
