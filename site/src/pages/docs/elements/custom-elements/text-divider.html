Overview

The text-divider element creates a horizontal line with centered text. Use it for short connective labels between groups of content — the "or" between sign-in options, "continue reading", a date stamp in a feed.

It is a styled layout element with no semantics: assistive technology reads its text as plain text, with no heading or separator role. When the label names a section ("Chapter 1", "Pricing"), use a real heading instead. When there is no label, use <hr>.

Attributes

This element has no custom attributes and no JavaScript. It is styled purely through CSS.

HookEffect
--color-borderLine colour (drawn as a border-block-start, so it stays visible in forced colours)
--border-width-thinLine thickness
--color-text-mutedLabel colour
--size-mGap between the label and each line (dropped to 0 when the element is empty)

Section Breaks

A divider is not a heading. If the text names the section that follows, make it a heading so it appears in the document outline and in screen-reader heading navigation. Use a plain divider (or <hr>) only for the visual break between sections.

Variations

Keep the label short and meaningful. Decorative ornaments (asterisms, fleurons) must be hidden from screen readers, otherwise they are announced as "star star star". An empty divider renders one continuous line.

Accessibility

  • The element has no role. Its lines are CSS pseudo-elements and are not exposed; its text is read as ordinary inline text.
  • Do not use it as a heading. Section and chapter labels belong in <h2>–<h6> so they appear in heading navigation.
  • Do not add role="separator": separator children are presentational, so the label would be lost. For a thematic break without a label, use <hr>.
  • Wrap decorative ornaments in <span aria-hidden="true">.
  • Lines are drawn with borders, so they stay visible in Windows High Contrast / forced-colours mode.
