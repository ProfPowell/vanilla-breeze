Overview

The <hour-view> element is a CSS-only container that holds <calendar-event> elements within a single hour slot. It is a two-row grid — the top half of the hour (:00) and the bottom half (:30) — that fills its slot in a <day-view> or <week-view>.

    • Half-Hour Positioning

    Each <hour-view> has two rows (top half and bottom half of the hour). Events go in row 1; events with data-start="30" on the <calendar-event> go in row 2. Only "30" has an effect — there are no quarter-hour rows, so a 9:15 event sits in the top half and a 9:45 event in the bottom half.

    Double-Booking

    Add data-overlap to display multiple events side by side when two events occupy the same time slot.

    2:00 Code review 2:00 1:1 with Sarah

    Without data-overlap, events stack vertically at full width: extra events take extra rows and the hour grows to fit. With it, every event in the same half-hour row gets an equal-width column — two, three or more — and a long title is truncated rather than widening its column. :30 events stay in the bottom half.

    Generated Grids

    When <day-view> or <week-view> builds the grid from loose <calendar-event> children, it creates the <hour-view> elements for you, sets data-start="30" on events starting at :30 or later, and adds data-overlap only when two or more events fall in the same half-hour row (a 9:00 and a 9:30 event stay full width). Events with data-duration are lifted out of the hour grid and positioned across the hours they span by JavaScript, with overlapping spans laid out side by side in columns.

    Attributes

    AttributeTypeDescription
    data-overlap boolean Lay events in the same half-hour row out side by side in equal columns. Added automatically by day-view and week-view when events clash.

    Empty Hours

    Empty <hour-view> elements render as blank rows in the grid — this is correct behavior showing available time slots.
