Attributes

Attribute Values Default Description
data-layout-scrollbar (boolean) — Show a thin scrollbar. Hidden by default, except under forced colours and on touch-only devices (hover: none), where it always shows.
data-layout-gap none, 3xs, 2xs, xs, s, m, l, xl, 2xl, 3xl m Gap between items, on the shared size scale.
data-layout-padding none, s, m, l s Padding on all sides (the block padding leaves room for focus rings and shadows); the same value is the inline scroll padding, so snapped items align with the padded edge.
data-layout-item-width auto, s, m, l, xl, full auto Item width: auto (content), s / m / l / xl tokens, or full (100%).
data-layout-align start, center, end, stretch stretch Cross-axis alignment of items.
data-scroll-hint (bare), start — Fade the edges to hint at overflow (logical: mirrored in RTL). start: only the end edge ever fades.
data-container (on main, article, section, aside) (boolean) — Opt a semantic child back into container queries (the reel removes container-type from such children so they size to content).

Basic Usage

Items scroll horizontally with proximity scroll snap: the reel settles on an item edge when you stop near one, without trapping you mid-item when items are wider than the view.

Scroll Hints

Add data-scroll-hint to fade the edges of the reel, signaling there is more content to scroll. Use data-scroll-hint="start" to only fade the end edge (useful when content starts fully visible). The fade size can be customized with --scroll-hint-size.

Where scroll-driven animations are supported, each edge fades only while there is more content in that direction: the start edge stays sharp at the start, the end edge clears at the end, and a reel that does not overflow has no fade at all. Other browsers fade both edges all the time.

... ... ...

Right to Left

The reel is logical. In dir="rtl" it starts at the right edge, the scroll hints mirror (the start edge is the right-hand side), and snapping aligns items to the right.

Scrollbar Visibility

By default the scrollbar is hidden. Add data-layout-scrollbar to show it. It always shows under forced colours (Windows High Contrast) and on touch-only devices, where a hidden scrollbar removes the only scrolling affordance. Show it whenever mouse users without a horizontal wheel need to reach the overflow.

Gap Variants

The data-layout-gap attribute controls spacing between items.

Accessibility

Keyboard access and a name

A scroll container is only reachable from the keyboard when something inside it, or the container itself, can take focus. Chrome and Firefox make a scroller with no focusable content focusable automatically; Safari does not, and nobody gives the region a name. When the items hold no links or buttons, make the reel a named, focusable region. The simplest way is the attribute form on a <section>, which is a region landmark once it has a name (the demos on this page use this form):

Arrow keys then scroll it, and screen readers announce the region by name. When every item contains a link or button, the region attributes are optional: tabbing to an item scrolls it into view.

Scrollbar

The scrollbar is hidden by default but always shown under forced colours and on touch-only devices. Add data-layout-scrollbar where mouse users need it.

Reduced motion

The reel respects prefers-reduced-motion by disabling scroll snap for users who prefer reduced motion.

@media (prefers-reduced-motion: reduce) { :is(layout-reel, [data-layout="reel"]) { scroll-snap-type: none; } }
