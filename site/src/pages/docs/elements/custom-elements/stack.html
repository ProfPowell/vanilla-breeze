Attributes

Attribute Values Default Description
data-layout-gap none, 3xs, 2xs, xs, s, m, l, xl, 2xl, 3xl m Gap between children, on the shared size scale.
data-layout-align start, center, end, stretch stretch Cross-axis (inline) alignment of children. start, center and end make children content-sized; see sectioning children.

Child attribute

Attribute On Description
data-container main, article, section, aside When the stack is aligned start/center/end, keeps the child as a query container. Give it an explicit inline size too, or it collapses.

Attribute form

Any semantic element can be a stack with data-layout="stack". The same data-layout-gap and data-layout-align values apply.

Sectioning children

VB makes main, article, section and aside query containers (container-type: inline-size). A query container has no intrinsic width, so in a stack aligned start, center or end, where children shrink to their content, it would collapse to zero width. The stack therefore removes container-type from such direct children so they size to their content. To keep container queries on one of them, add data-container and give it a width.
