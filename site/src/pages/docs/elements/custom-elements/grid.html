Attributes

Attribute Values Default Description
data-layout-min xs, s, m, l, xl m Minimum column width before wrapping: 8 / 10 / 15 / 20 / 25rem. Tracks are clamped to the container, so a grid narrower than the minimum shows one full-width column instead of overflowing. One-off lengths: see the escape hatch.
data-layout-gap none, 3xs, 2xs, xs, s, m, l, xl, 2xl, 3xl m Gap between cells, on the shared size scale.
data-layout-subgrid (bare), 2, 3, 4 bare = 3 Each child becomes a subgrid spanning that many rows so header/content/footer align across cells. Bare means 3; any other value also spans 3. See Subgrid.

Attribute form

Every attribute works the same on a semantic element with data-layout="grid". Use it when the grid is a list or a section in its own right, so you don't need a wrapper element.

Minimum Width Variants

The data-layout-min attribute sets the minimum width each column can shrink to before the grid reflows.

Card 1 Card 2 Card 3

Each track is minmax(min(min-width, 100%), 1fr). In a container narrower than the minimum (an xl grid in a 300px sidebar, or on a phone) the grid shows one column at the container's width instead of overflowing.

One-off widths: --layout-min

When none of the tokens fit, set --layout-min on the grid. It beats the data-layout-min token. It is registered as non-inheriting, so a grid nested inside goes back to its own token or the default.

Subgrid

With data-layout-subgrid, each child becomes a grid whose rows are subgrid. The child spans 3 rows (bare or "3"), 2, or 4. A header that wraps to two lines in one card then pushes the body row down in every card on that row, so titles, bodies and footers line up.

  • Give each child as many direct children as rows: header, section and footer for the default 3, title and body for 2.
  • The subgridded rows use the grid's row gap. data-layout-gap sets both the space between cards and the space between the parts inside each card. To space the parts differently, set row-gap on the children.
  • <layout-card> children with header/section/footer drop their own row template and follow the subgrid.
  • Browsers without subgrid fall back to cards that size their own rows.
