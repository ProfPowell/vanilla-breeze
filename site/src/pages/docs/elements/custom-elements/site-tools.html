Overview

The <site-tools> element is a flex container for site-wide utility controls. It uses margin-inline-start: auto to push itself to the trailing edge of flex parents like <header class="site">.

It parallels <page-tools> which handles page-level utilities. Use <site-tools> for controls that appear on every page: search, theme picker, settings, account menus.

Mobile Menus

A sibling <mobile-menu> hides <site-tools> completely (display: none !important) at and below its breakpoint, along with the header's <nav> and <nav-bar>. Anything inside <site-tools> is then unreachable unless you also provide it another way:

  • Repeat it in the mobile panel. This suits search and the theme picker, which work inside the panel. The demo above does this.
  • Keep it outside <site-tools>. Place it directly in the header, after <mobile-menu>, and it stays visible at every width, next to the menu button on narrow screens. Use this for tools whose own popup doesn't fit in the narrow mobile panel, such as the <notification-wc> bell. This site's header does this.

CSS Tokens

TokenDefaultDescription
--site-tools-gapvar(--size-s)Space between the tools. Set this instead of overriding --size-s, which would also re-scale the padding inside the nested components.

Accessibility

The element is a generic flex container with no implicit role. Each tool inside it (search, theme picker, settings) handles its own accessibility, including its touch-target size.
