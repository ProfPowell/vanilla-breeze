Overview

The <site-legal> element displays legal and compliance content with automatic dot separators between items. It renders in muted, small text appropriate for footer placement.

Use it exclusively for legal content: copyright notices, license types, privacy policy links, and terms of service links. General site links belong in a <nav> element instead.

List Form

Wrap the items in a single <ul> or <ol> to give them list semantics, so screen readers announce an item count. The separators then go between the <li>s. The list's bullets are removed. VoiceOver in Safari stops announcing lists that have no markers, so if the count matters there, add role="list" to the list.

Alignment and Wrapping

Items are centered by default. Set data-justify to start, center, end or between, or set the --site-legal-justify token to any justify-content value.

Each separator sits in the gap before its item, and the element clips anything that hangs past its inline-start edge. So when a long row wraps and the new row starts at that edge (start or between), the new row doesn't begin with a stray dot. Centered or end-aligned rows don't start at the edge, so a wrapped row there keeps its leading dot. Use data-justify="start" for legal rows that wrap often.

Copyright Year

The year is authored text: <site-legal> has no script and doesn't update it. Write it as <time datetime="2026">2026</time>, or have your build or template fill it in (for example, from a build-time year variable).

Separator Customization

The dot separator uses the --sep-list token. Override it to change the separator character. The separator is decorative: its alternative text is empty, it sits outside each link's box, and it is never underlined or clickable.

Accessibility

  • Links are always underlined, not just on hover. This keeps them distinguishable from the plain-text items without relying on color (WCAG 1.4.1). On hover and keyboard focus, the underline thickens and the link takes the full text color.
  • Separators use CSS generated content with empty alternative text (content: "·" / ""). They aren't part of any link's accessible name or click target.
  • Muted text uses --color-text-muted, which meets AA contrast for small text.
  • Use the list form if the number of items matters to screen-reader users.
