Overview

The <loading-spinner> element displays a CSS-only animated spinner for loading states. It requires no JavaScript and works as a simple custom element with CSS styling.

Attributes

Attribute Values Default Description
data-size xs, s, m, l, xl m Spinner size.
data-variant primary, success, warning, error inherit Color variant.
data-overlay boolean — Covers the nearest positioned ancestor with a translucent backdrop and centers the spinner in it. The container needs position: relative (or any non-static position).
role + aria-label status + string — For a standalone spinner: role="status" with a label such as “Loading”. CSS cannot add a role, so the author must.
aria-hidden true — For a spinner next to visible text that already describes the state.

Sizes

Five size presets from extra-small to extra-large. The spinner inherits currentColor by default.

Inline Usage

Use a small spinner inline with text or inside buttons. When visible text already says what is happening, hide the spinner from assistive technology with aria-hidden="true" so the text is not doubled (a labelled spinner inside the button would name it “Loading Processing...”).

Overlay

data-overlay makes the spinner position: absolute; inset: 0 with a translucent surface backdrop, and centers a spinner of the chosen size inside it. Absolute positioning resolves against the nearest positioned ancestor, so give the container you want covered a non-static position. Without one, the overlay covers some ancestor further up, or the whole page.

.loading-region { position: relative; }

Custom Properties

Property Default Description
--spinner-size 1.5em Overall spinner dimensions.
--spinner-width 0.2em Border/track thickness.
--spinner-color currentColor Active arc color.
--spinner-track 20% of color Background track color.
--spinner-speed 0.7s Rotation duration.
loading-spinner { --spinner-size: 3em; --spinner-width: 0.3em; --spinner-color: oklch(55% 0.2 260); --spinner-speed: 1s; }

Accessibility

  • CSS cannot give an element a role, so the spinner is a generic element until you add one. For a standalone spinner, add role="status" and aria-label="Loading" (or a more specific label).
  • A live region only announces changes that happen after it exists. A spinner inserted with role="status" already on it may not be announced. To announce reliably, insert the spinner into a role="status" container that was already on the page, or change that container's text.
  • When the spinner sits next to visible text (“Loading your data...”, a busy button), add aria-hidden="true" to the spinner and let the text carry the meaning. Otherwise the label is read twice or joins the button's name.
  • Mark the region being loaded with aria-busy="true" while it updates, and remove the attribute when it is done.
  • In forced-colors mode the track becomes transparent and the arc uses a system colour, so the rotation stays visible.
  • Animation slows to 1.5s under prefers-reduced-motion: reduce.
  • CSS-only: works without JavaScript.
