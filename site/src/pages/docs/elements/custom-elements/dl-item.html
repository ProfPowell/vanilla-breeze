Description

The <dl-item> custom element groups a <dt>/<dd> pair within a <dl> for styling. Apply variant attributes on the parent <dl> to get built-in layouts — no custom CSS needed.

The variants style the native <dl>, so they work the same with the spec's <div> wrapper (see Div wrappers) and, for horizontal and stacked, with flat <dt>/<dd> pairs.

Variants

Attribute (on <dl>) Description
data-variant="horizontal" Term column + description column (grid with subgrid rows, so terms line up). Falls back to stacked below 16rem of available width.
data-variant="stacked" Muted label above its value(s), no indent
data-bordered Separator lines between wrapped groups
data-density="compact" Tight spacing for dense data (same attribute as table[data-density])
data-striped Alternating group backgrounds

Variants compose freely — combine data-variant="horizontal", data-bordered, and data-density="compact" on a single <dl>.

Custom Properties

Property Default Description
--dl-term-min 10ch Minimum width of the term column in the horizontal variant
--dl-term-max 40% Maximum width of the term column; terms wrap beyond it

Horizontal

Side-by-side key-value pairs. Combine with data-bordered for separator lines between rows. Long values wrap inside the description column instead of overflowing, and in containers narrower than 16rem each term sits above its description.

Why a Custom Element?

HTML allows wrapping <dt>/<dd> groups in <div>, and VB styles both wrappers identically. <dl-item> is a named alternative: it reads as "description list item" in source and in selectors, without the ambiguity of a generic container. It is purely presentational — it has no JavaScript and adds no semantics.

Conformance

The HTML specification only permits <dt>, <dd>, <div>, and script-supporting elements as children of <dl>. A <dl-item> inside a <dl> is therefore non-conforming, and the W3C validator reports it.

  • In Chrome's accessibility tree the wrapper is ignored and the <dt>/<dd> children keep their term/definition roles, just as with a <div> wrapper.
  • Other browsers and screen readers have not been verified.
  • VB's html-validate rules accept <dl-item> only as a direct child of <dl>, and flag a <dl-item> (or its <dt>/<dd>) used anywhere else.

Where strict validity matters, use <div> — every variant works the same.

Content Model

Permitted Content

  • One or more <dt> elements followed by one or more <dd> elements

Required Parent

Must be a direct child of <dl>.
