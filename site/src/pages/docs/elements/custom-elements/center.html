Attributes

Attribute Values Default Description
data-layout-max narrow, normal, wide, prose normal Max inline size: narrow (--content-narrow, 40rem), normal (--content-normal, 60rem), wide (--content-wide, 80rem) or prose (65ch).
data-layout-intrinsic (boolean) — Center narrower-than-max content intrinsically (flex column, align center).
data-layout-text (boolean) — Center the text as well.
data-layout-gutter none, s, l m Inline padding: none, s or l (default m).
data-layout-gap (bare), none, 3xs, 2xs, xs, s, m, l, xl, 2xl, 3xl m Become a flex column with this gap between children, on the shared size scale. Bare attribute = m.

Element or Attribute

The same layout is available as data-layout="center". Prefer the attribute when a semantic element is already the centred container — an <article>, <main>, <form> or <footer> — so you don't add a wrapper just to centre it. Use <layout-center> when there is no such element. All data-layout-* modifiers work on both forms. See data-layout for the full comparison.

Max Width Variants

The data-layout-max attribute controls the maximum width of the container. Widths come from the content tokens, so a theme can retune them.

ValueTokenDefault width
narrow--content-narrow40rem
normal (default)--content-normal60rem
wide--content-wide80rem
prose—65ch

Fluid-scaling themes redefine --content-normal as a clamp(), so its width varies with the viewport there.

Intrinsic Centering

The data-layout-intrinsic attribute centers content that is narrower than the max-width.

Intrinsically centered card .card-constrained { max-inline-size: 20rem; }

Text Centering

The data-layout-text attribute adds text-align: center for centered text content.

Gap

Adding data-layout-gap turns the container into a flex column with space between its children. The bare attribute uses the default m gap; give a size for anything else.

Default gap (m)

Children are spaced with --size-m.

Larger gap

Children are spaced with --size-xl.
