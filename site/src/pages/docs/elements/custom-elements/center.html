Overview

A center caps the width of its content and centres it in the available space, with a gutter on each side so the content never touches the edges. It is a block (display: block) with max-inline-size, margin-inline: auto and inline padding for the gutter.

The container uses box-sizing: content-box: the max width applies to the content, and the gutter is added outside it. A narrow center with the default m gutter is therefore 40rem of content plus 2 × --size-m wide in total, so text measures stay exact whatever the gutter.

data-layout-intrinsic and data-layout-gap switch the container to a flex column; see Intrinsic centering and Gap.

Element and attribute forms

Any element can be a center with data-layout="center". The same data-layout-* modifiers work on both forms; the two below produce the same box.

Which to choose: use the attribute form when a semantic element is already the centred container: an <article>, <main>, <form> or <footer>. Use <layout-center> when there is no such element and you would otherwise add a wrapper. In the attribute form, main, article, section and aside are also container-query containers, which the element is not, so container queries inside resolve against the centred box. See data-layout for the full comparison and Semantic Layouts for the approach.

Attributes

Attribute Values Default Applies to Description
data-layout-max narrow, normal, wide, prose normal both Max inline size of the content box: narrow (--content-narrow, 40rem), normal (--content-normal, 60rem), wide (--content-wide, 80rem) or prose (65ch). See Max width.
data-layout-intrinsic (boolean) — both Center narrower-than-max content intrinsically (flex column, align center).
data-layout-text (boolean) — both Center the text as well.
data-layout-gutter none, s, l --size-m (omit the attribute) both Inline padding on each side: none, s or l. There is no m value; the m gutter is what you get without the attribute.
data-layout-gap (bare), none, 3xs, 2xs, xs, s, m, l, xl, 2xl, 3xl m both Become a full-width flex column with this gap between children, on the shared size scale. Bare attribute = m.

Child attributes

None. The center holds any content; children are laid out normally (or as a flex column with data-layout-intrinsic or data-layout-gap).

Examples

Max width

The data-layout-max attribute controls the maximum width of the container. Widths come from the content tokens, so a theme can retune them.

ValueTokenDefault width
narrow--content-narrow40rem
normal (default)--content-normal60rem
wide--content-wide80rem
prose—65ch

Fluid-scaling themes redefine --content-normal as a clamp(), so its width varies with the viewport there.

These widths are for the content box; the gutter is added on each side (see Gutter). Note that narrow means 40rem here, while data-layout-max="narrow" on text containers such as <layout-text> means a 45ch measure. Use prose (65ch) when you want a character-based reading measure on a center.

Intrinsic centering

The data-layout-intrinsic attribute centers content that is narrower than the max-width.

Intrinsically centered card .card-constrained { max-inline-size: 20rem; }

Text centering

The data-layout-text attribute adds text-align: center. Keep it for short text such as headings and hero lines; long centred paragraphs are harder to read.

Gutter

The data-layout-gutter attribute sets the inline padding on each side (useful for nested centers). The default gutter is --size-m; there is no m value, so leave the attribute off for it. Because the box is content-box, a larger gutter makes the whole box wider rather than the content narrower.

Gap

Adding data-layout-gap turns the container into a flex column with space between its children. It is the one modifier that also changes the box: the center takes the full available width (up to its max), so it does not shrink to its content when it sits inside another flex layout such as a cover. The bare attribute uses the default m gap; give a size for anything else.

Default gap (m)

Accessibility

  • The center only limits width and adds a gutter; it never reorders content. <layout-center> has no role, so use the attribute form on <main>, <article> or <form> to keep their semantics without an extra wrapper.
  • A capped measure helps reading: prose (65ch) keeps lines under 80 characters (WCAG 1.4.8 Visual Presentation).
  • data-layout-text centres every line. Use it for short headings and calls to action, not for paragraphs of body text.
  • The max width is a cap, not a fixed width: the box shrinks with its container, so content reflows at high zoom (WCAG 1.4.10 Reflow).
