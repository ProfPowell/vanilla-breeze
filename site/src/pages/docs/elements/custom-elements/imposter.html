Attributes

Attribute Values Default Description
data-layout-fixed (boolean) — Position relative to the viewport instead of the containing block.
data-layout-margin s, m, l, xl — Inset from the edges when pinned to one (and the inset used by data-layout-contain).
data-layout-position center, top, bottom, start, end, top-start, top-end, bottom-start, bottom-end center Where to place the overlay.
data-layout-contain (boolean) — Never larger than the containing block (the positioned ancestor, or the viewport when fixed) minus the margin on each side; scrolls inside when the content is bigger.

Custom properties

PropertyDefaultDescription
--imposter-z 1 (absolute), var(--z-float) (fixed) Stacking order, so the overlay paints above later positioned siblings.

How it positions

Every position uses the same mechanism: the imposter is stretched to its containing block with inset: 0, shrinks to fit its content, and is placed with auto margins. Pinned edges swap the auto margin on that side for the data-layout-margin value. Because nothing is translated by a physical offset, positions are logical (start is the right edge in RTL) and a centred overlay can use the full width of its container before it wraps.

Nested imposters start from their own defaults; an inner imposter never inherits an outer one's position or margin.

data-layout-contain caps the overlay at its containing block minus the margin, for absolute and fixed imposters alike, and lets it scroll inside.

Right to left

Positions are logical: start and end follow the writing direction, and centred overlays stay centred.

Accessibility

<layout-imposter> does visual positioning only. It does not trap focus, make the rest of the page inert, close on Escape, or give the content dialog semantics. For modal or dismissible UI, use the platform:

  • <dialog> with showModal() for modal dialogs (focus containment, inert background, Escape).
  • The popover attribute for light-dismiss overlays such as menus and toasts.

Status overlays (loading, saved) should carry role="status" so screen readers announce them. Keep a decorative spinner out of the accessibility tree with aria-hidden="true" when visible text sits next to it.
