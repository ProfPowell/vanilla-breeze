Overview

The <site-search> component opens a native modal <dialog> with a search combobox, keyboard navigation and highlighted excerpts. It uses Pagefind for indexing and searching your static site content.

Keyboard Shortcuts

The search component supports the following keyboard shortcuts:

Shortcut Action
Cmd + K / Ctrl + K Open/close search. Bound once for the page: it opens the first visible <site-search>, so a page may hold several (e.g. desktop header and mobile menu)
Escape Close search
Arrow Up / Arrow Down Navigate results
Enter Go to the selected result, or the first result when none is selected

Configuration

Subpath deploys

The component imports pagefind.js from /pagefind/ by default. When the site is served from a subpath, point data-pagefind-path at the index directory. Result URLs get the directory above it as Pagefind’s baseUrl; set data-base-url to override that.

Labels

Every UI string has a data-label-* override, including the result count ({count} is replaced; when the index matches more than the eight results listed, data-label-count-more also gets {total}, as in “8 of 23 results”) and the status shown when the index is missing. Developers get a console hint (“run npm run search:index”); visitors only see “Search unavailable”.

Pagefind Setup

The search component requires Pagefind to index your site content. Follow these steps to set up Pagefind:

1. Install Pagefind

npm install --save-dev pagefind

2. Add Build Script

Add a script to run Pagefind after your site builds:

{ "scripts": { "build": "vite build && npm run search:index", "search:index": "pagefind --site dist" } }

Accessibility

  • The search panel is a native <dialog> opened with showModal(): it sits in the top layer and the rest of the page is inert, so focus cannot leave it for the page behind
  • Escape closes the dialog and returns focus to the trigger
  • The input is a role="combobox" with aria-controls, aria-expanded and aria-activedescendant; the results are a role="listbox" that holds only role="option" links
  • A separate role="status" region announces “Searching…”, the result count, “No results found” and errors
  • Results are real links: Cmd/Ctrl-click and middle-click open them in a new tab
  • Result titles render as text and excerpts keep only Pagefind’s <mark> highlights; result URLs must be same-origin http(s)
