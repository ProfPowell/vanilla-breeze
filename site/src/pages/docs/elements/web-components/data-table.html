Overview

The <data-table> component wraps a standard HTML table to provide interactive features like column sorting, text filtering, pagination, expandable rows, row selection with bulk actions, responsive card layouts, and sticky headers/columns. All features are opt-in via data attributes and the table remains fully functional without JavaScript.

Name Age
Alice Johnson 32
Bob Smith 28

Basic Usage

Wrap any HTML table with <data-table> and add data attributes to enable features. The table structure remains semantic and accessible.

Name Email Department
Alice Johnson alice.johnson@example.com Engineering

Sorting

Add data-sort to any <th> element to make that column sortable. The component wraps the header text in a native <button> (the APG sortable table pattern), so headers are reachable with Tab, show a focus ring, and sort with Enter or Space. Activating a header toggles between ascending and descending; activating a different column sorts it ascending (or descending if the rows are already in ascending order, so the change is always visible). The arrow indicator and aria-sort on the <th> always agree.

Sort Types

Value Description
string Alphabetical sorting (case-insensitive)
number Numeric sorting (handles decimals and negatives)
date Date sorting (parses common date formats)

Custom Sort Values

Use data-sort-value on cells when the display value differs from the sort value. This is required for formatted numbers: data-sort="number" parses the cell with parseFloat, so text like $1,234 or 1,234 would not sort numerically without a raw value.

$95,000 1,234.50 Mar 15, 2019

Filtering

Add data-filterable to the table to enable text filtering. A search input is automatically generated above the table. Rows that don't match the filter text are hidden, and the result count is announced to screen readers. When nothing matches, a visible “No matching rows found” message appears below the table; override its text (and the announcement) with data-label-no-results on <data-table>.

Pagination

Add data-paginate="n" to the table to show only n rows per page. Pagination controls are automatically generated below the table.

Name Email Department Hire Date

Row Expansion

Create expandable rows by adding data-expandable to a row and following it with a data-expand-content row. Put your own toggle button in the row with data-action="toggle-expand" (give it an accessible name); the component wires it up, keeps aria-expanded in sync, and keeps the content row attached to its parent when sorting, filtering, or paging.

Row Selection

Add checkboxes to rows for selection, with a "select all" checkbox in the header and a bulk actions bar that appears when rows in that table are selected. The selection count is announced to screen readers. Selected rows get data-state-selected, which uses the same selected tint as a native tr[data-selected], plus a non-colour cue.

Responsive Card Mode

Add data-responsive="card" to transform the table into a card layout on narrow screens. Each cell's label is derived from its column header automatically, and the table roles are restored so screen readers still announce a table. An authored data-label on a cell overrides the derived one.

Name Email Department Status
Alice Johnson alice.johnson@example.com Engineering Active
Note: The layout switches based on viewport width. In production, it adapts automatically.

Horizontal Scroll

For wide tables that should keep their columns, wrap the table in a focusable scroll container labelled by its caption. Add data-table-scroll="block" to also cap the height.

Events

The component dispatches custom events for each interactive feature.

Event Detail Description
data-table:sort { column: number, direction: "asc"|"desc", columnName: string } Fired when a column is sorted.
data-table:filter { query: string, count: number } Fired when the filter is applied (input, setFilter(), refresh(), or a .rows assignment).
data-table:page { page: number } Fired when the page changes.
data-table:expand { row: HTMLTableRowElement, expanded: boolean } Fired when a row is expanded or collapsed.
data-table:selection { count: number, rows: HTMLTableRowElement[] } Fired when row selection changes.
const table = document.querySelector('data-table'); // Sort events table.addEventListener('data-table:sort', (e) => { console.log(`Column ${e.detail.column} sorted ${e.detail.direction}`); }); // Filter events table.addEventListener('data-table:filter', (e) => { console.log(`Filter "${e.detail.query}" matches ${e.detail.count} rows`); }); // Page change events table.addEventListener('data-table:page', (e) => { console.log(`Page ${e.detail.page} of ${table.totalPages}`); }); // Row expansion events table.addEventListener('data-table:expand', (e) => { console.log(`Row ${e.detail.expanded ? 'expanded' : 'collapsed'}`); }); // Selection events table.addEventListener('data-table:selection', (e) => { console.log(`${e.detail.count} rows selected`); });

Public API

The component exposes methods for programmatic control.

Method Parameters Returns Description
goToPage(n) n: number void Navigate to a specific page (1-indexed, clamped to the valid range). No-op without data-paginate.
setFilter(query) query: string void Programmatically set the filter text.
refresh() - void Re-scan rows after adding or removing <tr> elements, then re-apply rollups, heatmaps, filtering, sorting, and pagination (the current page is kept when still valid).
getSelectedRows() - HTMLTableRowElement[] Get array of currently selected rows.
const table = document.querySelector('data-table'); // Navigate to page 3 table.goToPage(3); // Filter by department table.setFilter('engineering'); // Refresh after external data change table.refresh(); // Get selected rows for bulk operation const selected = table.getSelectedRows(); selected.forEach(row => { console.log(row.cells[1].textContent); // Log names });

Decision Matrix recipe

Set data-weight="N" on each criterion column header, data-rollup="weighted-sum" on a Score column, and data-heatmap for visual scanning. The component computes the score per row from the weighted criteria, sets data-sort-value so the Score column remains sortable, and tints cells low/mid/high based on relative value within the column.

Option Performance (×3) Maintainability (×2) Ecosystem (×1) Score
Library A543
Library B355

This recipe replaces a dedicated decision-matrix component — there's no new element needed; the rule is "behaviour on existing element → data-* attribute".

Rollup kinds

  • sum — sum of all sibling numeric cells.
  • weighted-sum — each sibling cell × the data-weight on its column header.
  • product — multiply all sibling numeric cells (e.g. likelihood × impact for risk severity).
  • avg — average of all sibling numeric cells.
  • max — largest sibling numeric value.

Heatmap modes

  • high-good (also auto) — large values tinted green, small values red.
  • low-good — inverted; small values green (e.g. risk severity, defect count).

Tints use the --color-error-subtle, --color-warning-subtle, and --color-success-subtle tokens, which switch with the colour scheme; cell text stays --color-text so contrast holds in light and dark mode. Colour is never the only cue — the number stays in the cell.

Accessibility

Keyboard Navigation

Everything interactive is a native control, so the table follows the normal tab order; there is no custom row navigation.

Key Action
Tab / Shift+Tab Move between the filter input, sort header buttons, checkboxes, expand toggles, and pagination buttons
Enter / Space Sort by the focused column, toggle a checkbox, expand/collapse a row, or go to a page

After a pagination button is activated, focus moves to its replacement: Previous/Next keep focus (unless they become disabled), and a page number hands focus to the new current-page button.

ARIA and Semantics

  • aria-sort on sortable <th> headers reflects the current direction; the header's <button> is the control. The visual arrow is CSS content with empty alt text, so it is not read twice.
  • aria-expanded on data-action="toggle-expand" buttons reflects row expansion.
  • Row selection state is carried by the row checkboxes themselves.
  • aria-current="page" marks the current page; the pagination is a <nav aria-label="Table pagination">.

Screen Reader Announcements

A visually hidden role="status" region (aria-live="polite") inside the component announces:

  • Sort changes, e.g. “Sorted by Price, descending”
  • Filter results, e.g. “3 of 12 rows shown”, or the data-label-no-results text when nothing matches
  • Selection count changes, e.g. “2 rows selected”

Reduced Motion

When prefers-reduced-motion: reduce is set, transitions on the filter input and pagination buttons are disabled.
