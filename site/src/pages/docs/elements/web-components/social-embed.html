Overview

A privacy-first embed for social posts. Before activation the reader sees your fallback link and a Load {platform} post button with a note naming the host the post loads from. Nothing is requested from the platform until they press it (the default activate="click"). The post then loads in a sandboxed iframe that the component builds itself from the validated post URL: no oEmbed HTML is inserted into your page and no platform script runs in your page's origin.

The fallback content (typically an <a>) renders without JavaScript, is indexable, and stays the only content for URLs no provider accepts.

Providers

The provider is detected from the URL. Every built-in provider parses the URL with new URL(), accepts only https on an exact list of hostnames, and rebuilds the embed URL from the validated parts (post id, handle, shortcode). Anything else is unsupported and keeps the fallback link.

KeyAccepted URLsEmbedNotes
blueskyhttps://bsky.app/profile/{handle|did}/post/{rkey}embed.bsky.app/embed/{did}/app.bsky.feed.post/{rkey}A handle URL is resolved to its DID with one request to public.api.bsky.app on load; a DID URL needs no lookup. Themeable.
mastodonhttps://{any instance}/@{user}/{id}{instance}/@{user}/{id}/embedAny instance is allowed, so the frame gets the tightest sandbox (no allow-popups-to-escape-sandbox).
xhttps://x.com/{user}/status/{id} (also twitter.com, www., mobile.)platform.twitter.com/embed/Tweet.html?id={id}No widgets.js. Themeable.
instagramhttps://www.instagram.com/p|reel|tv/{shortcode}/www.instagram.com/p/{shortcode}/embed/No embed.js.
youtubeyoutube.com /watch?v=, /shorts/, /embed/, /live/; youtu.be/<youtube-player>Renders the player at once (its own facade is the click gate). t= becomes start.

Frames are created with sandbox (allow-scripts allow-same-origin allow-popups, plus allow-popups-to-escape-sandbox for the fixed-host providers), referrerpolicy="strict-origin", loading="lazy", a title and a minimal allow list. Their height follows each platform's resize message; messages are accepted only from that frame's window and origin.

Theme

theme="light" or "dark" is passed to providers that support it (X and Bluesky). The default auto uses the host's computed color-scheme (set by the active VB theme), then the page's data-mode, then prefers-color-scheme. When the VB theme changes, loaded X and Bluesky embeds re-render; other providers are left alone, so a playing video or a scrolled post is never reset.

Custom Provider

Register a provider with SocialEmbed.register(). Return a node from render() and the component inserts it; build frames with createEmbedFrame() so they get the same sandbox, lazy loading and resize handling. Instances already marked unsupported re-initialise when a matching provider is registered later.

import { SocialEmbed, createEmbedFrame } from './social-embed/logic.js'; SocialEmbed.register('peertube', { label: 'PeerTube', noun: 'video', canHandle: (url) => /^https:\/\/video\.example\/w\/[\w-]+$/.test(url), frameHost: () => 'video.example', async render(host, url, { title }) { const id = new URL(url).pathname.split('/').pop(); return createEmbedFrame({ src: new URL(`https://video.example/videos/embed/${id}`), title, sandbox: ['allow-scripts', 'allow-same-origin'], allow: 'fullscreen', height: 315, }); } });

Never insert oEmbed html (or any third-party markup) with innerHTML. If a platform only offers HTML, run it through sanitizeToFragment() from src/lib/sanitize-html.js.

Accessibility

  • The idle state is a real <button type="button"> named after the platform ("Load Bluesky post") beside the fallback link. The host has no role, so there is no nested interactive content and the link still navigates.
  • After a load started from the button, focus moves into the embed frame (named by data-title). On failure, focus stays on the Load button, which retries.
  • A polite status region announces loading and failure.
  • The loading pulse respects prefers-reduced-motion.

Privacy and Security

  • Click to load by default. No request reaches Bluesky, Mastodon, X or Instagram until the reader presses Load. The note under the button names the host. activate="visible" and "eager" skip that consent step.
  • YouTube is the exception. <youtube-player> renders its facade at once and fetches the thumbnail from i.ytimg.com on page load (set poster to a local image to avoid that request); the video itself loads from youtube-nocookie.com on play. Moving the element re-renders the player's facade, so a playing video stops.
  • Bluesky handle URLs make one lookup to public.api.bsky.app on load. Use the DID form of the URL to avoid it.
  • Sandboxed, never injected. Each embed runs in its platform's own origin inside a sandboxed frame. No oEmbed HTML enters your page and no platform script runs with access to your DOM. Platforms may still set their own cookies inside the frame once loaded.
  • Untrusted content. The shared sanitizer (sanitizeHTML / sanitizeToFragment, used by markdown-viewer, chat-window, comment-thread and others) unwraps <social-embed> to its fallback link, so user-supplied markup cannot embed third-party frames.
  • The component sets no cookies or storage.
