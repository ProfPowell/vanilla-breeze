Overview

<social-feed> shows recent posts from the site's accounts as post cards, newest first, in a list that scrolls inside a fixed height. Cook fills an empty <social-feed> at build time from config/social.json: an <activity-feed> of entries, a "More on" line linking to each account, and a small state script. Without JavaScript that markup is the whole feature.

With JavaScript, the element:

  • reads each account's first page from the service's public API once per page view, inserts newer posts in date order and updates the counts on posts already shown;
  • loads the next batch when the list is scrolled near its end, first from posts Cook fetched but did not show, then page by page from each account;
  • never shows a post twice, including a repost of a post already in the list;
  • stays quiet when a service fails: the posts already shown stay and no error appears.

Replies are left out; reposts and boosts are kept. GitHub contributes published releases only.

Attributes

AttributeTypeDefaultDescription
accounts string all visible Comma-separated account keys, service:handle as stored in config/social.json. A hidden account named here is included. Read by Cook.
tags string none Comma-separated hashtags without #, matched case-insensitively. Filters Bluesky and Mastodon posts; a block with tags shows no GitHub releases.
items number 12 How many posts to show first (1 to 50), and how many each scroll loads.
height string 32rem Height of the scrolling list, a rem, em, px or vh length. Cook writes it as --social-feed-height.
hide-counts boolean absent Leave out the reply, repost and like counts.

Accessibility

The list is an <activity-feed> labelled "Recent posts". It is in the tab order, so keyboard users can scroll it, and Page Up and Page Down move between posts. Counts carry visually hidden labels in each service's own terms (replies, reposts, likes; or replies, boosts, favourites on Mastodon).

Styling

Set --social-feed-height to change the list height. Entries use the classes social-feed-avatar, social-feed-head, social-feed-source, social-feed-text, social-feed-image, social-feed-release and social-feed-counts; each article carries data-service.
