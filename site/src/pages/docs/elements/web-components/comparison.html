Overview

The <compare-surface> component creates a before/after comparison slider. Two children overlay each other, and a draggable divider reveals one side. Works with any two children — images, divs, or any other elements.

Looking for "diff display"? See the diff-display recipe — <compare-surface> handles the side-by-side image case, while <change-set> / <review-surface> / <version-switcher> / the text-diff utility cover the other shapes.
Progressive enhancement: Without JavaScript, both children display side-by-side in a grid. The slider and clip-path only activate when JS registers the component.

Attributes

Attribute Type Default Description
position number 50 Slider position from 0 to 100, measured from the inline-start edge (left in LTR, right in RTL). Read on upgrade and observed afterwards: changing the attribute moves the divider. User drags and key presses reflect the new integer value back to the attribute.
label string "Comparison slider" Accessible name for the slider handle. A host aria-label is used when label is absent. Observed.

Custom Start Position

Set position to control where the divider starts. A value of 25 means the divider starts 25% from the inline-start edge (the left in left-to-right pages), showing mostly the second (“after”) child.

Non-Image Content

The component works with any two child elements, not just images. Use articles, figures, text blocks, or any HTML content. Only the first two children are compared: once upgraded, any extra children are hidden and a console warning is logged.

Keyboard Navigation

Key Action
ArrowLeft / ArrowRight Move the divider 1% in the arrow’s visual direction (also in RTL)
ArrowUp / ArrowDown Increase / decrease position by 1
Shift + Arrow Move by 10 instead of 1
PageUp / PageDown Increase / decrease position by 10
Home / End Jump to 0 / 100

JavaScript API

Property Type Description
position number Get or set the divider position (integer 0–100 from the inline-start edge). Setting clamps, rounds and reflects to the position attribute without firing compare-surface:change, like a native input’s value.
const slider = document.querySelector('compare-surface'); slider.position = 75; // or slider.setAttribute('position', '75') console.log(slider.position); // 75

Right-to-Left

The position is direction-aware. In a dir="rtl" context, position is measured from the right edge, the first child appears on the right of the divider and the second on the left, and pointer dragging and arrow keys follow the visual direction.

Events

Event Detail Description
compare-surface:change { position: number } Fired when the user changes the position by dragging or with the keyboard. position is an integer 0–100 (only fires when that integer changes). Not fired on upgrade or when the attribute or property is set from script.
const slider = document.querySelector('compare-surface'); slider.addEventListener('compare-surface:change', (event) => { console.log('Position:', event.detail.position); });

Accessibility

Slider Role

The injected divider has role="slider" with aria-valuemin, aria-valuemax, aria-valuenow, and aria-valuetext (for example “25%”). Its accessible name defaults to “Comparison slider”; set the label attribute (or aria-label on the host) to describe what is being compared. These ARIA attributes are managed on the divider — do not set them on the host.

Keyboard Support

The divider is focusable (tabindex="0") and supports the slider keys listed under Keyboard Navigation, including Home, End, PageUp and PageDown.

Touch Support

The divider uses touch-action: none and setPointerCapture for reliable touch/pointer drag behavior across devices. A cancelled pointer (pointercancel / lost capture) ends the drag.

Styling

The divider and handle can be styled with CSS. The divider is a .comparison-divider element with a ::after pseudo-element for the circular handle.

/* Custom divider color */ .comparison-divider { background: var(--color-interactive); } /* Custom handle */ .comparison-divider::after { background: var(--color-interactive); border-color: white; }

Progressive Enhancement

Without JavaScript, both children display side-by-side in a natural grid. The :not(:defined) selector provides the fallback layout. Once JS registers the component, children overlap and the clip-path slider takes over.

/* Without JS: side-by-side grid */ compare-surface:not(:defined) { display: grid; grid-template-columns: 1fr 1fr; gap: var(--size-s); }
