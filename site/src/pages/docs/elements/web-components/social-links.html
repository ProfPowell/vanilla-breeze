Overview

<social-links> styles a plain list of profile links. Cook writes the list at build time from config/social.json, so the links work with no JavaScript. The element draws the icons, applies the variants and takes no space when nothing matched. It does not render or fetch anything.

  • Bluesky

Attributes

AttributeTypeDefaultDescription
services string all visible Comma-separated service ids to show: bluesky, mastodon, github, linkedin, youtube, link. Read by Cook when it writes the list.
variant string icon-label icon hides the label visually but keeps it as the link's name; label hides the icons; icon-label shows both.
color boolean absent Brand colours on the icons only. Label text keeps the theme text colour.

Styling

Each icon is a span.social-icon with a data-service value. The icon is painted with mask and background: currentColor, so it follows the link colour. Override social-links .social-icon[data-service="github"] to change one.
