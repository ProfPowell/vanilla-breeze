Overview

The <geo-map> component displays a map from free raster tiles. It computes the tiles needed to cover its box from lat/lng/zoom, re-lays them out when the element is resized, and draws a marker at the centre. Activating the map lazy-loads pan and zoom.

Key features:

  • Zero dependencies — no API keys, no external libraries
  • OpenStreetMap or CARTO tiles, or your own tile proxy, each with the credit its terms require
  • Progressive enhancement — the slotted <address> is visible before JS and names the map
  • Opt-in consent mode that contacts no tile server until the user agrees
  • On-screen zoom buttons, pinch, keyboard, and click-to-centre in interactive mode
  • CSS custom properties, CSS parts, and data-label-* strings for localisation

Tile Providers

Each built-in provider shows the credit its terms require: OpenStreetMap shows “© OpenStreetMap contributors”; the CARTO styles add “© CARTO”. Keep the credit visible.

Your Own Tiles and Attribution

For privacy, swappability, caching control, or rate limiting, point <geo-map> at your own endpoint. tile-url takes a URL template; every {z}, {x}, {y} is substituted, {s} rotates through subdomains a/b/c, and {r} becomes @2x on high-density screens. See Server-Side Service Facade for a Cloudflare Worker that proxies and caches OSM tiles.

A tile-url source has no built-in credit — supply the credit its licence needs with attribution (and attribution-href), or slot your own element with slot="attribution". If you proxy OpenStreetMap, credit OpenStreetMap.

Privacy and Third-Party Requests

By default the static map fetches its tiles as soon as it is near the viewport, even with interactive="click". Each tile request sends the visitor’s IP address and the page as referrer to the tile host:

  • osm: https://tile.openstreetmap.org
  • carto-*: https://basemaps.cartocdn.com
  • tile-url: whatever host you configure (nothing third-party if it is same-origin)

With a Content Security Policy, allow the tile host in img-src (for example img-src 'self' https://tile.openstreetmap.org). The component adopts its styles as a constructable stylesheet, so it does not need style-src 'unsafe-inline' in browsers that support adoptedStyleSheets.

Set loading="consent" to show a placeholder naming the tile host instead; no tile is requested until the user presses “Load map” (which then also activates interactive mode). Hovering or focusing that button preconnects to the tile host. Keep a link in the slotted address so the placeholder is still useful.

Marker

The marker pin is an SVG drawn at the centre of the map. By default it uses the theme’s --color-error; set --geo-map-marker-color in CSS for a site-wide colour, marker-color for one map, or hide it with marker="false".

Caption

Slot an <address> (or any content) as a caption at the bottom of the map. It is also the no-JS fallback and, by default, the map’s accessible name (“Map of …”). Links in the caption stay clickable above the activation surface.

Data Binding

Coordinates can come from 6 sources, checked in priority order. The first match wins:

  1. Explicit lat/lng attributes — highest priority
  2. src → <address data-lat data-lng> — reference an external address element by ID
  3. src → <script type="application/ld+json"> — reference a JSON-LD script by ID
  4. Slotted <address data-lat data-lng> — address inside the component
  5. place attribute — scans all JSON-LD scripts for a matching name
  6. <meta name="geo.position"> — page-level fallback

src → address element

Point src to the ID of an <address> element with data-lat and data-lng attributes. The address stays visible as semantic content while the map reads its coordinates.

src → JSON-LD script

Point src to the ID of a <script type="application/ld+json"> element. The component reads geo.latitude and geo.longitude from the parsed JSON.

Slotted <address> with coordinates

Slot an <address> with data-lat and data-lng directly inside the component. The address appears as a caption and also provides the coordinates.

place attribute

Set place to a name that matches the name field in a JSON-LD Place script anywhere on the page. Useful when structured data already exists for SEO.

<meta> fallback

As a last resort, the component checks for a <meta name="geo.position"> tag in the document. The content format is "lat;lng".

JavaScript API

.data reads the map state; assigning a partial object writes the attributes as one batch and re-renders once. Assigning the current state is a no-op, an invalid markerColor is ignored, and '' clears it.
PropertyTypeDescription
data{ lat, lng, zoom, marker, markerColor }Get, or assign (partial) to update. Emits geo-map:data-changed.
markersArray<{ lat, lng, color }>Read-only. The centre marker as a one-element array, or [] without coordinates.

const map = document.querySelector('geo-map'); map.data = { lat: 51.5007, lng: -0.1246, zoom: 16, markerColor: 'rebeccapurple' }; map.data; // { lat: 51.5007, lng: -0.1246, zoom: 16, marker: true, markerColor: 'rebeccapurple' } map.markers; // [{ lat: 51.5007, lng: -0.1246, color: 'rebeccapurple' }] map.addEventListener('geo-map:data-changed', (e) => { console.log(e.detail.data, e.detail.source); // source: 'property' });

Interactive Mode

With the default interactive="click" the whole map surface is the activation target: click or tap anywhere, or Tab to the “Activate interactive map” button and press Enter. On touch screens the button is always visible. Activation lazy-loads the pan / zoom layer and moves focus to the map.

In interactive mode you can drag to pan, click a point to centre the map on it (a single-pointer alternative to dragging), pinch with two fingers, scroll, or use the on-screen + / −, recenter and exit buttons. Use interactive="eager" to activate on load, or interactive="none" / static-only for a static map.

Accessibility

What the component provides:

  • The static map is an image named from label, the slotted <address>, the src name, or place — not raw coordinates.
  • The activate button’s accessible name is its visible text; on touch screens it is always visible, and the whole map surface activates.
  • In interactive mode the map is a focusable region with aria-roledescription="map", instructions via aria-describedby, and a polite live region announcing the new centre and zoom.
  • Single-pointer alternatives to dragging and pinching: click-to-centre and the on-screen zoom, recenter and exit buttons (WCAG 2.5.7). All controls work from the keyboard.
  • The marker is decorative (aria-hidden); attribution links open in a new tab.

Limits to be aware of:

  • Raster tiles are pictures: street names and landmarks on the map are not available to screen readers. Always put the address (and ideally a link to a full map service or directions) in the slotted <address> — that text, not the map, is the accessible content.
  • Tile colours come from the provider and are not themed; check that your marker colour contrasts with the tiles you use, and prefer carto-auto for dark pages.
  • Announcements report coordinates, not place names (there is no geocoding).
