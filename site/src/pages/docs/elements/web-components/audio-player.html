Overview

A platform-native audio player that wraps <audio> in light DOM and renders custom controls in shadow DOM. The native player is always the fallback — if JS is unavailable or the component fails, <audio controls> works normally.

Pair with <audio-visualizer> for canvas-based frequency or waveform visualization.

Single Track

Playlist Mode

Include a <details> with <ol class="track-list"> inside the component. Clicking a track updates the audio source and plays it. When a track ends it is marked data-audio-played, keeps data-audio-active until the next track starts, and playback advances in list order, stopping after the last track (or wrapping with loop).

  1. 01. Opening Theme 2:14
  2. 02. Main Theme 3:45
  3. 03. Ending Theme 4:12

Shuffle and Loop

With shuffle, the next track is picked at random from the tracks not yet played in the current cycle, so a track never plays twice in a row. Without loop playback stops once every track has played; with loop a new shuffled cycle starts. Clicking a track counts it as played for the cycle, and toggling shuffle starts a fresh cycle.

Attributes

AttributeTypeDescription
autoplayBooleanStart playing on load (subject to browser autoplay policy)
loopBooleanLoop the track (single-track mode sets the native audio.loop) or wrap the playlist back to the first track; with shuffle, start a new shuffled cycle
shuffleBooleanAdvance to a random unplayed track (once per cycle, never twice in a row)

Reflected state

Set by the component — read them, style with them, but don't author them.

The native controls attribute belongs on the inner <audio>: it is the no-JS fallback. The component removes it while upgraded and restores it if the player is removed from the page.

Dark Mode

The player adapts automatically to light and dark mode via design tokens. All colors resolve through CSS custom properties that respond to theme changes. Set data-mode="dark" on the player or any ancestor (such as the <section> it sits in), or let the system preference apply.

Elevated Card Style

Opt in to a shadow with --audio-player-shadow for a raised card look. Set the properties in your stylesheet on a class:

.player-elevated { --audio-player-shadow: var(--shadow-m); --audio-player-padding: var(--size-s) var(--size-m); }

Keyboard Shortcuts

KeyAction
SpacePlay / Pause
Left ArrowSeek back 10 seconds
Right ArrowSeek forward 10 seconds
MToggle mute

The player itself is a tab stop (tabindex="0", exposed as a group named “Audio player” with aria-keyshortcuts) so the shortcuts have somewhere to live. Shortcuts apply when the player itself (or a non-interactive part of it) has focus. When focus is on a control — the seek or volume slider, the play or mute button, the playlist <summary> or a track link — keys keep their native behavior, so arrow keys step the focused slider and Space activates the focused control.

Progressive Enhancement

The <audio> element lives in light DOM. Before JS loads, native controls render. After the component upgrades, native controls are hidden and custom chrome takes over. If the component is removed from the DOM, native controls are restored.

Accessibility

  • All controls have aria-label attributes
  • The focusable host has role="group" and the label “Audio player” (author-supplied role, aria-label or aria-labelledby are kept)
  • The seek slider announces the position as text, e.g. “1:05 of 3:20” (aria-valuetext), updated during playback and seeking
  • The mute button keeps the stable label “Mute” and reports its state with aria-pressed
  • Load failures show a visible message in a role="status" region, so screen readers announce it politely
  • Keyboard navigable: every control is a native focusable element, and the documented shortcuts never override a focused control's own keys
  • Respects prefers-reduced-motion
  • Falls back to fully accessible native <audio> without JS

Companion: audio-visualizer

Pair with <audio-visualizer> for canvas-based frequency or waveform display. The visualizer is a separate component — it connects to any <audio> via the for attribute.
