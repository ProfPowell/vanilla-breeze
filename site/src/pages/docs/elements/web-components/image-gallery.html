Overview

A thumbnail grid that opens a fullscreen lightbox viewer on click. Progressive enhancement at every layer: without JS, thumbnails are plain links to full images. With JS, a native <dialog> lightbox adds navigation, swipe, keyboard control, and View Transitions.

The lightbox is a native <dialog> built on first open, appended inside the gallery. An empty gallery still upgrades, so thumbnails added later (markup or the .images property) open the lightbox too.

Usage

Image-only

Wrap each thumbnail in an <a> linking to the full image. The href is the full-size source; the <img> is the thumbnail.

With Captions

Wrap each item in a <figure> with a <figcaption>. Captions support HTML including links; in the lightbox they sit in a footer behind an info button (see Caption Modes).

Progressive Enhancement

Grid Configuration

Control the thumbnail grid layout with columns, gap, and ratio attributes.

Lightbox Navigation

  • Prev/Next buttons on either side of the image (controls="edge") or in the top bar (controls="bar")
  • Keyboard: ArrowLeft/Right (previous/next, swapped in right-to-left documents), Home/End, Escape to close
  • Swipe: Left/right touch gestures on the image area, also direction-aware
  • Loop: Add loop attribute to wrap at ends

The header shows a counter ("Image 3 of 8" by default) that is announced politely on navigation, plus the close button. Focus returns to the thumbnail when the lightbox closes.

Lightbox Controls and Transitions

AttributeValuesBehavior
controlsedge (default), bar, minimaledge: prev/next on the sides, header floats over the image. bar: prev/next move into the top bar. minimal: close only; navigate by keyboard or swipe.
transitionmorph (default), fade, nonemorph: the thumbnail morphs into the full image (View Transitions). fade: cross-fade between images only. none: no transitions.

Changing controls or captions closes an open lightbox; it is rebuilt on the next open.

Caption Modes

The captions attribute controls how <figcaption> content appears in the lightbox.

ValueBehavior
auto (default)Footer with an info button that shows/hides the caption text (aria-expanded + hidden); the footer only appears for images with a caption
overlayCaption shown below the image inside the frame
hiddenCaptions suppressed in lightbox (still visible in grid)

JavaScript API

The images property reads or replaces the image set. Each entry is { href, thumbSrc, alt, caption }. A string caption is rendered as plain text, never parsed as HTML; pass a Node, DocumentFragment, or <template> for rich captions. Reading returns a string for text-only captions and a cloned DocumentFragment when the caption has markup.

const gallery = document.querySelector('image-gallery'); gallery.addEventListener('image-gallery:images-changed', (e) => { console.log(e.detail.images.length, e.detail.source); // 2 'property' }); gallery.images = [ { href: '/photos/1.jpg', thumbSrc: '/photos/1-thumb.jpg', alt: 'Harbour at dawn' }, { href: '/photos/2.jpg', thumbSrc: '/photos/2-thumb.jpg', alt: 'Old town', caption: 'Lisbon, 2024' }, ]; gallery.open(1); // open the lightbox at index 1 gallery.next(); // also: prev(), close()

Assigning images closes an open lightbox. Generated thumbnails load lazily. Entries without alt log a single console warning and name the link from the caption text or the counter template instead.

Accessibility

  • Native <dialog> provides focus trapping, Escape-to-close, and ::backdrop; it is named "Image viewer" by default
  • Focus returns to the thumbnail that opened the lightbox
  • Counter uses aria-live="polite" and reads "Image 3 of 8" rather than a bare "3 of 8"
  • Prev/Next buttons have aria-label and a disabled state at boundaries
  • In right-to-left documents the arrow keys, swipe direction, and chevron icons follow the reading direction
  • The info button exposes aria-expanded and aria-controls
  • Animations respect prefers-reduced-motion and the data-motion-reduced preference
