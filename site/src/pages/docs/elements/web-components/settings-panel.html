Overview

A compact settings panel opened from a gear button. It is built from native <details> sections that share a per-instance name, so only one section is open at a time. The sections hold theme selection, accessibility toggles, layout options, effects, environment shifts and system information.

It runs alongside <theme-picker>. Both components read and write the same ThemeManager state and VBStore keys, and each listens for the other's window events, so a change made in one shows up in the other on the same page. Other tabs are not synced: there is no storage listener, so a second tab picks up changes when it reloads.

Attributes

Attribute Type Default Description
open boolean — Reflected state, set by open(), close() and toggle(). Don't author it.
data-label-* string English Overrides for every visible or announced string. See Labels.

Child attributes

Attribute On Description
data-trigger <button> Marks your own trigger. Without one, the first child <button> is used, and if there is none, a gear button is generated. The runtime sets aria-haspopup="dialog", aria-expanded and aria-controls on the trigger.

Panel Sections

The panel has six collapsible <details> sections. Only one is open at a time, and Appearance starts open.

Appearance

  • Color Mode — segmented control: Auto, Light or Dark (ThemeManager.setMode).
  • Theme — a <select> grouped with <optgroup> from the shared theme list (ThemeManager.setBrand). Active accessibility themes are re-applied on top of the new theme.

Accessibility

Toggle switches (input[data-switch="s"]) that add the theme to <html data-theme> after the brand theme:

  • High Contrast (a11y-high-contrast)
  • Large Text (a11y-large-text)
  • Dyslexia-Friendly (a11y-dyslexia)

The section also has a Single-Key Shortcuts switch (WCAG 2.1.4 Character Key Shortcuts). Turning it off sets <html data-char-shortcuts="off"> and stores charShortcuts: false in vb:settings:extensions. Every unscoped single-character shortcut then stops firing: data-hotkey actions such as /, the ? key of <short-cuts>, and any component that binds shortcuts through VB's hotkey binder. Shortcuts with Ctrl, Cmd or Alt keep working. The stored choice is restored as soon as the hotkey code loads. With no stored choice, an authored data-char-shortcuts="off" on <html> is the starting state.

Layout

  • Fluid Scaling — on or off. When it's off, static token values are used.
  • Density — Compact, Default or Spacious. Shown only when fluid scaling is on.
  • Canvas Backdrop — on or off. When it's on, these controls also appear:
    • Style — Default, Flush or Elevated.
    • Chrome — Card, Stretch or Integrated.
    • Fixed Header — adds fixed to the backdrop chrome value.
    • Page Background — Theme Default, Solid Color (one color input) or Gradient (start color, end color and a direction <select>).
  • Sticky Navigation — toggles <html data-sticky> and starts or stops the sticky manager. The panel touches only the root attribute. The sticky manager owns the banner header's data-sticky: it adds the attribute only when it's missing and removes only what it added. A header you wrote data-sticky on yourself is never changed.

Effects

  • Motion Effects (default on). Turning it off sets <html data-motion-reduced>.
  • Sound Effects (default off). The sound manager is loaded only when this is turned on.

Environment

  • Time-of-Day Shifts
  • Seasonal Tinting

Both toggles call EnvironmentManager.setSource().

System

  • The Vanilla Breeze version.
  • The service-worker status, in a role="status" line.
  • Clear Cache and Check for Updates buttons. Their results are announced through a polite live region.

The Reset to Defaults button in the footer asks for confirmation inside the panel, with Reset and Cancel buttons; there is no browser confirm(). Confirming resets ThemeManager, clears the accessibility, effects and sticky preferences, and turns off the environment sources. Sticky navigation goes back to the page's authored state. The reset is announced.

Custom Trigger

Provide your own trigger button as a child element with data-trigger. If no trigger is found, a gear icon is generated.

Footer Integration

The usual place for the panel is next to the footer's legal links. The panel opens upward from the trigger, and downward when there isn't room above.

JavaScript API

Member Type Description
open() method Opens the panel and moves focus into it. If the element hasn't rendered yet (it isn't connected), the call is queued until it renders.
close({ returnFocus }) method Closes the panel. Pass returnFocus: true to focus the trigger, as Escape and the close button do.
toggle() method Opens the panel if it's closed and closes it if it's open.
data property { a11yThemes, extensions: { motionFx, sounds, charShortcuts }, sticky }. Setting it applies each field you provide to the page straight away, writes it to VBStore and updates the controls. It works before the panel renders.
const settings = document.querySelector('settings-panel'); settings.open(); settings.close({ returnFocus: true }); // Apply and persist preferences in one assignment settings.data = { a11yThemes: ['a11y-large-text'], sticky: true }; settings.addEventListener('settings-panel:data-changed', (e) => { console.log(e.detail.data); // { a11yThemes, extensions, sticky } });

State Sharing

<settings-panel> and <theme-picker> share state through these channels. When a window event arrives, the panel applies the event's detail before it updates its controls. That way it never shows stale values, and it never writes stale values back.

Channel localStorage key Window event
Theme (mode, brand, fluid, backdrop, page background) vb:theme:current (ThemeManager) vb:theme-change
Accessibility themes vb:settings:a11y vb:a11y-themes-change
Effects and shortcuts (motion, sound, single-key shortcuts) vb:settings:extensions ({ motionFx, sounds, charShortcuts }) vb:extensions-change
Sticky navigation vb:settings:sticky ("on" / "off") —

The VBStore values are wrapped in a { data, timestamp } envelope. The site's head script restores a stored sticky "on" before first paint.

Keyboard Navigation

Key Action
Enter / Space on the trigger Open the panel and move focus into it
Tab / Shift+Tab Move through the controls. Tabbing out of the panel closes it.
Escape Close the panel and return focus to the trigger

Accessibility

  • The panel is a non-modal role="dialog", named by data-label-dialog (default "Site settings"). When it opens, focus moves to the panel. It does not trap focus: tabbing out, clicking outside or pressing Escape closes it.
  • The trigger has aria-haspopup="dialog", aria-controls and an aria-expanded that tracks the open state, including across a remove and reinsert.
  • Color mode, density, backdrop style and chrome are radio groups inside <fieldset> elements with visually hidden <legend>s. Their radio names and the control ids carry a per-instance suffix, so two panels on one page don't share groups or labels.
  • Toggle switches are native <input type="checkbox" data-switch="s"> elements inside their <label>.
  • The service-worker status line is role="status". Clear Cache, Check for Updates and Reset results are announced through a visually hidden live region.
  • Reset asks for confirmation inside the panel and moves focus to Cancel.
