Overview

The <emoji-picker> component provides an accessible popup for browsing, searching, and selecting emoji. It can insert directly into a target input, textarea, or contenteditable element, or dispatch events for custom handling.

209 curated emoji by default. A focused core subset organized into 9 categories, reachable through 252 shortcodes (43 of them aliases such as :heart:). Load the extended set (/cdn/emoji-extended.js or import 'vanilla-breeze/emoji-extended', ~23 KB gzipped) to add about 1,700 shortcodes — roughly 1,640 more emoji, the full GitHub/Slack set. Glyphs listed under several shortcodes appear once in the picker; every shortcode stays searchable. The same dataset powers the data-emoji attribute (type :shortcode: straight into a field; see its accessibility notes on how screen readers name emoji), and the extended set reaches both whichever loads first.
Not what you want? For a small curated set of emoji reactions attached to a comment / post / message (GitHub-style chips + palette), use <reaction-bar> instead. <emoji-picker> exposes the full Unicode catalog; <reaction-bar> exposes a curated handful with per-option counts and toggle behavior.

Attributes

Attribute Type Default Description
for string — ID of target input, textarea, or contenteditable element for insertion.
open boolean — Reflected state attribute set by open()/close() methods. Not intended as initial markup.
recent-limit number 24 Maximum number of recently used emoji to store.
data-trigger boolean (on a child button) — Marks the trigger button. Without one, the first child <button> is used, else a trigger is created.

Localization

Every UI string can be overridden with a data-label-* attribute on the host. Emoji names come from the CLDR/gemoji dataset and are English.

Methods and Properties

Member Description
open() Open the panel and focus the search input.
close() Close the panel. Focus is not moved.
toggle() Open when closed, close when open.
isOpen Read-only boolean.
ready Promise that resolves once the panel is built (the emoji data loads asynchronously). data-upgraded is set at the same moment.

The methods are safe to call at any time: before the data has loaded, open() and toggle() are queued and applied once the panel exists, and close() cancels a queued open.

const picker = document.querySelector('emoji-picker'); await picker.ready; // optional — open() would queue anyway picker.open();

Events

Event Detail Description
emoji-picker:select { shortcode, emoji, name, keywords } Fired when an emoji is selected, after it was inserted into the for target (which also receives a native input event with inputType: "insertText").
emoji-picker:open — Fired when the picker panel opens.
emoji-picker:close — Fired when the picker panel closes.
const picker = document.querySelector('emoji-picker'); picker.addEventListener('emoji-picker:select', (e) => { console.log(e.detail.emoji); // "🚀" console.log(e.detail.shortcode); // "rocket" console.log(e.detail.name); // "Rocket" });

Custom Trigger

Provide your own trigger button as a child element with data-trigger. If no trigger is found, one is auto-created.

Without Target

Omit the for attribute to use the picker without auto-insertion. Listen for the emoji-picker:select event and handle insertion yourself.

Keyboard Navigation

The panel has three Tab stops: the search input, the category toolbar, and the emoji list. Tabbing past the list (or anywhere outside the component) closes the picker.

Key Context Action
Enter / Space Trigger Toggle picker open/close
Escape Anywhere in the picker Close picker, return focus to the trigger
Arrow Down Search input Move focus into the emoji list
Arrow Left / Arrow Right Category toolbar Previous/next category (wraps; mirrored in right-to-left pages). Home/End jump to the first/last. Enter scrolls to the category.
Arrow keys Emoji list Move by the visual layout: Up/Down go to the nearest emoji in the row above/below, across category headings. Left/Right follow reading order (mirrored in RTL).
Arrow Up Emoji list, first row Return focus to the search input
Home / End Emoji list First/last visible emoji
Page Down / Page Up Emoji list First emoji of the next category / of the current (then previous) category
Enter / Space Emoji list Select the focused emoji

After a selection, focus goes to the for target (the caret sits after the inserted emoji). Without a target it returns to the trigger.

Recents

Selected emoji are stored in localStorage (key: vb-emoji-recent) and shown as a “Recently used” section at the top of the grid. The recent-limit attribute controls how many are kept.

Progressive Enhancement

Without JavaScript the [data-trigger] button is hidden (emoji-picker:not(:defined)), so there is no dead control. The text field still works and users can type emoji with their OS emoji keyboard (Cmd+Ctrl+Space on macOS, Win+. on Windows) — consider saying so in the field’s hint.

Once defined, the trigger works immediately: a click while the emoji data is still loading opens the panel as soon as it is built.

Accessibility

  • The trigger carries aria-haspopup="dialog", aria-expanded and aria-controls. A trigger with visible text keeps it as its name; an emoji-only trigger needs an aria-label (or gets data-label-trigger).
  • The panel is a role="dialog" in the top layer (Popover API), so overflow containers and dialogs never clip it. It opens below the trigger aligned to its start edge (right edge in RTL), flips above when there is no room, and stays inside the viewport.
  • Categories are plain buttons in a role="toolbar" with a roving tab stop and arrow keys; the category in view is marked aria-current="true" as the list scrolls.
  • The emoji list is a role="listbox" of labelled role="group" categories; each emoji is a role="option" named with its CLDR name (the tooltip shows the shortcode). Exactly one option is tabbable.
  • The search input has aria-controls pointing at the list, and a polite role="status" region announces the result count or “No emoji found”.
  • Insertion is a real edit: it goes through the browser’s editing command, so undo works and the target receives an input event. A selection elsewhere on the page is never touched.

Related: data-emoji Attribute

The data-emoji attribute provides a complementary approach — replacing :shortcode: text patterns with emoji characters:

  • Static content: Add data-emoji to any container to replace shortcodes in text nodes on load.
  • Live input: Add data-emoji to a <textarea> or <input> for live replacement as the user types.

Use emoji-picker when users need to browse and discover emoji. Use data-emoji when users already know the shortcode they want to type.
