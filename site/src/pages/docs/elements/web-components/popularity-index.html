Overview

The aggregated counterpart to <recently-visited>. Where that surface is local-only, this one consumes site-wide aggregate data from an analytics endpoint and shows the most-visited pages.

The default endpoint /api/analytics/popular is a Cloudflare Pages Function over VB's D1 analytics store (the same page.view aggregate the stats dashboard uses). When the endpoint is missing, errors, or has no data yet, the component shows a short generic message and reflects data-state so sites can hide it instead.

Changing analytics-src, window, limit, data-meta-src, data-lens-src or data-heading-level after upgrade re-fetches. Any request still in flight is aborted, so a slow stale response can never overwrite a newer one, and nothing renders after the element is removed.

Endpoint contract

The component expects the endpoint to respond with JSON in either of these shapes:

or simply an array. Each entry must carry url; title and views (or count) are optional. If data-meta-src is set, missing titles fall back to the matching pages.json record. VB's own endpoint returns only url and views, so pair it with data-meta-src="/pages.json" for titles.

Links are checked before they render: only http:/https: URLs and same-origin paths are kept. javascript:, data: and scheme-relative //host entries are dropped. The list is built with DOM APIs, so titles from the payload are always treated as text.

VB's endpoint accepts ?window=24h|7d|30d, ?limit=1–50 and ?site=, and returns { ok, site, window, pages }.

Accessibility

  • The list is an ordered list (<ol>), so rank is announced with each item.
  • The heading level is configurable with data-heading-level, so the panel fits the page outline instead of forcing an <h2>. Use 0 when a lens label or surrounding heading already names it.
  • While loading, the host has aria-busy="true"; the heading is present from the start.
  • View counts use Intl.NumberFormat compact notation (1.8K) and Intl.PluralRules, both for the nearest lang.
  • The provenance chip is a text label; its colour is only a secondary cue.

Styling

The heading is .popularity-heading, the list .popularity-list, and the status messages .popularity-empty. Provenance chips (.popularity-prov[data-provenance]) take their colour from the theme's AA text tokens: --color-success-text for human, --color-warning-text for ai-assisted and --color-error-text for ai-generated.
