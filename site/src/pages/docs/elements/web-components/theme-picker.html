Overview

The <theme-picker> component provides a UI for users to select their preferred color mode and brand theme. It integrates with ThemeManager for persistence and system preference detection.

ThemeManager API

For programmatic theme control, use the ThemeManager module:

import { ThemeManager } from './lib/theme-manager.js'; // Initialize (called automatically in main.js) ThemeManager.init(); // Get current state const { mode, brand, accent, effectiveMode } = ThemeManager.getState(); // Set color mode: 'auto', 'light', or 'dark' ThemeManager.setMode('dark'); // Set brand theme (personality themes) ThemeManager.setBrand('swiss'); // Set color accent (see the accent table below) ThemeManager.setAccent('ocean'); // Toggle between light and dark ThemeManager.toggleMode(); // Reset to defaults ThemeManager.reset(); // Listen for changes window.addEventListener('vb:theme-change', (e) => { // { mode, brand, accent, borderStyle, iconSet, fluid, backdrop, // backdropChrome, pageBgType, effectiveMode } console.log(e.detail); });

Creating Custom Themes

Create new brand themes by copying the template:

# Copy the template cp src/tokens/themes/_brand-template.css src/tokens/themes/_brand-coral.css

Edit the hue values (0-360). Keep the @layer bundle-theme wrapper: every theme self-declares that layer, which places it above the framework layers, below packs, and below your own unlayered CSS.

@layer bundle-theme { :root[data-theme="coral"], [data-theme="coral"] { --hue-primary: 15; /* coral orange */ --hue-secondary: 350; /* pink */ --hue-accent: 180; /* teal contrast */ /* Colors are auto-calculated from hues */ --color-primary: oklch(50% 0.15 var(--hue-primary)); /* ... */ } }

Register in src/tokens/themes/index.css:

@import "./_brand-coral.css";

Events

Event Detail Description
theme-picker:open - Fired when popover opens
theme-picker:close - Fired when popover closes
theme-picker:dtcg-download { themeId, href } A per-swatch DTCG download link was clicked (the native download still happens)
vb:theme-change { mode, brand, accent, borderStyle, iconSet, fluid, backdrop, backdropChrome, pageBgType, effectiveMode } Fired on window by ThemeManager when the theme changes. The picker listens and re-syncs.
vb:a11y-themes-change string[] (active a11y-* ids) Fired on window when an accessibility theme is toggled. Every picker and <settings-panel> listens, so all controls on the page stay in step.
vb:extensions-change { motionFx, sounds } Fired on window when extension preferences are applied (on load and on toggle). Shared with <settings-panel> the same way.

Accessibility

  • The popover is a non-modal role="dialog" with an aria-label. Focus is not trapped: opening moves focus to the selected colour mode, Escape closes and returns focus to the trigger, and tabbing out of the picker or clicking outside closes it.
  • Every radio set (mode, accent, each theme group, sizing) is a role="radiogroup" inside a labelled <fieldset>. Radio names are unique per picker, so a header picker and a mobile-menu picker on the same page don't share groups.
  • Arrow keys move through a radio group and apply each choice, but never close the popover. Only pointer selections auto-dismiss it.
  • The trigger announces its state with aria-expanded and aria-controls.
  • In forced-colours mode the selected mode segment and options use Highlight, and swatches and accent dots keep their real colours with a visible outline.
  • Accessibility themes you author on <html data-theme> (for example a11y-large-text) are kept until the visitor makes their own choice.
