Overview

This is the private half of the lens family. It lists pages the reader has visited on this device, most recent first. The data lives in localStorage under vb:recently-visited and never crosses the network.

Reader control is built in: the header has Pause tracking, Show anchor visits and Clear history buttons, and a note that the history stays on the device. The page the reader is on is left out of the list unless you add include-current.

Turning tracking on

The tracker ships in the VB bundles, but it records nothing until a page opts in. A page is recorded when either of these is true:

  • it has <meta name="vb:track-history" content="on">. Put this in your site's shared head to record every page;
  • it contains a <recently-visited> element.

Without the meta, only pages that host the lens are recorded, which is rarely what you want. Most sites should add the meta site-wide.

Opting out

A page is never recorded when any of these is true:

  • <html data-vb-no-track> is set. This is the site-wide switch, shared with VB analytics;
  • the page has <meta name="vb:no-track-history">. Use it for a single page, such as a dashboard that hosts the lens but should not appear in it;
  • the reader has pressed Pause tracking.

Privacy defaults

  • Query strings are stripped. Only the parameters listed in vb:track-history-params are kept, so reset tokens, email addresses and search terms are not stored by default. The fragment is stored separately as an anchor visit.
  • Entries expire after 30 days. Expired records are dropped whenever the history is read or written.
  • At most 100 entries are stored. The limit attribute only controls how many pages are shown.
  • Only same-origin http(s) paths are stored or rendered. A leading // is collapsed to /, so a crafted URL cannot turn into a link to another site.

Storage

Three localStorage keys are used:

vb:recently-visited
JSON array of { url, hash, title, hashTitle, ts } records, most recent first. url is a same-origin path plus any allowed query; hash is the fragment (or "") and hashTitle is the text of the element it targets; ts is epoch milliseconds.
vb:recently-visited:paused
"1" while the reader has paused tracking. If the key is absent, tracking is active.
vb:recently-visited:show-anchors
"1" when anchor visits are shown, grouped under their page in a <details>. Anchor visits are always recorded; this key only controls whether they are shown.

The reader controls all three keys. Clear history empties the first, and the two toggles set the others. Every instance on the page, and in other tabs, updates when any of them changes. In private modes that block localStorage, nothing is recorded and no error is shown.

Data API

The read-only entries property returns the stored records. Expired, malformed and off-origin records are already removed. It has no setter because the tracker owns all writes.

Accessibility

  • The controls are icon buttons with fixed labels. The two toggles report their state with aria-pressed, so screen readers announce “Pause tracking, pressed” and not a label that contradicts the state.
  • The controls are built once and then updated in place, so focus stays on the button you pressed. Clear history uses aria-disabled when the history is empty, so it keeps focus.
  • When the list re-renders, for example after a change in another tab, a focused link gets focus back.
