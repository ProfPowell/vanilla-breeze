Overview

Reads pages.json via data-lens-src and groups by author. Provides search and per-author counts. If the source request fails, any light-DOM markup the author wrote inside the host is left in place (without the search filter); if the host was empty, an error message is shown instead.

Attributes

AttributeTypeDefaultDescription
data-lens-srcstring—URL to pages.json or compatible source
srcstring—Alias for data-lens-src
placeholderstring"Filter authors…"Search input placeholder
sort"alpha" | "count""alpha"Group sort order

Source contract

The component expects either a JSON array of records or an object with a pages array, where each record carries at minimum:

{ "url": "/docs/concepts/document-provenance/", "title": "Document Provenance", "author": "Thomas A. Powell", "authorUrl": "/team/tpowell/", "modified": "2026-04-24", "provenance": "ai-assisted", "signed": true }

VB's Cook SSG plugin generate-pages-json emits this shape automatically.

Fallback markup and accessibility

Without data-lens-src or src, nothing is fetched. The component keeps the light-DOM markup you author and prepends a search input that filters it. Each group to be filtered must carry data-author-group; a group is hidden when its text does not contain the query. Native <details> elements keep the groups usable and keyboard-accessible without JavaScript.
