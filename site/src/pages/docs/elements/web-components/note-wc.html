Overview

<note-wc> adds private reader notes to highlighted text. It owns the note panel (quote, textarea, Save and Cancel) and opens it in three ways:

  • Inside <selection-menu> — one click highlights the selection (or reuses the highlight it falls inside) and opens the panel.
  • With for="id" (standalone or in <page-tools>) — a page-level button that opens the panel for the first noted highlight on the target, or the first highlight if none has a note.
  • Margin annotations — clicking a highlight’s margin label on a data-highlights article dispatches highlights:request-note; the first connected note-wc opens its panel for that highlight. A note-wc with no for outside a selection menu renders no button and only hosts the panel.

Notes are the reader’s private marginalia — stored in localStorage, not shared with others. For collaborative comments, use <comment-wc> with <review-surface>.

How It Works

  1. The reader selects text and clicks the sticky-note icon in the toolbar.
  2. note-wc locates the selection by text offset. If it falls inside an existing highlight, that highlight is reused; otherwise a yellow highlight is created.
  3. note-wc opens its note panel beside the highlight with a textarea for the private note.
  4. Notes persist in localStorage alongside the highlight data, and saving fires highlights:note-changed on the article.
  5. Notes appear as margin annotations (“* You highlighted”) beside the text; clicking one reopens the panel.

Accessibility

  • The button is named “Add private note” (selection-menu) or “View notes” (page-level); override with data-label-*.
  • The note panel has role="dialog" and an accessible name; the textarea is focused when it opens.
  • Ctrl+Enter (Cmd+Enter on macOS) saves; Escape anywhere in the panel cancels.
  • On Save, Cancel, Escape or an outside click, focus returns to the opener if it is still visible, otherwise to the highlight’s <mark> or the article, so it never drops to the page body.
  • Without JavaScript there is no toolbar and nothing renders; the article reads normally.
