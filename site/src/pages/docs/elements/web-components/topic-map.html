Overview

Joins two data sources to draw a concept tree. vocabulary.json supplies the SKOS graph (skos:broader, skos:narrower, skos:hasTopConcept) and the display labels. pages.json supplies each page's concepts: [] array, harvested by the build from repeated <meta name="concept"> tags (per meta-tag contract v1.1). Each node's summary shows the concept's skos:prefLabel and a count of distinct pages tagged with that concept or any descendant (a page tagged with a parent and its child counts once). The /topics/{id}/ link sits first inside each node, so the summary only toggles.

The tree is built by JavaScript from the fetched JSON; without JavaScript the element shows only whatever fallback content you author inside it. Once rendered, the tree uses native <details> disclosure, so there is no custom keyboard code.

Inside content-lens

<content-lens> already names each lens with its radio label, so turn the panel heading off with data-heading-level="0".

Authoring concept tags

Each content page declares the concepts it covers in frontmatter:

concepts: - data-provenance - page-info - meta-tag-contract

The build emits one <meta name="concept"> per id, and generate-pages-json.js harvests them into the page's concepts: [] array. The ids must resolve against vocabulary.json — concepts not in the vocabulary land under Uncategorized. Hierarchy comes from skos:broader / skos:narrower in the vocabulary, not from path strings.

JavaScript API

Assign already-loaded payloads to skip the fetch. While set, data takes precedence over data-lens-src.

document.querySelector('topic-map').data = { pages, vocabulary };
MemberDetailNotes
data (property){ pages, vocabulary } | nullReturns the assigned payload, or null when the tree came from src.
topic-map:data-changed (event){ pages, vocabulary, source: 'property' }Fires after data is assigned and the tree re-renders.

Safety

Page URLs that are not http(s) or relative (for example javascript:) render as plain text, not links. Cycles in skos:broader / skos:narrower are skipped instead of recursed.
