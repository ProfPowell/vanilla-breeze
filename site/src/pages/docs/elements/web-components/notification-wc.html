Overview

<notification-wc> ships two modes that share an element name. Pick with mode="banner" or mode="panel" (the default).

  • Banner — full-width, sticky strip with a dismiss button. Dismissal persists across reloads via VBStore under the namespace notifications; optional expires re-shows after N days.
  • Panel — bell-icon trigger with an unread badge. Click opens a drawer with a list of notifications composed from static <article> children and (optionally) a dynamic JSON feed. Per-item read state persists via VBStore.

With scripting disabled both modes still show their content: the banner is plain HTML and the panel’s static <article> children render inline as a list. JS adds dismissal, read tracking, and dynamic fetches. While a script is still loading, the panel’s articles (and a banner with persist) stay hidden so they don’t flash before the upgrade.

Banner Mode

A site-wide announcement strip. The persist attribute is the VBStore key under which dismissal is recorded. variant sets the color, position sticks it to the top or bottom, expires (days) lets the banner re-show after a time window.

Dismissal is recorded as vb:notifications:site-update-v3 in VBStore. Wipe the key from devtools (or call VBStore.remove('notifications', 'site-update-v3')) to test the show flow again.

Panel Mode

An ambient bell-icon trigger that opens a panel listing notifications. Static <article> children are the no-JS fallback and the source of truth for the IDs they declare; dynamic notifications fetched via src are merged on top by data-id.

Supply your own trigger by placing a <button data-trigger> child; the unread badge is appended inside it.

While there are unread items the element carries data-unread with the count, for styling from outside. Mark a header bell data-mobile-menu to have <mobile-menu> move it into its panel on narrow screens.

The panel has two forms. On a wide screen it is a dropdown under the bell. On a narrow screen (below 37.5rem), or when the bell sits inside a popover such as a mobile menu, it opens as a sheet in the top layer instead: full width from the top edge on a phone, centred on anything wider, with a backdrop and a close button. A menu behind it stays open. Escape, the close button and a click on the backdrop all close the sheet and return focus to the bell.

Dynamic feed shape

The src attribute accepts an absolute URL (/api/notify or https://…) or a VBService role name. The endpoint must return either an array or an object with a notifications array. Each entry:

{ "id": "release-3.0", "type": "update", "title": "v3.0 Released", "body": "New notification system.", "url": "/changelog#v3", "date": "2026-04-10T00:00:00Z", "dismissed": false }

Rows link to url only when it resolves to http: or https: (relative URLs included); any other scheme, such as javascript:, renders the row as a plain button. Dates are formatted with Intl.DateTimeFormat in the document language; date-only values (2026-04-10) are shown as that calendar day in every time zone.

Setting notifications from JavaScript

The notifications property takes the same entry shape as the feed. Entries merge over the static articles by id; the getter returns a copy. Each assignment re-renders and fires notification-wc:notifications-changed.

const bell = document.querySelector('notification-wc'); bell.notifications = [ { id: 'build-42', type: 'system', title: 'Build 42 passed', date: '2026-11-04T09:00:00Z', url: '/builds/42' }, ];

Six recognized type values pick the row icon: update (package), alert (alert-triangle), watch (eye), system (settings), message (mail), stewardship (shield).

Polling

Set poll in milliseconds to re-fetch on an interval (e.g. poll="300000" for every 5 minutes). The component runs setInterval, cleared automatically when the element disconnects.

Toast on new

With toast-new set, every never-before-seen entry on a non-initial fetch fires a toast on the <toast-msg> matched by its value (a selector such as toast-new="#alerts"); a bare toast-new, or a value that matches nothing, uses the first <toast-msg> in the document. The first fetch is silent so the page does not light up on every reload.

Watching tab

The panel grows two sub-tabs — All and Watching. The Watching tab reads VBStore namespace watches and lists every page the user has bookmarked via data-watch-page. Each row shows title, URL, time of last check, an “Changed” badge when the page’s content hash drifted since the user last visited, and a per-row Unwatch button. The tab’s count badge shows how many pages the user is watching.

The list refreshes whenever the panel opens, and also when a page-watch:add or page-watch:remove event fires anywhere in the document.

Labels

Every English string in the panel can be overridden on the element with data-label-*: trigger (Notifications), unread ({n} unread), title (Notifications), mark-all (Mark all read), tabs (Notification categories), all (All), watching (Watching), empty (No notifications), watch-empty, last-checked (Last checked: {date}), never (—), changed (Changed), unwatch (Unwatch {title}) and new (New notification, the toast fallback).

Accessibility

  • The bell trigger gets aria-haspopup="dialog", aria-controls and aria-expanded. Its accessible name includes the unread count (“Notifications, 3 unread”); the visual badge is aria-hidden.
  • Opening moves focus into the drawer (role="dialog", named by its heading). Esc closes it and returns focus to the trigger; tabbing out of the component or clicking outside also closes it, returning focus to the trigger if it was inside the drawer.
  • The All / Watching switcher is a full tabs pattern: role="tablist", tabs with aria-controls, role="tabpanel" panels, and ← → Home End with a roving tabindex.
  • After upgrade the static articles are re-rendered as rows inside the drawer and the originals are hidden, so the content is reachable through the drawer, not by page heading navigation.
  • Dismissing a banner that holds focus moves focus to <main> rather than dropping it on the page body.
  • In forced-colors mode the badge, the selected tab and unread rows get system-colour borders.
