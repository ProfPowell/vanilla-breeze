Overview

The splitter provides resizable panel support as a two-layer progressive enhancement story — from attribute init to full web component — matching a "platform-first, enhance upward" philosophy.

Layer 1: Attribute Init

Light JS (about 200 lines). Apply data-splitter to a container. A small init script injects a full-height drag divider between the first two children with pointer and keyboard events.

Position and persistence

position is the default split. With persist, the user’s last layout (position and collapsed state, stored under vb:layout:split:{key} after they resize) wins over position on the next load; reset() clears it and returns to position. Changing position, min, max or direction after upgrade is applied; the attribute is not reflected, so read the live value from the position property.

Collapsing

With collapsible, Enter or a double-click on the divider collapses the first panel to zero and back. While collapsed the panel is inert (its links and controls leave the tab order), the divider reports aria-valuenow="0" with aria-valuetext “Collapsed” (data-label-collapsed to translate), and any arrow, Home or End key expands it again — the keyboard is never trapped. split-surface:state(collapsed) styles the collapsed state.

The divider is created asynchronously (after the persisted layout is read), so properties and reset() set right after creating or appending the element are queued and applied once it is ready.

Accessibility

Separator Role

The divider has role="separator" with aria-valuenow, aria-valuemin, aria-valuemax and aria-controls (the first panel; an id is generated when missing). aria-orientation is the divider's own axis: vertical for side-by-side panels, horizontal for direction="vertical". Screen readers announce the current position; <split-surface> adds an aria-valuetext such as “30%” or “Collapsed”. When collapsible is set, aria-valuemin is 0 because the panel can reach zero.

The accessible name defaults to "Resize panels"; set data-label-resize to translate or specialise it.

Keyboard Support

The divider is focusable (tabindex="0") and responds to arrow keys. Shift + arrow provides larger steps. Home and End jump to min/max. On a collapsible <split-surface>, Enter collapses and expands, following the APG window-splitter pattern, so collapse is not mouse-only.

Forced colors

In Windows High Contrast the divider is drawn in CanvasText with a Canvas grip, and hover, drag and focus switch to Highlight, for both layers.

Touch Support

The divider uses touch-action: none and setPointerCapture for reliable pointer drag behavior across devices. A cancelled gesture (pointercancel or lost capture) ends the drag cleanly.

Styling

The divider uses the .split-divider class shared by both layers. The ::after pseudo-element renders a grip indicator.

/* Custom divider color */ .split-divider { background: var(--color-interactive); } /* Custom grip handle */ .split-divider::after { background: white; border-radius: 4px; }

Progressive Enhancement

Without JavaScript, <split-surface> renders as a simple two-column flex layout. The :not(:defined) selector provides the fallback. Once JS registers the component, the divider appears.

/* Without JS: simple two-column flex */ split-surface:not(:defined) { display: flex; gap: var(--size-s); } split-surface:not(:defined) > * { flex: 1; min-width: 0; }
