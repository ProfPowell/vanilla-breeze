Overview

A lightweight YouTube embed that uses the facade pattern: it renders a thumbnail and a play button on page load and defers the ~500 KB YouTube iframe until the reader presses play. The player loads from youtube-nocookie.com. The default thumbnail is fetched from i.ytimg.com on render; set a local poster to keep Google out of the page until play (see Privacy).

Light DOM only (no shadow root), so design tokens and utility classes apply naturally.

Default

Provide a YouTube video ID via video-id and the video's title via title. The play button is named "Play {title}". Without poster the thumbnail comes from i.ytimg.com.

Rounded

Apply the rounded class (inherited from the <video> native element vocabulary).

With Caption

Wrap in a <figure> with <figcaption> for a captioned embed.

Playlist

Pass a YouTube playlist ID via list. YouTube manages the playlist UI inside the iframe.

Local Poster

Set poster to a local image URL. The facade shows it instead of the YouTube thumbnail, so nothing is requested from Google until the reader presses play.

Start and End

Use start and end to play a clip, in whole seconds. Other formats (such as 1m30s) are ignored with a console warning; <social-embed> converts t=1m30s URLs to seconds for you.

Extra Player Parameters

params is an escape hatch for any other player parameter. Its keys override start, end, list and autoplay; the embed host cannot be changed.

Reconnect

Moving or re-inserting the element renders the facade again (state="ready"). A moved iframe reloads anyway and would restart playback, so the reader presses play again instead. With autoplay, the iframe is loaded again (still without taking focus).

Progressive Enhancement

Author an <a> fallback inside the element. Without JavaScript, the link takes the user to YouTube. Once the component upgrades, the facade replaces the link.

Privacy

What reaches Google, and when:

MomentWithout posterWith poster
Page load (facade)One image request to i.ytimg.com. It carries the reader's IP address but no referrer (referrerpolicy="no-referrer") and no cookies.Nothing
Reader presses playThe player loads from www.youtube-nocookie.com with referrerpolicy="strict-origin-when-cross-origin" (YouTube needs the origin). From here YouTube's own scripts run and may store data.
autoplayThe player loads on page load, with no facade step.

If your consent policy treats an image request to Google as tracking, always set poster. <social-embed> passes its own poster through to the player.

Accessibility

  • The inner <button> is the only control: one tab stop, named "Play {title}" (override with data-label-play). It covers the whole facade, so a click anywhere on the thumbnail plays.
  • The host has no role or tabindex, so there is no nested interactive control.
  • Thumbnail or poster image has alt="" (decorative; the button has the name)
  • Enter and Space activate the button natively
  • After the reader presses play, focus moves to the iframe. autoplay never moves focus.
  • Iframe has a descriptive title attribute
  • autoplay is ignored under prefers-reduced-motion; the hover scale uses the motion tokens, which drop to 0 ms under reduced motion
  • No-JS fallback is a plain anchor with meaningful text
