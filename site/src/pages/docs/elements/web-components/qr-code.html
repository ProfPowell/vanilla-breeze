Overview

The <qr-code> component encodes text or a URL as a QR code on a canvas. Without JavaScript, its children (plain text or a link to the same URL) are what readers see. After upgrade those children stay in the element as the code’s caption.

vanilla-breeze.com Hello, World!

Encoder. Encoding uses Project Nayuki’s QR Code generator library (MIT), vendored in src/vendor/qrcodegen/. It supports versions 1–40 and numeric, alphanumeric and byte (UTF-8) modes, and it picks the smallest version and the best mask. A unit test decodes generated codes at every level with an independent decoder (jsQR). There are no runtime dependencies.

Sizes

size sets the edge of the whole box in CSS pixels, with the quiet zone included. Each module is drawn as a whole number of device pixels, and the canvas is scaled for devicePixelRatio. Any pixels left over widen the white margin. For phone scanning, keep the code at least about 2 cm across in print and 100 px on screen.

100px 200px (default) 300px

Colors

By default every code is black modules on an opaque white background with a four-module quiet zone. The theme, dark mode and forced colours do not change it, because inverted (light-on-dark) or low-contrast codes fail on many scanners. In forced-colours mode the canvas keeps its pixels and gets a CanvasText border so the edge of the box stays visible.

color and background are explicit opt-ins and accept any CSS colour. Keep the modules darker than the background. When a custom pair is inverted, below about 4:1 contrast, or translucent, the element logs a console warning.

Error Correction and Capacity

error-correction accepts L, M, Q or H (case-insensitive), or 0–3. The default is M. Higher levels let a damaged or partly covered code still scan, but they hold less data, so the code needs more modules for the same text. The level you set is the level that is used.

Level Recovers up to Max bytes (UTF-8) Max alphanumeric Max digits
L / 0~7%295342967089
M / 1 (default)~15%233133915596
Q / 2~25%166324203993
H / 3~30%127318523057

These are the limits of the largest code (version 40, 177 modules per side). In practice keep URLs short: a code above about version 10 needs a large size to scan reliably. Alphanumeric means digits, upper-case A–Z, space and $%*+-./:. Any other text is encoded as UTF-8 bytes.

When the text does not fit, no code is drawn, so there is never a truncated or unreadable one. Instead the element sets data-error="capacity", shows its caption, and fires qr-code:error.

L H The link, as text

JavaScript API

Member Returns Description
value string The encoded text. Setting it sets the value attribute and redraws. Setting '' removes the attribute, and the element falls back to its original text content.
toDataURL(type?) string The code as a data URL (default image/png), opaque and with the quiet zone. Returns '' when no code is drawn.
copy(options?) Promise<boolean> Copies the code to the clipboard as the encoded text (text/plain) and a PNG (image/png), so it pastes as text in text fields and as an image in design and chat tools. Browsers without ClipboardItem get text only. options.button gets data-state="copied" and a copy:done event (data-state="failed" and copy:error on failure). Screen readers hear data-label-copied. Resolves false when no code is drawn or the write fails.

Progressive Enhancement

Without JavaScript, the element’s children are shown as they are. A link to the encoded URL is the best fallback, because it does what scanning would do. After upgrade the canvas is added before the children, and the children are not removed.

Accessibility

  • The canvas has role="img" and a short name, “QR code”. Change it with data-label-prefix, for example to translate it.
  • The children (the caption) carry the value. They are visually hidden by default and read once, after the image. Add data-caption="visible" to show them under the code.
  • A link in a hidden caption is still keyboard-reachable, and the caption is shown while the link has focus.
  • When no code can be drawn, the caption is shown so the content is never lost.
  • Colours are fixed black on white, with an opaque quiet zone, in every theme, in dark mode and in forced colours.
