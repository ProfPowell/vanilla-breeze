Overview

Reads pages.json and presents four orthogonal dimensions as checkbox groups: provenance, review level, status, and has signature. Several values in one group combine with OR; groups combine with AND. Ticking both Yes and No under Has signature is the same as ticking neither.

It answers reader questions like show me every page that's AI-generated and editor-reviewed. Only the count (“3 of 10 pages”) is a live region; the list sits beside it, so a change is announced as one short message. Nothing is announced on first load.

Attributes

AttributeTypeDefaultDescription
data-lens-srcstring—URL to pages.json
srcstring—Alias for data-lens-src
data-label-*stringEnglishText overrides: form, provenance, review, status, signed (“Has signature”), yes, no, clear, has-signature, error, no-source, plus the count templates page ({count} of {total} page) and pages ({count} of {total} pages), chosen with Intl.PluralRules.

“Has signature” is not verification

The signed field in pages.json is set at build time when a page carries a <meta name="vb:signature">. It says a signature is declared, not that it checked out. Verification happens in the reader's browser in <page-info>, which can report a declared signature as failed. That is why the group is labelled Has signature and shown in neutral text, not in success colours.

Events

EventDetailWhen
trust-filter:change{ selected, count }Reader ticks, unticks or clears a filter; selected is a per-dimension array of values. Not fired on the initial render or when the element reconnects (which rebuilds the controls unchecked and clears the selection).

Provenance composition

The vb:provenance attribute is space-composable (e.g., "ai-generated translated"). The trust-filter splits each page's tokens and matches against any selected chip. A page tagged "ai-generated translated" matches both the ai-generated chip and the translated chip independently. The provenance colour in the results also matches per token, using theme tokens.

Safety

Result URLs that are not http(s) or relative (for example javascript:) render as plain text. Load errors show a generic message; the detail goes to the console.
