Quick Start

Here's where you'll get started with Vanilla Breeze and see what it can do. Vanilla Breeze takes plain semantic HTML and enhances it with styles, layout attributes, components, and a theme, all without the need for utility classes or build steps.

Elements

Vanilla Breeze styles native HTML elements and adds custom elements and web components. Browse the ${elements.nativeCount} native elements, ${elements.customCount} custom elements and ${elements.componentCount} web components.

Native

Vanilla Breeze styles and animates the native <details> element, which shows a summary and expands to reveal more content.

Custom

Custom elements are new tags styled entirely with CSS. Use <chat-thread>, <chat-message> and <chat-bubble> to show a conversation, including the typing indicator.

Web component

Web components are new tags that use JavaScript to progressively enhance the HTML inside them. <data-table> adds sortable columns to a regular <table>.

Themes

Vanilla Breeze changes the look of the whole page with two attributes on the <html> element: data-theme and data-mode. See all ${themeRegistry.length} themes on the Themes page.
