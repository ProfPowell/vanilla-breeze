Quick Start

One HTML file, ten minutes. You'll write a plain page, then add Vanilla Breeze one optional layer at a time: styles, layout, components, theme. No utility classes, no wrapper divs, no build step.

1. Install in 60 seconds

Save this as index.html and open it in a browser. That's the whole setup.

CDN
npm
Self-host

Copy node_modules/vanilla-breeze/dist/cdn/ into your site and link vanilla-breeze.css and vanilla-breeze.js from there, exactly as in the CDN version.

The JS line is optional; step 5 shows when you need it. Zero dependencies. Want a smaller footprint? The core bundles (vanilla-breeze-core.css and vanilla-breeze-core.js) cover most pages; see loading strategies.

3. Layout is an attribute

Put data-layout on the element you already have. Same markup, different arrangement.

The one structural change is the <section> wrapping the main column, because sidebar needs a content child next to the <aside>. It finds the <aside> by element type, not by class. Resize the window: the cards reflow and the aside drops below when space runs out.

The layout vocabulary
data-layoutArranges children…Key modifiers
stackvertically, evenly spaceddata-layout-gap, data-layout-align
clusterin a wrapping row at natural widthdata-layout-justify, data-layout-align, data-layout-nowrap
gridin auto-fit columnsdata-layout-min (xs–xl)
sidebaras a nav/aside beside content, wrapping when narrowdata-layout-side="end", data-layout-sidebar-width
switcherin one row or one columndata-layout-threshold, data-layout-limit
centerin a centered, max-width columndata-layout-max (narrow, normal, wide, prose)
coveraround a vertically centered principal elementdata-layout-min, data-layout-centered
columnsin newspaper-style text columnsdata-layout-column-count

Every value takes data-layout-gap on the spacing scale (none, 3xs to 3xl). Prefer elements? <layout-stack>, <layout-grid> and friends are the same layouts. Full data-layout reference →

5. Add components where HTML runs out

Steps 2–4 were CSS only. You already used one CSS-only custom element: <form-field> around the email input, which shows validation messages without JavaScript (<layout-card> is another). For behaviour, add the script and wrap elements you already have.
