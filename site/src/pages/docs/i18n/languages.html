The lang attribute

Set lang on <html> for the page and on any element whose content is in another language. The rules below are written with :lang(), which matches the element and everything inside it, so one attribute on a section is enough.

Typography by script

Scripts differ in more than their letters. Chinese, Japanese and Korean text has no spaces to break lines at. Arabic and Thai have marks above and below the line that collide at a Latin line height. For each script the library sets a typeface stack, a line height and line-breaking rules.

Typeface tokens

Each script has a token that holds its typeface stack. The defaults name fonts that ship with the common operating systems. Override a token to use a font you serve.

:root { --font-cjk: "Noto Sans CJK SC", "PingFang SC", system-ui, sans-serif; --font-arabic: "Noto Sans Arabic", "Segoe UI", system-ui, sans-serif; --font-hebrew: "Noto Sans Hebrew", "Segoe UI", system-ui, sans-serif; --font-thai: "Noto Sans Thai", "Leelawadee UI", system-ui, sans-serif; --font-devanagari: "Noto Sans Devanagari", system-ui, sans-serif; }

The Typography guide covers the type system for Latin text. Typefaces lists the fonts served with the library.

Quotation marks

The <q> element draws the quotation marks of the language it is in. Write <q> and leave the marks out of your text. The same sentence is then correct in every translation.

She said hello.

Sie sagte hallo.

Elle a dit bonjour.

彼女はこんにちはと言いました。

Ruby annotations

<ruby> places a small reading aid above or beside a character, as furigana does in Japanese and pinyin in Chinese.

Annotations are visible by default. Put data-ruby on <html>, any ancestor, or the <ruby> itself to change that for its subtree; the nearest data-ruby wins:

ValueBehavior
(absent)Visible (browser default)
showVisible; undoes an outer hide or auto
hideVisually hidden, still in the accessibility tree
autoVisible when the annotation's own language is CJK (ja, zh, ko, yue, wuu), visually hidden otherwise
