Overview

Typography in Vanilla Breeze is CSS only. Every feature on this page is a progressive enhancement: a browser that does not support a property ignores it and keeps the base style. Most of it applies to plain elements with no classes or attributes, and the rest is opt-in.

This guide explains how the pieces fit together. Each section links to the element or attribute page that holds the full reference.

The demo below is one article and a few cards that use most of them.

Foundations

Type is set from tokens, so a theme can change the fonts and the scale without touching markup.

Text wrapping

Headings use text-wrap: balance, so a heading that wraps breaks into lines of similar length. Paragraphs use text-wrap: pretty, which avoids a single short word on the last line.

Emphasis

Font synthesis

When a font has no bold or italic face, a browser can synthesize one by thickening or slanting the glyphs. Vanilla Breeze sets font-synthesis: weight style on <strong>, <b>, <em> and <i>. A real bold or italic face is always used when the font has one. Synthesis only fills in for single-face fonts, which several theme fonts are, so emphasis never looks like body text. Small-caps and position synthesis stay off.

font-optical-sizing: auto lets a variable font adjust stroke weight and contrast to the rendered size.

strong, b { font-weight: 600; font-synthesis: weight style; font-optical-sizing: auto; } em, i { font-style: italic; font-synthesis: weight style; font-optical-sizing: auto; }

Bold in code

Inside <code> and <pre>, bold text also gets a tinted background. Weight differences are hard to see in monospace fonts.

Italic inside italic

Emphasis inside text that is already italic turns upright, so it still stands out. The italic contexts are <blockquote>, <cite>, <dfn>, <var>, <em> and <i>. A blockquote's attribution (its <footer> or <cite>) is upright, so emphasis there is italic again. The <em> page lists every case.

Subscript and superscript

<sub> and <sup> are drawn smaller and shifted off the baseline (font-size: 0.75em, line-height: 0, position: relative). This works with every font and does not push lines apart. When you know the font has its own subscript and superscript glyphs, add data-variant="opentype" to use font-variant-position.

Headings

All headings, h1 to h6, get four refinements:

  • text-wrap: balance evens out the lines of a wrapped heading.
  • line-height: var(--line-height-tight) closes up multi-line headings.
  • font-variant-numeric: lining-nums keeps numbers the height of capital letters.
  • hyphens: none stops headings from being hyphenated.

h1 and h2 also get tighter letter-spacing, which large text needs:

ElementLetter spacing
h1-0.025em (var(--letter-spacing-tight))
h2-0.01em
h3 to h6Normal (inherited)
h1 or h2 with data-display-0.03em, with a larger viewport-scaled size

The headings page covers the display variants and theme ornaments. <hgroup> covers eyebrows, bylines and section headers.

Long-form prose

An <article> with data-prose, or with the blog class, is set for reading. It gets a line height of 1.6, old-style numerals that sit with lowercase text, a larger size when its column is wide, and hyphenation.

Hyphenation

Hyphenation needs a lang attribute on the article or any ancestor, usually <html>. Without it the browser has no dictionary and nothing is hyphenated.

PropertyValuePurpose
hyphensautoEnable automatic hyphenation
hyphenate-limit-chars6 3 2Min 6 chars, at least 3 before and 2 after break
hyphenate-limit-lines2No more than 2 consecutive hyphenated lines
hyphenate-limit-zone8%Only hyphenate in rightmost 8% of line

The constitutionality of the telecommunications infrastructure was unprecedented.

Drop caps

Put data-drop-cap on an <article> or on one <p> to enlarge the first letter. Browsers that support initial-letter (Chrome, Edge and Safari) use it. Others fall back to a floated letter.

Once upon a time, in a land far away, there lived a great typographer who cared deeply about the first letter of every paragraph...

The quick brown fox jumps over the lazy dog.

Four tokens adjust it: --drop-cap-lines (default 3), --drop-cap-color, --drop-cap-font and --drop-cap-weight. See article: data-drop-cap.

Section numbering

data-section-numbers on an <article> numbers its headings in the legal style: each h2 becomes § 1, § 2, and each h3 becomes § 1a, § 1b. For outline numbering (1.1, 1.2) use data-numbered. Both are on the article page.

Baseline unit (--lh)

The --lh token is 1.5rem, one line of body text. Use it for spacing that should fall on the line grid:

article[data-prose] p + p { margin-block-start: var(--lh); /* one line */ } article[data-prose] h2 { margin-block-start: calc(var(--lh) * 2); /* two lines */ }

Hanging punctuation

<blockquote> sets hanging-punctuation: first last, so opening and closing quotation marks hang outside the text edge. Only Safari supports this today. For quotation marks that follow the language, see i18n.

Lists

Marker variants

data-marker on a <ul> replaces the bullet with check, arrow, dash or star. The glyph is decorative and is not read aloud. A list of checkmarks carries no state, so use checkboxes for a real task list.

  • Task completed
  • All tests passing
  • Feature one
  • Feature two

Metadata list

The meta class on a <ul> or <ol> sets the items inline with a middle dot between them. Use it for a byline, tags or similar short facts. data-separator changes the dot to pipe, dash or slash.

Block progress

A progress bar drawn with Unicode block characters, for terminal-style interfaces. role="meter" and the aria-value* attributes give it a value that assistive technology can read. For an ordinary bar use <progress> or <meter>.

Print

When a page is printed, the address of each external, email and phone link is printed after its text, and an <abbr> prints its title. Links to images and to places on the same page are left alone. See Printing and the data-print attribute.
