Overview

The rel attribute is a space-separated list of link types describing how the target relates to the current document. On <link> it loads things (stylesheets, icons, preloads). On <a>, <area> and <form> it annotates a navigation: whether the new page gets window.opener and a referrer, and what the link means (help, tag, next, external).

Applies to: <a>, <area>, <form> and <link>. Each link type is allowed on some of these and not others.

VB styles links by their rel: tag links become chips, external gets an arrow, help a dotted underline, prev/next get arrows, and legal links are muted.

Values

Tokens are case-insensitive and unordered; unknown tokens are ignored. There is no default: without rel a link is a plain hyperlink, and a <link> does nothing.

Opener and referrer (a, area, form)

ValueEffect
noopenerThe new page's window.opener is null, so it cannot navigate your tab. Implied for target="_blank".
noreferrerNo Referer header and an empty document.referrer. Also implies noopener.
openerOpts back in: a _blank page keeps window.opener. Use only for trusted, cooperating pages.

Resources (link)

ValueEffect
stylesheetLoad and apply CSS.
icon, manifestFavicon; web app manifest.
preloadFetch a resource this page needs, early. Requires as; fonts also need crossorigin.
modulepreloadFetch and parse an ES module early.
preconnectOpen a connection (DNS, TCP, TLS) to an origin you will use soon.
dns-prefetchResolve an origin's DNS only.
prefetchFetch something a later page will need, at low priority.
expectWith blocking="render", hold first render until the element with the given id has been parsed.
canonical, alternateThe preferred URL; translations, feeds and other versions (hreflang, type).

Meaning (a, area; some also on link)

ValueMeaning
externalLeads to a different site.
help, license, authorContext help; the content's license; the author.
privacy-policy, terms-of-serviceThe site's legal pages.
tag, bookmarkA topic tag for this content; a permalink to the nearest article.
prev, nextPrevious and next documents in a series.
searchA search interface for this site.
nofollowThe site does not endorse the target (search engines).
ugc, sponsoredUser-generated and paid links; search-engine conventions, not in the HTML standard.
meAnother profile of the same person (used for Mastodon verification); a microformats convention.

In Vanilla Breeze

  • Styling hooks (src/utils/links.css): a[rel~="external"] arrow, help dotted underline, tag pill, prev/next arrows, muted license/privacy-policy/terms-of-service. Decorations are suppressed inside nav, header and footer, and with data-no-icon. All selectors use :where(), so themes override them easily.
  • hgroup.byline a[rel~="author"] gets byline styling (src/native-elements/hgroup/styles.css).
  • Automatic noopener. When a page contains a[target="_blank"], VB loads src/utils/links-init.js, which adds rel="noopener" to any such link without opener, noopener or noreferrer. With <html data-link-privacy="strict"> it also adds noreferrer. Browsers already imply noopener; the explicit token makes intent visible in the DOM.
  • VB components that open external links set rel="noopener noreferrer" themselves (<nav-bar>, <geo-map>, <share-wc>, <ai-summary>).
  • The full vocabulary and philosophy: Link relations.

Accessibility

  • rel is not announced by screen readers. If a link opens a new tab or leaves the site, say so in the link text or with visually hidden text; VB's arrow glyphs are decorative (empty alt text).
  • rel="prev"/next do not create keyboard shortcuts; keep visible pagination links.

Security

  • noopener is the default for target="_blank" on links, areas and forms. Writing it is harmless and documents intent. It does not cover window.open(): pass 'noopener' in the features string.
  • noreferrer is a privacy choice, not a security requirement. It hides your URL from the destination, but it also removes referral data that partners and your own analytics use. The default referrer policy already sends only your origin to other sites.
  • Avoid rel="opener" for third-party pages: they could navigate your tab to a look-alike page (reverse tabnabbing).

Browser support

Implicit noopener for _blank: Chrome 88, Firefox 79, Safari 12.1. modulepreload: Chrome 66, Firefox 115, Safari 17. expect: Chrome 124 and Safari 18.2, not Firefox (MDN browser-compat-data, November 2026).

Gotchas

  • Unused preloads waste bandwidth and log a console warning a few seconds after load.
  • prev/next are not an SEO signal. Google said in 2019 it no longer uses them for indexing; they remain valid navigation hints.
  • rel="prerender" is obsolete. Chromium offers speculation rules (<script type="speculationrules">) instead.
  • Font preloads without crossorigin are fetched twice. See crossorigin.

Which to choose

  • External link in a new tab — target="_blank" alone is safe; add noreferrer only to hide your URL, or set data-link-privacy="strict" site-wide.
  • Mark a link's meaning — rel (external, help, tag…) and let VB style it, rather than a class.
  • Speed up a critical resource — preload for this page, prefetch for the next, preconnect for an origin.
