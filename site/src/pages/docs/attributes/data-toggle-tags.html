Overview

data-toggle-tags on a <fieldset> draws each <label><input type="checkbox"></label> inside it as a pill chip. The checkboxes stay real: they take focus, toggle with Space, submit with the form and reset with it. The chip look is CSS only, via label:has(:checked).

Add data-max to cap the number of selections. That loads a small script; without it there is no JavaScript at all.

Usage

Topics

Options

AttributeValuesDefaultEffect
data-toggle-tagsboolean, on <fieldset>—Chip styling for the checkbox labels inside. CSS only.
data-maxinteger ≥ 1no limitCaps the number of checked boxes. At the limit the unchecked boxes are blocked and a status message appears. Changing the attribute later takes effect at once.
data-label-limitstring, {max}"Limit reached: {max} selected. Uncheck one to choose another."The limit message (on the fieldset).

How the limit works

  • At the limit, each unchecked box gets aria-disabled="true" and data-max-blocked. It is not natively disabled, so it stays in the tab order and screen readers still list it.
  • Clicking a blocked chip, or pressing Space on it, does nothing except repeat the limit message in the fieldset's role="status" line.
  • Unchecking any box lifts the block and clears the message.
  • Boxes you disabled yourself (disabled or aria-disabled) are never touched.
  • After a form reset the block is recalculated from the restored checked states.

Form behaviour

  • Submission — each checked box submits a name=value pair; new FormData(form).getAll(name) returns them all.
  • Reset — <button type="reset"> restores the original checked states.
  • Validation — required on a checkbox makes that box mandatory. There is no built-in "at least one" or minimum rule for the group; check it in your submit handler.

Events

No custom events. Each checkbox fires native input and change events, which bubble to the fieldset. A blocked click is cancelled, so it fires neither.

const fieldset = document.querySelector('[data-toggle-tags]'); fieldset.addEventListener('change', () => { const picked = [...fieldset.querySelectorAll('input:checked')].map(cb => cb.value); console.log(picked); });

Styling

No custom properties. These are the shipped rules (excerpt):

[data-toggle-tags] label { display: inline-flex; padding: var(--size-2xs) var(--size-s); border: var(--border-width-thin, 1px) solid var(--control-border, var(--color-border)); border-radius: var(--radius-pill, 999px); transition: background-color var(--duration-fast, 150ms) var(--ease-default, ease), border-color var(--duration-fast, 150ms) var(--ease-default, ease), color var(--duration-fast, 150ms) var(--ease-default, ease); } /* Clipped to 1px, not hidden: it keeps focus and form participation */ [data-toggle-tags] input[type="checkbox"] { appearance: none; position: absolute; inline-size: 1px; block-size: 1px; overflow: hidden; clip: rect(0 0 0 0); } [data-toggle-tags] label:has(:checked) { background: var(--color-interactive); color: var(--color-text-on-interactive-auto, var(--color-text-on-primary, white)); border-color: var(--color-interactive); } [data-toggle-tags] label:has(:focus-visible) { outline: var(--focus-ring-width, 2px) solid var(--focus-ring-color, var(--color-interactive)); outline-offset: var(--focus-ring-offset, 2px); } [data-toggle-tags] label:has(:disabled), [data-toggle-tags] label:has([aria-disabled="true"]) { opacity: 0.5; cursor: not-allowed; } @media (forced-colors: active) { [data-toggle-tags] label:has(:checked) { forced-color-adjust: none; background: Highlight; color: HighlightText; border-color: Highlight; } }

The legend floats to inline-start so the chips wrap below it in either writing direction. The limit message is .toggle-tags-status. Transitions switch off under prefers-reduced-motion: reduce.

Accessibility

  • Native checkboxes: Tab moves between chips, Space toggles, and the checked state is announced by the checkbox itself.
  • The <fieldset> and <legend> name the group. Put the limit in the legend too ("Pick up to 3").
  • Chips blocked by data-max stay focusable and are announced as unavailable (aria-disabled); the limit message is read through a polite role="status" line.
  • The focus ring is drawn on the chip with :focus-visible.
  • In forced-colours mode a checked chip uses the system Highlight colours, so checked and unchecked chips stay distinct.
  • Without CSS or JavaScript the group is a plain list of labelled checkboxes.
