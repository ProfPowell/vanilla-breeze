Overview

data-clip masks an image into a shape. Put it on an <img>, or on a <figure> to clip the figure's image while the caption stays rectangular. The shapes use percentage coordinates, so they scale with the image, and clipped images get object-fit: cover so a non-square source fills the shape without distortion.

The shapes are pure CSS (clip-path: shape()) in the utils layer, behind @supports: older browsers show the plain rectangular image.

Usage

On a <figure> the clip applies to a direct <img> child or to the <img> inside a direct <picture> child, so the responsive-images pattern works. Images nested deeper are not clipped.

Options

ValueShapeGood for
hexagonSix-sided polygonAvatars, team photos
archRounded top, flat bottomArchitecture, portraits
swooshFlat top, bottom curving down to the inline-end cornerHero images, banners
leafFour-curve organic leafNature, organic themes
diagonal-frameParallelogram tiltDynamic layouts, sport
tornJagged torn bottom edgeScrapbook, vintage

swoosh, diagonal-frame and torn are asymmetric and mirror in right-to-left text (:dir(rtl)); the other three are symmetric.

Styling

There are no custom properties: size the image with width/height or aspect-ratio and the shape follows. hexagon, arch and leaf look best on square images.

data-morph does not animate a clipped image: both write clip-path, so the static shape wins and the animation is skipped.

Accessibility

  • The image still needs real alt text. The shape is decoration and is not announced.
  • Shapes crop the corners and edges of the picture (up to about a third of the width for hexagon). Do not rely on text or detail near the edges of a clipped image.
  • Clipped images are not focusable, so there is no focus ring to protect. If you wrap one in a link, the link's own focus ring is outside the image and is not clipped.
  • Images are not repainted in forced colours mode and print normally, so the clip stays in both.

Examples
