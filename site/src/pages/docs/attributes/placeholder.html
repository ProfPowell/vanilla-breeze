Overview

placeholder shows text inside a field while it is empty. It suits a short example of the expected format ("jane@example.com"). It is not submitted, it vanishes on the first keystroke, and it is not a replacement for a <label> or for instructions.

Applies to: <textarea> and <input> of type text, search, url, tel, email, password and number.

Values

ValueMeaning
TextShown while the field is empty. On <input>, carriage returns and line feeds are stripped. On <textarea>, line feeds render as line breaks.
Absent or emptyNothing is shown (the default).

Good placeholders are examples of a format, not instructions: jane@example.com, 123 456, https://. Anything the user must remember while typing belongs in a hint.

In Vanilla Breeze

  • Colour. ::placeholder on text fields and textareas uses --input-placeholder (src/native-elements/input/styles.css), which defaults to var(--color-text-muted) (src/tokens/forms.css). Themes override the token. In forced colours, datalist inputs use GrayText.
  • Floating labels. data-floating-label adds a transparent placeholder=" " when the input has none, so :placeholder-shown can tell an empty field from a filled one. An author placeholder is kept, and the label then stays floated so the two never overlap (src/utils/floating-label-init.js).
  • Hints. <output class="hint" for> is the VB place for instructions. <form-field> wires it to aria-describedby and collapses it once the field is valid.

Accessibility

  • Always give the field a visible <label>. Placeholder text disappears on input, is often low contrast, and screen readers don't announce it consistently.
  • Placeholder text that looks like a value can make users skip the field, believing it is already filled. Keep it clearly an example.
  • If you show placeholder text, it should still be readable: WCAG 1.4.3 asks for 4.5:1 for text. Check --input-placeholder against --input-bg when you change themes.
  • Instructions and validation rules go in an output.hint, not the placeholder.

Gotchas

  • placeholder is never submitted. An empty field with a placeholder sends an empty value.
  • <select> has no placeholder. Use a first option with value="" ("Choose a country"); with required, that option counts as no selection.
  • ::placeholder accepts only the properties allowed on ::first-line (font, colour, background, text decoration and similar), not layout properties such as margin or border.
  • Browsers may draw placeholders with their own opacity. If you set your own placeholder colour, also set opacity: 1 so the colour you chose is the colour shown.

Which to choose

  • <label> — always: the field's name.
  • output.hint — instructions and rules the user needs while typing.
  • placeholder — a short example of the format, optional.
  • data-floating-label — compact layouts that would otherwise use a placeholder as the label.
