Overview

The data-effect="animate-image" effect adds a pause/play button to an animated image (GIF, animated WebP or APNG). Pausing shows a still image, so readers can stop distracting motion (WCAG 2.2.2 Pause, Stop, Hide). The image starts paused when the reader prefers reduced motion.

It is part of the unified effects system and ships in the effects pack. There is no bare data-animate-image attribute: always write data-effect="animate-image".

Usage

The effect wraps the image — or its whole <picture>, so the <source> elements keep applying — in a <span class="animate-image-wrapper"> and adds a <button class="animate-image-toggle"> in its corner.

What "paused" shows, in order:

  1. data-poster, when you give one: a still image URL.
  2. Otherwise the first frame, captured to a canvas once the image loads. While paused, srcset / sizes on the image and its <source>s are set aside and restored on play.
  3. If no frame can be captured — a cross-origin image served without CORS headers taints the canvas — pausing hides the animation and shows its alt text in its place. The button never claims "paused" while the image keeps moving. Give cross-origin images a data-poster (or crossorigin plus CORS headers) to get a still instead.

Do not put the image inside a link: the button would be nested inside the link, which is invalid and confusing for keyboard users.

Options

Attribute Values Description
data-effect="animate-image" — On an <img> (optionally inside <picture>). Adds the control.
data-poster URL Still image shown while paused. Recommended for cross-origin images.
data-animate-image-paused boolean Start paused. Also reflected by the effect while the image is paused.
data-label-animation-pause string Button name (default "Pause animation"). The alt text is appended ("Pause animation: A robot arm…"), or placed where you write {alt}. Read from the image or any ancestor, so one attribute on <html> localises every image.

Styling

  • .animate-image-wrapper — the inline-block positioning box. [data-animate-image-hidden] is set on it while a paused image is hidden.
  • .animate-image-toggle — the round button; [aria-pressed="true"] shows the play triangle. Forced-colors mode uses system button colours.
  • .animate-image-placeholder — the alt-text box shown when the animation is hidden.
  • img[data-animate-image-paused] — the image while paused.

Reduced motion

The image starts paused when either is true, and both are watched while the page is open:

  • prefers-reduced-motion: reduce — the operating-system setting;
  • <html data-motion-reduced> — set by <settings-panel> and <theme-picker> when the reader turns motion effects off.

Turning reduced motion on pauses every playing image; turning it off resumes the ones it paused (not the ones the reader paused). The reader can always press play.

Accessibility

  • The button keeps one name and reports its state with aria-pressed ("Pause animation: <alt>", pressed = paused), so several animated images on a page are distinguishable.
  • Alt text: describe what the animation shows (“A robot arm picks up a block and sets it down again”), not the format (“GIF”) or a placeholder (“Demo”). An image without alt logs a console warning.
  • Pausing really stops the motion: a still, or the animation hidden behind its alt text (WCAG 2.2.2).
  • The button is a native <button>: focusable, activated with Enter or Space, with a visible focus ring.
  • Without JavaScript the image displays normally.

Dynamic elements

Images added later are enhanced by the effects runtime; a clone of an enhanced image (even a paused one) gets its own working control.

const img = document.createElement('img'); img.src = 'animation.gif'; img.alt = 'A paper plane loops across the page'; img.dataset.effect = 'animate-image'; document.querySelector('main').append(img);
