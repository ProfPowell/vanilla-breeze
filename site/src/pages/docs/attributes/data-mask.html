Overview

data-mask formats a text input while the user types: it keeps only the characters the pattern allows, inserts the separators, and keeps the caret where the user is working. Use it when a value has exactly one shape. When any order of allowed characters is fine, use data-accept instead.

Usage

Masks apply to type="text", tel and search inputs (and inputs with no type). Other types, such as email and number, are left alone. Without JavaScript the input accepts free text.

Options

AttributeValuesDefaultEffect
data-mask phone, credit-card, date, ssn, zip, custom — The preset, or custom with data-pattern. An unknown value does nothing until it is corrected; the input is then picked up.
data-pattern pattern string — Required for custom. Tokens: # digit, A letter, * letter or digit. Every other character is a literal that is inserted for the user.
data-mask-message string "Enter the complete value, like placeholder." Validation message while the value is started but not complete.
data-raw-value string — Set by the script: the characters the user typed, without separators (5551234567). For scripts only; it is not submitted.
inputmode, maxlength native set if absent inputmode="numeric" for digit-only patterns; maxlength = pattern length. Values you author are kept.
data-mask-init boolean — Set by the script once a valid mask is wired. Turns on tabular numerals.

Presets

The presets are US formats. For other countries, write a custom pattern or use data-accept.

ValuePatternExample
phone(###) ###-####(555) 123-4567 — US national number
credit-card#### #### #### ####1234 5678 9012 3456 — 16 digits (not 15-digit Amex)
date##/##/####01/15/2026 — US month/day/year order; digits are not checked as a real date
ssn###-##-####123-45-6789
zip#####90210 — five-digit ZIP

Letters keep the case the user typed; the mask does not change case. Add text-transform: uppercase in CSS if you want them to look upper-case (the submitted value is unchanged).

Events

No custom events. The input fires its native input and change events with the formatted value; read data-raw-value in the handler when you need the bare characters.

const phone = document.getElementById('phone'); phone.addEventListener('input', () => { console.log(phone.value); // (555) 123-4567 (submitted) console.log(phone.dataset.rawValue); // 5551234567 (scripts only) });

The form submits the formatted value. If your server needs the bare value, strip the separators there, or copy data-raw-value into a hidden input on submit.

Validation

A value the user has started but not finished (for example (555) 12) is invalid: the mask calls setCustomValidity(), so the form will not submit and <form-field> shows its error. An empty value is valid unless the input is required. The mask clears only its own message, so other validators on the same input keep working. It checks the shape only; it does not check that a date is real or a card number passes its checksum.

Styling

No public hooks. A wired mask input gets font-variant-numeric: tabular-nums so digits line up while the value grows. Otherwise it is styled as any text input.

Accessibility

  • Give the expected shape in visible text (the label or a hint), not only in placeholder, which disappears once the user types.
  • Digit-only masks set inputmode="numeric", so phones show a number keypad.
  • Typing in the middle keeps the caret after the typed character. Backspace or Delete next to a separator removes the neighbouring character instead of stalling on the separator.
  • An incomplete value is reported as invalid with a readable message (override it with data-mask-message).
  • IME composition is left alone until it ends, so multi-key input methods are not interrupted.
  • form.reset() restores the authored value, formatted, and refreshes data-raw-value.

data-mask or data-accept

  • data-mask — exactly one valid shape, with separators inserted: a US phone number, a product key.
  • data-accept — only the characters are restricted, and the user types any separators: international phone numbers, postcodes of varying shape.
