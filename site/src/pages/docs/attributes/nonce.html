Overview

The nonce attribute marks an element as trusted by the page's Content Security Policy (CSP). The server generates a fresh random value for each response, puts it in the policy (script-src 'nonce-R4nd0m') and on every script it means to run. An attacker who injects markup cannot guess the value, so injected scripts are blocked.

Nonces work for external scripts as well as inline ones. The recommended "strict CSP" puts a nonce on every <script> and adds 'strict-dynamic', instead of listing allowed hosts.

Applies to: <script> (inline and src), <style> and <link rel="stylesheet"> (via style-src), and <link rel="preload"> / modulepreload. It is a global attribute, but only these elements use it.

The demo page sets a policy in a <meta> tag. The script with the nonce runs, the one without is blocked (see the console), and VB's own module, which also carries the nonce, loads normally. The demo uses a fixed nonce because it is a static file; that is exactly what you must not do in production.

Values

ValueMeaning
A random tokenAt least 128 bits from a cryptographically secure generator, base64-encoded. New for every response.
Absent or emptyThe element has no nonce and is allowed only by some other source in the policy (a hash, a host, 'self').

In the policy the value is written 'nonce-VALUE', in single quotes.

Examples

A strict CSP

This is the policy recommended by web.dev's strict CSP guide. Modern browsers use only the nonce and 'strict-dynamic'; 'unsafe-inline' and https: are fallbacks that those browsers ignore once a nonce or 'strict-dynamic' is present.

Content-Security-Policy: script-src 'nonce-R4nd0mBase64Value' 'strict-dynamic' https: 'unsafe-inline'; object-src 'none'; base-uri 'none';

Generating the nonce per response

import crypto from 'node:crypto'; app.use((req, res, next) => { // 16 random bytes = 128 bits, new for every response const nonce = crypto.randomBytes(16).toString('base64'); res.locals.nonce = nonce; res.setHeader( 'Content-Security-Policy', `script-src 'nonce-${nonce}' 'strict-dynamic'; object-src 'none'; base-uri 'none'` ); next(); }); // In the template:
