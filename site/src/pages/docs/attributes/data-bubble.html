Overview

data-bubble styles a paragraph as a chat bubble. Each value sets a background, an alignment and a tail drawn with CSS shape(). It is CSS-only, and it is meant for static or server-rendered conversations: transcripts, documentation and marketing pages.

For a live chat, use the components instead. <chat-window> renders <chat-message> and <chat-bubble> elements, which have their own rounded styling and do not use data-bubble.

Usage

Put bubbles in a flex column. Each variant sets its own align-self, so incoming messages sit at the start and outgoing ones at the end. Name the sender in every message: a visible name, or visually hidden text as below. Side and colour alone do not tell a screen reader user who is speaking.

Today, 2:34 PM

Alice: Have you seen this?

You: Yes! Looks great.

Alice is typing

.conversation { display: flex; flex-direction: column; gap: var(--size-s); }

The attribute name is shared with the range slider's value bubble (<input type="range" data-range data-bubble>). Chat styling skips <input>, so the two never collide.

outgoingBottom end corner--color-primary, with --color-text-on-primary-auto textEnd

errorAccent border on the start edge, no shape12% --color-error tintStart
systemPill, no shape--color-surface-sunkenCentre

The tails need CSS shape(). Without it, bubbles are rounded rectangles with the same colours and alignment. "Start" and "end" follow the writing direction, and in right-to-left text the tails mirror with the alignment.

The typing bubble animates its empty <span> children as dots. Spans with text, such as the visually hidden label, are left alone.

Styling

Custom propertyDefaultEffect
--bubble-bgSet by the variantBubble fill. It accepts gradients. Shaped variants paint it inside the tail shape.

The shape is painted on a ::before layer behind the text, and the bubble itself is not clipped. To recolour a variant, set --bubble-bg rather than background: a plain background would paint a rectangle behind the tail. For a shadow that follows the tail, use filter: drop-shadow(). The kawaii and cyber themes do both. Text colour is ordinary color. If you change --bubble-bg on outgoing, check the text contrast.

Accessibility

  • Name the sender in every message. Side, colour and tail are visual only.
  • Mark the conversation as a log. role="log" on the container lets screen readers announce new messages that you append.
  • Announce typing. Put role="status" on the typing bubble, with visually hidden text such as "Alice is typing". The dots are decorative and say nothing on their own.
  • Errors need words. The error tint and border are decoration, so the text must say what failed. Use role="alert" when the error appears in response to an action.
  • Reduced motion. The typing dots stop animating under prefers-reduced-motion: reduce.
  • Forced colours and print. Every bubble gets a real border, with a thick edge on the side the tail was on, so incoming and outgoing messages stay distinguishable.
  • Focus rings survive. Nothing is clipped, so links inside a bubble keep their full focus outline.
