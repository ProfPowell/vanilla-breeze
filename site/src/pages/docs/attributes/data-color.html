Overview

data-color on an <input type="color"> shows the chosen colour as a round swatch next to its hex code, in a frame that matches other fields. The native input is still the control. It lies, transparent, over the display, so a click opens the browser's own colour picker, and focus, the keyboard, the label and form submission all stay with the input.

Usage

The script wraps the input in a .color-wrapper and adds the display after it:

#6366f1

Without JavaScript the browser's own colour input is shown.

Options

AttributeValuesDefaultEffect
data-color boolean — Adds the swatch and hex display. Applies only to input[type="color"], and not inside <color-picker>, which draws its own trigger.
value native, #rrggbb #000000 The colour shown and submitted. The display updates on input, on change and after the form is reset.
disabled native — The whole display is dimmed and the input cannot be opened.
data-color-init boolean — Set by the script. Informational; no styles depend on it.

One name, two meanings. On <layout-badge> and on buttons, data-color is a colour variant (primary, success…). That is a different attribute. This enhancement only reacts on input[type="color"].

Events

No custom events. Listen on the input: input fires while the user picks, change when the picker closes with a new colour.

const brand = document.getElementById('brand'); brand.addEventListener('change', () => { document.documentElement.style.setProperty('--brand', brand.value); });

Setting value from a script fires nothing; dispatch input or change afterwards so the swatch follows.

Styling

There are no public custom properties. The generated classes are the hooks:

  • .color-wrapper — the inline-flex frame that the input covers.
  • .color-display — the bordered box. Its border turns --color-interactive on hover, and gains a halo while the input has keyboard focus (an outline in forced-colours mode).
  • .color-swatch — the 1.5rem circle; its colour comes from the private --color-swatch-value the script sets.
  • .color-hex — the hex code in the monospace font, upper-cased by CSS.
.color-display .color-swatch { inline-size: 2rem; block-size: 2rem; }

Accessibility

  • There is one control and one tab stop: the native input, named by its <label>. Screen readers announce it as a colour input with its value.
  • The swatch and hex text are aria-hidden; they repeat the input's value for sighted users.
  • Keyboard focus shows a --color-interactive border and halo on the display.
  • In forced-colours mode the swatch keeps the real colour (forced-color-adjust: none) with a CanvasText ring, and focus is a Highlight outline.
  • The native picker dialog is the browser's; its accessibility depends on the browser and platform.
