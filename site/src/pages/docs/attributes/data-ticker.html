Removed — use data-effect="ticker"

The data-ticker attribute no longer exists. Count-up numbers are the ticker effect of the unified effects system, documented on the data-effect page.

Migration

Effect options are custom properties, set in your stylesheet like any other style:

50,000 .hero-stat { --vb-ticker-duration: 2s; /* capped at 5s */ --vb-ticker-start: 500; --vb-ticker-decimals: 2; }
