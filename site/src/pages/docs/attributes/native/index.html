Native Attributes

The standard HTML attributes every browser understands, documented with what the specification says, how Vanilla Breeze styles or reads them, and the mistakes to avoid. ${attributeIndex.nativePageCount} pages in ${attributeIndex.nativeGroupCount} groups.

Vanilla Breeze documents native attributes alongside its own data-* attributes because the platform comes first. Many problems usually solved with JavaScript are already solved by an attribute: autocomplete for one-tap form filling, loading for lazy images, popover and commandfor for menus and dialogs without script. When VB adds something on top (a style hook, a data-* companion, a component that sets the attribute for you), the page says exactly what and where.

Every page follows the same template:

  • Overview: what the attribute does, the elements it applies to, and a live demo where a page can show the effect (crossorigin and ping need a second origin or a server, so they explain why instead).
  • Values: each value, what it means, and the default (including what an empty or invalid value does).
  • Examples: live demos with the code that produces them.
  • In Vanilla Breeze: the CSS hooks, tokens, data-* attributes and components that style, read or set the attribute, with source file references.
  • Accessibility, and Security where the attribute affects it.
  • Browser support, as a dated note, on pages where support is not universal.
  • Gotchas and Related, with a short "which to choose" list of native siblings, data-* companions and components.
