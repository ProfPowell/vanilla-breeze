Overview

data-effect is the single entry point for every visual effect in Vanilla Breeze. Name one or more effects, separated by spaces; pick when they run with data-trigger; tune them with classes and --vb-* custom properties.

Most effects are pure CSS. Text effects (reveal, blur-reveal, typewriter, scramble, flipboard, ticker) and a few widgets need the effects runtime. Which bundle carries each effect is listed in the catalogue, generated from the source.

Scroll-trigger gallery: every entrance effect fired by data-trigger="scroll" is in the scroll-effect gallery. For effects that follow scroll position continuously, see data-trigger="view-progress".

Multiple effects and animation slots

Every animated effect publishes into one of four animation slots. One composer rule on [data-effect] reads all four into a single animation list, so effects in different slots run together:

SlotEffectsLifecycle
entrancefade-in, slide-up, slide-in, pop, shadowOnce, on activation; holds the end state.
attentionshake (once), pulse, bounce, blink (stops after about 5s)Draws the eye.
decorationneon, outline.glow, text-3d.animate, rainbow, gradient-text.animate, shimmer, glow, floatContinuous. Static paint (glow, stroke, colour) stays if the slot is taken.
exitfade-out, collapse, slide-outOnce, on activation; holds the end state.

    Two effects in the same slot share one animation. fade-in + slide-up and shimmer + gradient-text ship merged keyframes; for other same-slot pairs the later rule wins. Effects that only paint (hard-shadow, text-3d without .animate, outline without .glow, stamp) never collide.

    Try it: the Effects Lab composes effects across slots and shows the resulting HTML and animation value.

    Slots that fight over one property

    Slots guarantee that both effects run, not that they look good together. When two slots animate the same property, the later slot (entrance → attention → decoration → exit) wins each frame.

    ConflictEffectsWhat you see
    Opacity flicker hides decorationblink + neon, blink + shimmerThe decoration shows only in blink’s “on” half.
    Exit erases decorationfade-out, collapse, slide-out + any decorationThe decoration fades away with the element.
    Attention transform wins during entrancepop + bounce, slide-up + shakeThe entrance scale or offset is replaced by the attention motion; the entrance fade still runs.
    Decoration transform wins after entrancepop + float, slide-up + floatThe float takes over once the entrance ends.
    Background-clip collidesshimmer + marqueeOnly shimmer + gradient-text has a merged rule.

    Pick one effect per perceptual axis, chain effects with VB.onPhaseEnd(), or write your own composite selector.

    EventFired onDetail
    vb:phase-changeThe element, when it is activated or deactivated{ active: true | false }

    JS API

    MethodUse
    VB.activate(el)Set data-effect-active and run the JS half of the effects. Programmatic trigger.
    VB.deactivate(el)Remove data-effect-active; slot animations un-publish.
    VB.onPhaseEnd(el, phase, fn)Run fn when a keyframe of phase ends. Returns an unsubscribe function.
    VB.registerKeyframe(name, phase)Classify your own keyframe so vb:effect-phase-end reports it.
    const el = document.querySelector('#hero-title'); VB.onPhaseEnd(el, 'entrance', () => { el.dataset.effect += ' shimmer'; });

    Adding, removing or changing data-effect later re-applies the effects. Removing an element runs each JS effect’s cleanup (timers, observers, split text restored), so a re-inserted or cloned element starts fresh.

    Styling

    HookDescription
    --vb-duration, --vb-easing, --vb-delayShared by the slot effects that list them above. data-stagger sets --vb-delay per child.
    .slow, .fast900ms / 150ms for one-shot effects; loops get their own (twice / half the default cycle).
    .bouncyOvershooting spring easing for effects that read --vb-easing.
    [data-paused]On the element or an ancestor: pauses slot loops, glitch layers, marquee children, the typewriter cursor and .loop typing.
    [data-effect-active]Set by the runtime when the trigger fires. Style your own activated state with it.
    [data-effect-armed]Set by the runtime when a registered trigger is wired. Entrance effects hide only under [data-effect-armed]:not([data-effect-active]), so content shows without JS or with an unknown trigger.

    Effects live in @layer web-components. Infinite decorations animate paint properties (text-shadow for neon and outline.glow, filter for rainbow and glow, background-position for shimmer and gradient-text.animate); use them sparingly on large areas.

    Accessibility

    • Reduced motion. Under prefers-reduced-motion: reduce or :root[data-motion-reduced] every effect lands on its final state at once: entrances visible, exits gone, loops stopped at rest. Text effects do not split or animate, marquee becomes a scroller, animate-image starts paused.
    • Nothing hidden for good. Entrance effects start hidden only when a registered trigger is wired. Without JS, with a misspelled trigger or on an unprocessed clone the content is visible.
    • Pause, stop, hide (WCAG 2.2.2). Content that moves, blinks or scrolls for more than five seconds alongside other content needs a way to pause it. blink stops by itself after about five seconds; marquee pauses while keyboard focus is inside it; everything else that loops (pulse, bounce, float, glow, neon, rainbow, shimmer, gradient-text.animate, text-3d.animate, outline.glow, glitch, marquee, typewriter.loop) holds while data-paused is set on it or an ancestor. Wire that to a button (example), or keep loops to purely decorative spots.
    • Flashing (WCAG 2.3.1). No effect flashes more than three times a second (blink.fast is 2.5).
    • Vestibular safety. Large or continuous motion (long slide distances, marquee, scroll-linked effects) can trigger nausea. Keep distances small and honour the reduced-motion setting; never rely on motion to convey meaning.
    • Screen readers. Text effects split only text nodes: links and other inline elements keep working, the text is read once from a visually hidden copy, and the animated pieces are hidden from assistive technology. flipboard cells and glitch copies are hidden the same way.
    • Hover is not enough. data-trigger="hover" also fires on keyboard focus, but do not hide information behind hover.
    • International text. typewriter, scramble and flipboard work on grapheme clusters (Intl.Segmenter): emoji, combining marks and surrogate pairs are never split. Directional effects (slide-in, slide-out, marquee) mirror in RTL.
