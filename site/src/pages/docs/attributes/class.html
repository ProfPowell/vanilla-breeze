Overview

The class attribute is a space-separated list of names that CSS and scripts can select on. In Vanilla Breeze a class picks a named variant of one element: <button class="secondary">, <nav class="pills">, <header class="site">. VB does not ship appearance utilities such as .text-center or .mt-4.

Every variant is scoped to its element. .pills does something on <nav> and <menu> and nothing elsewhere; .compact means one thing on <header> and another on <article>.

Applies to: every element (it is a global attribute).

Classes or data attributes?

VB splits the work (see Principles: data attributes for configuration):

  • Class — a named variant that is either on or off: button.secondary, nav.tabs, footer.columns.
  • data-* attribute — configuration with a value, or state: data-layout="stack", data-density="compact", data-sticky, data-state.
  • ARIA or native attribute — state the browser or assistive technology must also know about: aria-current, aria-pressed, disabled, open. VB styles these directly. See ARIA states VB styles.

If you are looking for a class and cannot find it, look for a data-* attribute. These are attributes, not classes:

You wantWrite
A sticky header or footer<header data-sticky>, <footer data-sticky> (data-sticky)
Striped, bordered or compact tables<table data-striped data-bordered data-density="compact"> (table variants)
Pagination styles<nav class="pagination" data-variant="compact">
Horizontal description lists<dl data-variant="horizontal">
List markers<ul data-marker="arrow">
Layout (stack, cluster, grid, sidebar…)data-layout on any element

Release notes

Faster builds.

New themes.

In Vanilla Breeze

  • Element-scoped selectors. Variants are written as element.class (or nested &.class inside the element's rule) in src/native-elements/<element>/styles.css. A class on the wrong element does nothing.
  • Themes can restyle variants. Most variants set custom properties (for example --_active-bg on nav.pills) that themes override.
  • Build-system classes. nav a.active is styled like aria-current="page" for site generators that can only add a class. Prefer aria-current: it is also announced.
  • Your own classes are fine. VB does not reserve class names, so project classes sit alongside VB's.

Accessibility

  • A class is invisible to assistive technology. Never use a class alone to carry state ("current", "selected", "disabled"). Use the native or ARIA attribute, which VB styles anyway.
  • .visually-hidden is for text, not controls. A focusable element hidden this way vanishes when a keyboard user reaches it.

Gotchas

  • Same word, different element. .compact on <header> reduces header padding; on <article> it makes a compact list row (flex, small padding, a bottom border). There is no global .compact.
  • .lead is p.lead. It has no effect on other elements.
  • There is no .sticky and no table.compact. Use data-sticky and data-density="compact".

Which to choose

  • Class — a named look for one element: button.secondary.
  • data-* — a value or a state: data-density="compact", data-sticky.
  • Native or ARIA attribute — state that users of assistive technology must hear: aria-current, disabled.
