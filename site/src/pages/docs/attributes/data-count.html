Overview

The data-count attribute adds a live counter below a textarea that updates as the user types. It supports both character counting (with maxlength) and word counting (with data-maxwords), with automatic color shifts at warning and error thresholds.

How It Works

Add data-count to any <textarea>. The init script:

  1. Creates an <output> element with class="textarea-counter" and an id, and adds it to the textarea's aria-describedby
  2. Keeps the visible counter quiet (aria-live="off") and announces the count through a visually hidden live region only near or over the limit, once typing pauses
  3. Places the counter after the textarea (inside <form-field> if present, otherwise directly after)
  4. Listens for input events to update the count in real time, and recounts after the owning form is reset
  5. Calculates thresholds: warning at ≥80% of limit, error at ≥100%
  6. Sets counter.dataset.state to "", "warning", or "error" for CSS styling
  7. Sets data-count-init to prevent double-binding

Attributes

Attribute Values Description
data-count "", "words" Enables the counter. Empty string (default) counts characters. "words" counts words.
maxlength number Standard HTML attribute. Used as the character limit and enforced by the browser. The counter displays "42 of 200 characters".
data-maxwords number Word limit for word-count mode. The counter displays "12 of 50 words". Advisory only: typing is not stopped and the field does not become invalid.
data-label-characters, data-label-words string Text for counters without a limit, with {count} replaced (default {count} characters / {count} words). Add a plural category suffix for languages that need it, e.g. data-label-characters-one="{count} Zeichen"; the category comes from Intl.PluralRules for the nearest lang.
data-label-limit string Text for counters with a limit, with {count} and {max} replaced (default {count} of {max} characters / {count} of {max} words). Plural suffixes work as above (data-label-limit-one, …); the category is chosen from {max}.
data-count-init boolean Set automatically to prevent double-binding. Do not set manually.

Character Count

The default mode counts characters. Pair with maxlength to show "42 of 200 characters" and enforce the limit.

Word Count

Set data-count="words" for word counting. Use data-maxwords to set a word limit. Words are split on whitespace, so languages written without spaces (Chinese, Japanese, Thai) count each unbroken run as one word; use character mode for them. The word limit is advisory: it changes the counter colour but does not block typing or submission, so validate it on the server.

Count Without Limit

Omit maxlength or data-maxwords to show a running count without enforcing a limit. No threshold states are applied.

Display Format

The counter text adapts based on the configuration:

Configuration Display Example
Characters with maxlength {count} of {max} characters 42 of 200 characters
Characters without limit count character(s) 42 characters
Words with data-maxwords {count} of {max} words 12 of 50 words
Words without limit count word(s) 12 words

Numbers are formatted with Intl.NumberFormat for the nearest [lang]. Override any of the texts with the data-label-* templates above.

Threshold States

When a limit is set, the counter shifts color at configurable thresholds via data-state:

  • Normal (data-state="") — below 80% of the limit, uses muted text color
  • Warning (data-state="warning") — at or above 80% of the limit, shifts to warning color
  • Error (data-state="error") — at or above 100% of the limit, shifts to danger color with bold weight

Without a limit, no threshold states are applied and the counter stays in its default style.

Combined with data-grow

Use data-count alongside data-grow for a textarea that expands as the user types while showing the count.

Programmatic Access

The counter element is a standard DOM node. Query it to read the current state programmatically.

Setting textarea.value from script fires no event, so the counter does not see it. Dispatch an input event afterwards; it also re-measures data-grow. Form resets are handled automatically.

textarea.value = savedDraft; textarea.dispatchEvent(new Event('input', { bubbles: true })); const textarea = document.querySelector('[data-count]'); textarea.addEventListener('input', () => { const counter = textarea.parentElement.querySelector('.textarea-counter'); console.log('Count state:', counter.dataset.state); console.log('Counter text:', counter.textContent); });

Styling

The counter is an <output> element styled via the .textarea-counter class. Threshold states are driven by data-state attribute selectors.

/* Counter element */ .textarea-counter { font-size: var(--font-size-s); color: var(--color-text-muted); text-align: end; margin-block-start: var(--size-2xs); font-variant-numeric: tabular-nums; } /* Warning state (>=80% of limit) */ .textarea-counter[data-state="warning"] { color: var(--color-warning-text); } /* Error state (>=100% of limit) */ .textarea-counter[data-state="error"] { color: var(--color-error-text); font-weight: 600; }

The states use the --color-warning-text and --color-error-text tokens, which are tuned for at least 4.5:1 contrast in light and dark mode (the raw --color-warning is too light for small text on white). The error state is also bold, so it does not rely on colour alone. Themes adjust the tokens rather than this rule.

Dynamic Elements

Textareas added to the DOM after page load are automatically enhanced via a MutationObserver. No manual initialization is needed.

// Dynamically added textareas are auto-enhanced via MutationObserver const textarea = document.createElement('textarea'); textarea.maxLength = 140; textarea.dataset.count = ''; textarea.rows = 3; document.querySelector('form-field').appendChild(textarea); // counter element is created automatically — no manual init needed

Accessibility

  • The visible counter is linked with aria-describedby and set to aria-live="off", so it is read with the field but not on every keystroke
  • Near or over the limit, a visually hidden aria-live="polite", aria-atomic="true" region announces the count once typing pauses
  • The text says what is counted ("170 of 200 characters"), rather than a bare "170 / 200" that is read as "170 slash 200"
  • The counter is placed after the textarea in DOM order, matching visual reading order
  • Without JavaScript, the textarea works normally with no counter (progressive enhancement)
