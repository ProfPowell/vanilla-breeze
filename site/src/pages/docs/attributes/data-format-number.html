Overview

The data-format-number attribute enhances native <data> elements by replacing their text content with a locale-aware formatted number. The value attribute carries the raw number, while the displayed text is formatted for the user's locale.

1,234,567

How It Works

  1. Reads the value attribute from the <data> element and parses it as a number. A missing, empty or non-numeric value leaves the text as written.
  2. Formats the number using Intl.NumberFormat with the specified style
  3. Replaces the text content with the formatted string (no title is added: the visible text is the value)
  4. Formats again whenever value, data-format-number, data-currency, data-fraction-digits, data-locale or a lang attribute changes

The locale is resolved in this order: data-locale on the element, the nearest ancestor with a lang attribute, <html lang>, then the browser language.

Attributes

Attribute Type Description
data-format-number string Format style: "" (decimal), "currency", "percent", "compact".
value string The raw numeric value. Standard HTML value attribute on <data>.
data-currency string ISO 4217 currency code (e.g., "USD", "EUR") for the "currency" style. Default "USD". An unknown code leaves the text as written.
data-fraction-digits number Optional fixed number of decimal places, 0–20. Default: Intl's default for the style — up to 3 decimals for decimal, whole numbers for percent, the currency's minor units for currency, two significant digits for small compact values (46K, 1.5M).
data-locale string Optional locale override (e.g., "de-DE"). Defaults to the nearest [lang], then <html lang>, then the browser locale.
data-format-number-init boolean State hook, set once the element is enhanced. Read it for styling or tests; do not set it. Enhancement is tracked internally, so a cloned element is still formatted when it is inserted.

Format Styles

All four styles side by side:

Decimal (default)

Standard number formatting with locale-aware grouping separators:

1,234,567

Currency

Formats with currency symbol and locale-appropriate placement, using data-currency (default USD). Currency values keep the currency's minor units, so write the fallback text the same way:

$48,200.00 €48,200.00 £48,200.00

Want whole amounts? Add data-fraction-digits="0": <data value="48200" data-format-number="currency" data-fraction-digits="0">$48,200</data>.

Percent

Multiplies by 100 and adds the percent sign. Pass the decimal value (e.g., 0.85 for 85%). Percentages round to whole numbers unless you set data-fraction-digits:

85% 2.4%

Compact

Abbreviated notation for large numbers (e.g., 1.5M, 46K). Add data-fraction-digits="1" to keep a decimal (45.6K):

1.5M 46K 45.6K

Locale Override

Use data-locale to force a specific locale for formatting:

1.234.567,89 1,234,567.89

Common Use Cases

Revenue Table

Format currency values in a data table. The font-variant-numeric: tabular-nums CSS ensures columns align:

ProductRevenue
Widget A $142,500.00
Widget B $89,300.00

Dynamic Elements

Elements added to the DOM after page load are automatically enhanced via a MutationObserver. No manual initialization is needed. Changing value (or any formatting attribute) re-formats the element, and a cloned element is formatted like a new one.

// Dynamically added elements are auto-enhanced via MutationObserver const el = document.createElement('data'); el.value = '0.995'; el.dataset.formatNumber = 'percent'; el.dataset.fractionDigits = '1'; el.textContent = '99.5%'; document.body.appendChild(el); // el is enhanced automatically — no manual init needed // Changing the value re-formats it el.value = '0.42'; // → "42.0%"

Progressive Enhancement

The <data> element's original text serves as a fallback when JavaScript is unavailable. Write a reasonable pre-formatted value as the text content:

1,234,567

Accessibility

  • The semantic <data> element with value attribute provides machine-readable data
  • Falls back to the original text content when JavaScript is unavailable
  • No wrapper element — the <data> is the enhanced element, keeping the accessibility tree clean
  • Re-formatting is silent. If a changing number must be announced, put it in your own live region (or a <output>).

Not Supported

Only the options above are exposed. For Intl options such as signDisplay, currencyDisplay, compactDisplay: "long" or unit formatting, format in your own script with Intl.NumberFormat and leave data-format-number off. For file sizes use data-format-bytes.
