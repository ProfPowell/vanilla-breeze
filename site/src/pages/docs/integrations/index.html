Static site generators

Vanilla Breeze is plain HTML, CSS and web components, so it works with any tool that outputs HTML. Two starter kits give you ready-made templates, and Cook is the generator this site is built with.

Astro

Eight components and four layouts, with TypeScript props.

Eleventy (11ty)

Three Nunjucks layouts and seven includes.

Cook

A static site generator built on web platform features. It builds this documentation site. Published on npm as cook-ssg.

What the starter kits contain

Both kits live in the repository under demos/integrations/. They are not in the npm package. Copy the folder for your generator into your project and adapt it. The Astro and Eleventy pages give the setup steps.

Content management

Any system that emits HTML can serve Vanilla Breeze pages. There are no adapters for specific systems yet.

Vanilla Press

An HTML-first publishing front end built on Vanilla Breeze.

Built on Vanilla Breeze

Two packages hold elements that were moved out of the core library. They read Vanilla Breeze tokens and use some of its elements, so load Vanilla Breeze on the page with them.

vb-design-system

Nineteen elements for documenting a design system: type, spacing, token and motion specimens, color palettes, a font pairer, and the theme catalog and import tools.

vb-project-planning

Twenty elements for planning work: personas, user stories, journeys, empathy maps, kanban, roadmap, Gantt and burndown charts, risk registers and decision records.

Standalone web components

Sixteen components are published separately on npm under @profpowell. None of them needs Vanilla Breeze. Most read the same --color-*, --size-* and --font-* tokens, with fallbacks of their own, so on a Vanilla Breeze page they follow the active theme. The web components overview covers how to load them.

These eleven have an integration guide on this site, with a demo and a quick reference.

bg-wc

Animated WebGL and Canvas2D backgrounds behind any content. Also usable through data-background attributes.

browser-console

An in-page console that captures console.* calls, with tables, timers and groups.

browser-window

Browser window chrome for demos and tutorials, with source view, full screen and CodePen export. Used throughout these docs.

code-block

Syntax-highlighted code with copy, line numbers, focus mode, diffs and multi-file tabs. Used throughout these docs.

code-playground

A live HTML, CSS and JavaScript editor with a sandboxed preview and console output.

epub-reader

A dependency-free EPUB 3 reader with a contents sidebar, toolbar and keyboard navigation.

image-editor

Crop, rotate, filter, resize, convert and export images, with undo and redo.

marquee-wc

The <marquee> tag rebuilt: tickers, credit rolls, dot-matrix boards and per-letter motion.

pdf-viewer

A PDF.js wrapper with navigation, zoom, search, thumbnails and dark mode.

screen-saver

Seventeen idle-overlay effects. Five of them follow the active Vanilla Breeze theme.

terminal-window

A styled terminal with prompts, typing animation and a registry for custom commands.

More standalone components

These five have no guide here yet. Each card goes to the component's own documentation site.

blink-wc

The <blink> tag rebuilt: accessible, CSS-driven blink modes that read Vanilla Breeze color and font tokens.

border-wc

Thirty-four decorative border effects, from neon and aurora to marquee bulbs and washi tape. Pairs with data-border-effect.

http-component

Four elements that show HTTP requests and responses in wire format, with waterfall views, live capture and a request builder.

json-viewer

A collapsible JSON tree with a path and glob API and search. Its colors fall back to Vanilla Breeze tokens.

pattern-grid

A 1 KB element that stamps out a CSS grid of empty cells for you to style. No tokens needed: the look is your CSS.

Other libraries

Nothing in Vanilla Breeze depends on a framework, so it sits beside any library that works with HTML:

  • HTMX for hypermedia-driven pages.
  • Alpine.js for small amounts of reactive behavior.
  • Hotwire and Turbo for HTML sent over the wire.
  • Plain HTML with no framework at all.

See Principles for why the library is built this way, and Quick Start to add it to a page.
