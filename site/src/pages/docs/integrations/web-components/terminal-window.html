terminal-window

A web component that simulates a terminal: readers type commands, and you decide in JavaScript what each command prints. It reads Vanilla Breeze surface, text, border and radius tokens directly, and the VB stylesheet maps the prompt, cursor and status colors as well.

Install

Load the component from a CDN. It is one file with no dependencies and no stylesheet.

Or install it from npm and import it in your own script.

npm install @profpowell/terminal-window import '@profpowell/terminal-window';

Demo

A terminal on a Vanilla Breeze page with two custom commands and the built-in file commands. Click in it and type help, status or ls.

Usage

Add the element and give it a height. It fills the height of its container. The built-in commands are help, clear, echo and history.

terminal-window { block-size: 24rem; }

Register your own commands in JavaScript. A handler receives the words typed after the command name as an array, and the terminal itself. The string it returns is printed. A handler can be async.

await customElements.whenDefined('terminal-window'); const terminal = document.querySelector('terminal-window'); terminal.registerCommand('greet', (args) => `Hello, ${args[0] || 'World'}!`); terminal.registerCommand('deploy', async (args, term) => { await term.print('Uploading files', 'info'); await new Promise((resolve) => setTimeout(resolve, 1000)); await term.print('Deployed', 'success'); }); terminal.registerAlias('hi', 'greet');

For a scripted demonstration, make the terminal read-only and run commands from code. Note that typing-effect must be written with the value true.

With Vanilla Breeze

A token is a CSS custom property that holds one design value, such as --color-surface. Two things connect the component to Vanilla Breeze tokens.

First, the component itself reads these VB tokens as fallbacks.

VB tokenDrives
--color-surfaceTerminal background
--color-surface-raisedHeader and secondary backgrounds
--color-borderBorders
--color-textMain text
--color-text-mutedMuted text
--radius-mOuter corner radius
--radius-sRadius of buttons and menus

Second, the VB stylesheet contains a token bridge: a rule with the selector terminal-window that sets the component's --terminal-window-* properties from VB tokens. It ships in vanilla-breeze.css and vanilla-breeze-core.css, so there is no extra file to load and no attribute to add. Besides the tokens above, the bridge sets these.

VB tokenSet on
--color-successPrompt, success messages and the fullscreen button
--color-errorError messages and the close button
--color-warningThe minimize button
--color-infoInfo messages
--color-interactiveCursor and text selection
--color-text, --color-text-mutedTyped commands, and printed output

For each value the order is: the --terminal-window-* property if it is set, then the VB token where the component reads one, then the built-in color for the current mode. The bridge does not set the ANSI colors, the header button colors or the scrollbar colors, so those keep the component's built-in values.

The font is an exception. The component and the bridge both point --terminal-window-font-family at --font-mono, but in version 2.1.0 the element also applies its font-family attribute, default included, directly to the terminal, and that wins. To use the VB monospace font, set the attribute.

Light or dark is chosen separately. With no mode or theme attribute, the component follows data-mode, data-theme or a dark class on <html> or <body>, then the page's computed color-scheme, then the operating system preference. It updates when these change.

The bridge sits in a cascade layer, so any rule you write outside a layer wins. To change one terminal, set the property on it.

terminal-window#tour { --terminal-window-prompt-color: var(--color-primary); --terminal-window-cursor-color: var(--color-primary); --terminal-window-border-radius: 0; }

Accessibility

  • Keyboard: Enter runs the command, the up and down arrows step through the history, Tab completes a command name, and Ctrl+C cancels the current line or skips a typing effect in progress. Escape leaves fullscreen.
  • The output area has role="log" and is a polite live region, so screen readers announce new lines. Errors and state changes such as "cleared" are announced as well.
  • The header buttons have ARIA labels. The copy menu is a labeled menu that can be used with the arrow keys.
  • When the reader has asked for reduced motion, the typing effect is skipped and the cursor stops blinking. The force-animations attribute overrides this and is meant for testing only.
  • Use setI18n() to translate the labels and announcements.
