Web Component Integrations

Sixteen standalone web components, published independently on npm under ~tpowell2, that drop into a Vanilla Breeze page with zero extra wiring.

Theme-ready, not VB-dependent

None of these components require Vanilla Breeze. Each ships with sensible pixel/color fallbacks so they work fine on any HTML page. But they're built to consume the same design-token namespaces VB uses — --color-*, --size-*, --font-*, --radius-*, --shadow-*, --border-width-* — so when you place them inside a VB-themed page they pick up the active theme automatically.

That means switching between VB theme packs (default, rough, extreme-swiss, extreme-neumorphism, etc.) re-skins their chrome alongside everything else. Per-instance overrides via the component's own --{component-name}-* custom properties always win, so brand customization stays available.

Available components

Eleven have an integration guide on this site, with a demo and a quick reference.

bg-wc

Animated WebGL and Canvas2D backgrounds behind any content. Also usable through data-background attributes.

browser-console

An in-page console that captures console.* calls, with tables, timers and groups.

browser-window

Browser window chrome for demos and tutorials, with source view, full screen and CodePen export. Used throughout these docs.

code-block

Syntax-highlighted code with copy, line numbers, focus mode, diffs and multi-file tabs. Used throughout these docs.

code-playground

A live HTML, CSS and JavaScript editor with a sandboxed preview and console output.

epub-reader

A dependency-free EPUB 3 reader with a contents sidebar, toolbar and keyboard navigation.

image-editor

Crop, rotate, filter, resize, convert and export images, with undo and redo.

marquee-wc

The <marquee> tag rebuilt: tickers, credit rolls, dot-matrix boards and per-letter motion.

pdf-viewer

A PDF.js wrapper with navigation, zoom, search, thumbnails and dark mode.

screen-saver

Seventeen idle-overlay effects. Five of them follow the active Vanilla Breeze theme.

terminal-window

A styled terminal with prompts, typing animation and a registry for custom commands.

Documented on their own sites

Five more have no guide here yet. Each link goes to the component's own documentation.

blink-wc

The <blink> tag rebuilt: accessible, CSS-driven blink modes that read Vanilla Breeze color and font tokens.

border-wc

Thirty-four decorative border effects, from neon and aurora to marquee bulbs and washi tape. Pairs with data-border-effect.

http-component

Four elements that show HTTP requests and responses in wire format, with waterfall views, live capture and a request builder.

json-viewer

A collapsible JSON tree with a path and glob API and search. Its colors fall back to Vanilla Breeze tokens.

pattern-grid

A 1 KB element that stamps out a CSS grid of empty cells for you to style. No tokens needed: the look is your CSS.

Built on Vanilla Breeze

Two further packages need Vanilla Breeze on the page. Their elements were moved out of the core library.

vb-design-system

Nineteen elements for documenting a design system: type, spacing, token and motion specimens, color palettes, a font pairer, and the theme catalog and import tools.

vb-project-planning

Twenty elements for planning work: personas, user stories, journeys, empathy maps, kanban, roadmap, Gantt and burndown charts, risk registers and decision records.

Already in VB by default

Two of these components — browser-window and code-block — are already package-json dependencies of Vanilla Breeze itself, used throughout these docs to render demos. The integration pages document them anyway because they're independently usable outside VB.
