code-block

A web component that shows source code with syntax highlighting, a copy button, optional line numbers and tabs for several files. The Vanilla Breeze stylesheet sets its colors, fonts and corner radius from the active theme, so it needs no extra styling on a VB page.

Install

Load the component from a CDN. The stylesheet is optional: it styles the element before the script has run, so the code does not show as a line of inline text and then jump.

Or install it from npm and import it in your own script.

npm install @profpowell/code-block import '@profpowell/code-block'; import '@profpowell/code-block/code-block.css'; // optional, needs a bundler that handles CSS

Demo

Three blocks on a Vanilla Breeze page: highlighted lines with focus mode, a tabbed group of files, and a diff.

Usage

Put the code between the tags and name the language. The component reads the element's text, so write < and & in the code as &lt; and &amp;.

<code-block language="javascript" show-lines highlight-lines="2-3" focus-mode>function greet(name) {
  const message = `Hello, ${name}!`;
  console.log(message);
  return message;
}</code-block>

To avoid escaping markup by hand, put the code in a <textarea> child. The component takes the code from the textarea and removes it.

<code-block language="html" filename="index.html">
  <textarea><main>
  <h1>Trail report</h1>
</main></textarea>
</code-block>

Wrap several blocks in <code-block-group> to show them as tabs. Each tab is named from the block's filename, then its label, then its language.

<code-block-group show-download>
  <code-block language="html" filename="index.html">...</code-block>
  <code-block language="css" filename="styles.css">...</code-block>
</code-block-group>

Load the code from a file with src. The language and file name are taken from the URL unless you set them.

<code-block src="/examples/greet.js" show-lines></code-block>

With Vanilla Breeze

A token is a CSS custom property that holds one design value, such as --color-surface. Two things connect the component to Vanilla Breeze tokens.

First, the component itself reads five VB tokens as fallbacks, so it picks up a VB theme even without any VB rule aimed at it.

VB tokenDrives
--color-surfaceCode area background
--color-surface-raisedOuter background and header background
--color-textCode text and button text
--color-text-mutedComment color
--color-borderBorders

Second, the VB stylesheet contains a token bridge: a rule with the selector code-block that sets the component's --cb-* properties from VB tokens. It ships in vanilla-breeze.css and vanilla-breeze-core.css, so there is no extra file to load and no attribute to add. The bridge covers more than the five fallbacks.

VB tokenSet on
--color-surface, --color-surface-raisedBackgrounds of the block, header, line numbers, buttons and scrollbar track
--color-text, --color-text-mutedCode text, file name, label, comments and button text
--color-borderBorders and the scrollbar thumb
--color-interactiveButton hover, focus ring, expand link and the highlighted-line border
--color-primaryKeywords, functions, attributes and built-in names
--color-accentStrings, numbers, tags and meta tokens
--radius-m, --radius-sCorner radius of the block, and of buttons and menus
--font-mono, --font-sansCode font and interface font

For each value the order is: the --cb-* property if it is set, then the VB token, then the component's built-in color. With VB loaded, the bridge is what sets the --cb-* properties.

Light or dark is chosen separately. With no theme attribute, the component follows the nearest ancestor with data-mode, then data-theme, data-mode or a dark class on <html> or <body>, then the page's computed color-scheme. It updates when these change.

The bridge sits in a cascade layer, so any rule you write outside a layer wins. To change one block, set the property on it.

code-block[filename="deploy.sh"] { --cb-border-radius: 0; --cb-keyword: var(--color-error); --cb-font-size: var(--font-size-s); }

Accessibility

  • The copy, download and share buttons have ARIA labels, and the copy button's label changes to report success or failure.
  • Buttons show a focus ring. Set its color with --cb-focus-color.
  • Line numbers are hidden from screen readers, so only the code is read.
  • In a group, the tabs use the tablist and tab roles. The left and right arrow keys move between tabs, and Home and End go to the first and last.
