blink-wc

<blink-wc> makes its content blink, as a replacement for the retired <blink> tag that can be paused and stops for reduced motion. Its modes (named looks such as a neon sign or a terminal cursor) take their colors, fonts and corner radius from Vanilla Breeze tokens.

Install

From a CDN. Load both files: the component renders in the light DOM and the script does not add the styles for you.

Or with npm:

npm install @profpowell/blink-wc import '@profpowell/blink-wc'; import '@profpowell/blink-wc/style.css';

Demo

Six modes on a Vanilla Breeze page. None of them sets a color or a font: both come from the theme tokens.

Usage

With no attributes, the content switches fully on and off once a second. behavior="pulse" fades instead, and count stops it after a set number of blinks.

The step engine

A step is one stage of the blink cycle. With behavior="steps", or any step mode, the element moves through its steps during one rate cycle and sets data-step="0", data-step="1" and so on in turn. You style each step with CSS. A plain blink is the two-step case.

With Vanilla Breeze

The component's stylesheet names Vanilla Breeze tokens directly, so a themed page needs no setup. Tokens resolve on each element, so light and dark mode both work.

TokenDrives
--color-accentText of neon, extrude, outline and depth; the cursor of terminal and typewriter; the lit letter in chase.
--color-primaryThe shadow block of extrude, and the fallback when no accent is set.
--color-successThe glow color of crt; text of morse and decode.
--color-warningPanel of warning.
--color-errorPanel of alert.
--color-textText of terminal.
--color-surface-sunken, --color-surfaceBackground of terminal.
--font-mono, --font-sansTypeface of each mode: mono for crt, terminal, morse and decode; sans for the other surface themes and extrude.
--radius-mCorner radius of the panels.

For each value the styles use the first of these that is set: the --blink-* property, then the Vanilla Breeze token, then a built-in default. Text on the warning and alert panels is worked out as black or white from the panel color, so it stays readable with any theme and with your own --blink-bg.

.build-status { --blink-fg: var(--color-success); --blink-min-opacity: 0.4; } .quota-warning { --blink-bg: var(--color-info); }

All the styles sit in the cascade layer web-components, which is one of Vanilla Breeze's own layers. Theme packs can therefore restyle the component, and your unlayered CSS overrides it without !important.

blink-wc or data-effect="blink"

Vanilla Breeze has a CSS-only blink, data-effect="blink", which stops by itself after about five seconds. Use it to draw the eye to one thing once, with no script. Use blink-wc when you need a themed look, letter-by-letter motion, the step engine, script control or events.

Accessibility

Blinking content is a real hazard for some readers, which is why browsers dropped <blink>. Keep blinking areas small and slow: below about three flashes a second, and never across the whole screen.

  • Reduced motion. All animation stops and the text shows in full when the operating system asks for reduced motion, and also when Vanilla Breeze's own setting puts data-motion-reduced on <html>. The change applies at once, with no reload. It keeps blinking only if you set reduced-motion="ignore".
  • Screen readers. The text is read once, as written. The letter and word modes hide their animated pieces from assistive technology and expose a visually hidden copy of the text instead. Content that holds links or other controls is left as you wrote it. The terminal cursor, the typewriter caret and the Morse caption are not announced.
  • Keyboard. With pause-on-hover, the blinking also pauses while focus is on a link or control inside the element.
  • Idle cost. The blinking pauses while the element is off screen and while the tab is hidden.
