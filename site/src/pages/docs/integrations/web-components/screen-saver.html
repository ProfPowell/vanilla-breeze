screen-saver

<screen-saver> covers the page with an animated effect after the visitor has been idle for a set time, and goes away when they move the mouse or press a key. Five of its 17 effects are drawn in the colors and typefaces of the matching Vanilla Breeze theme, and others can use theme colors on request.

Install

Load the component from a CDN with one script tag.

Or install it from npm and import it in your own script.

npm install @profpowell/screen-saver import '@profpowell/screen-saver';

Demo

Each demo is a Vanilla Breeze page with one theme applied and the matching effect. The screen saver starts as soon as the demo loads. Move the pointer over a demo to dismiss it, then hold still for two seconds to bring it back.

Usage

Put one <screen-saver> anywhere in the page. It takes no space until it starts, then covers the whole viewport. The text inside the element is the text the effect shows.

Add palette="theme" to make an effect that normally cycles through rainbow colors use the theme's colors.

Start and stop it from script, and listen for its events.

const saver = document.querySelector('screen-saver'); document.querySelector('#preview').addEventListener('click', () => { saver.activate(); }); saver.addEventListener('screensaver-deactivate', (event) => { console.log(`Shown for ${event.detail.duration} ms`); });

With Vanilla Breeze

The effects read Vanilla Breeze tokens at the moment the screen saver starts. Custom properties inherit into the shadow DOM, so no setup is needed. How much of the theme an effect picks up depends on the effect.

EffectsFollows the theme?
bauhaus, memphis, art-deco, brutalist, kawaiiYes, always. Shapes, backdrop and text all come from tokens. The palette attribute makes no difference.
matrix, starfield, ascii-glitchYes, in part. The falling characters, the stars and the text use tokens. The backdrop stays dark.
bounce3d, fireworks, bubbles, pipes, mystify, plasma, tunnelOnly with palette="theme". Without it they use built-in rainbow colors.
slideshow, snowNo. They show images or their own scene. Only the optional text uses tokens.

The tokens and what they drive:

TokenDrives
--color-primary, --color-accent, --color-success, --color-warning, --color-info, --color-errorThe color set for memphis, and for bounce3d, fireworks, bubbles, pipes and mystify with palette="theme". bauhaus and art-deco each use three of them. plasma and tunnel use the first one or two.
--color-primary-subtle, --color-accent-subtle, --color-success-subtleThe pastel shapes in kawaii
--color-backgroundThe backdrop of the five themed effects
--color-textText in most effects, the blocks in brutalist, the stars in starfield
--color-successThe falling characters and the text in matrix
--font-display, --font-sans, --font-monoThe typeface of the text. Most effects use the display face. brutalist and ascii-glitch use the monospace face.

The fallback order for text color and typeface is: the --screen-saver-* property if you set it, then the Vanilla Breeze token, then a built-in default. --screen-saver-bg, --screen-saver-font-size and --screen-saver-z-index have no Vanilla Breeze token behind them. Without Vanilla Breeze the built-in defaults apply.

screen-saver { --screen-saver-bg: var(--color-surface-sunken); --screen-saver-text-color: var(--color-accent); --screen-saver-font-family: var(--font-mono); --screen-saver-font-size: var(--font-size-3xl); }

Accessibility

  • Every effect checks the visitor's reduced-motion setting (prefers-reduced-motion: reduce) when it starts. With that setting on, the screen saver still appears but shows a still picture or a plain backdrop and does not animate. slideshow stays on its first image.
  • Moving the mouse, pressing a mouse button, pressing any key or touching the screen dismisses the screen saver. Input in the first half second after it starts is ignored, so the movement that started it does not also dismiss it.
  • Mouse, keyboard, touch, scroll and wheel input all count as activity and restart the idle timer.
  • The overlay has the dialog role and the label "Screen saver". It is hidden from screen readers until it starts.
