bg-wc

<bg-wc> draws an animated background behind any HTML content, choosing a WebGL, Canvas 2D or CSS 3D renderer to suit the preset (a named effect). It takes its colors from the Vanilla Breeze --color-* tokens, so it changes with the active theme.

Install

From a CDN. The package has no stylesheet to load. Each preset is a separate file that the element fetches the first time it is used.

To use the data-background attributes instead of the element, load the binder. It imports the element for you.

Or with npm:

npm install @profpowell/bg-wc import '@profpowell/bg-wc'; // Optional: the data-background attribute binder import '@profpowell/bg-wc/data-background';

Usage

Wrap content in the element. The content renders above the background, and the fallback slot holds a still image for when the animation cannot or should not run.

Hero headline

This content sits above the rendered layer.

With the binder loaded, put data-background on an existing element. The binder inserts a <bg-wc> as that element's first child and positions it behind the content.

Squares behind any element

Some presets draw text. Pass it with text, using | to split lines.

Attribute binder

The binder watches the page, so elements added later are bound too. It accepts two spellings, data-background and the shorter data-bg. Use one spelling per element.

AttributeEffect
data-background="name"Sets preset on the inserted <bg-wc>.
data-background-xSets attribute x on the inserted element. Any name works, for example data-background-speed or data-background-mode.
data-background-color-xSets the custom property --bg-wc-color-x, for example data-background-color-1="hotpink".
data-background-skipStops the binder from touching this element.

The module also exports bindDataBackgrounds(root), which scans a subtree on demand, and stopWatching(), which stops the binder from reacting to later page changes.

Events are dispatched on the element and do not bubble.

EventDetailWhen
bg-wc:ready{ preset, renderer }The preset loaded and drew its first frame.

With Vanilla Breeze

Custom properties inherit into shadow DOM, so the element reads the tokens that a Vanilla Breeze theme sets on the page. No setup is needed. Token values written with light-dark() resolve against the element's own color scheme.

TokenDrivesPer-instance overrideBuilt-in default
--color-backgroundBackdrop of the element and of the drawing--bg-wc-color-bgtransparent
--color-primaryFirst tint--bg-wc-color-1#3b82f6
--color-accentSecond tint--bg-wc-color-2#ec4899
--color-infoThird tint--bg-wc-color-3#10b981
--color-textLines and text. The element looks for --color-foreground first; Vanilla Breeze does not define it, so --color-text is used.--bg-wc-color-fg#1a1a1a
--color-success, --color-warning, --color-errorExtra colors for presets that use the status palette, such as confettinone#22c55e, #f59e0b, #ef4444

For each color the element uses the first of these that has a value: the --bg-wc-* property, then the Vanilla Breeze token, then the built-in default. Set the property on one element to change that element only.

.launch-banner { --bg-wc-color-1: var(--color-success); --bg-wc-color-bg: var(--color-surface); --bg-wc-intensity: 0.8; }

Vanilla Breeze has no data-background attribute of its own. The attribute only does something once the bg-wc binder is loaded.

Accessibility

  • Reduced motion. With motion="auto", the default, the element stops animating when the operating system asks for reduced motion (prefers-reduced-motion: reduce). Most presets then draw one still frame. A preset with no still frame shows the fallback slot, so put a static image there.
  • The Vanilla Breeze motion setting. Version 0.5.1 does not read the data-motion-reduced attribute that Vanilla Breeze sets on <html>. If your page offers that setting, set motion="reduce" on the element when it is on.
  • Screen readers. The canvas is marked aria-hidden="true", so only your own content is announced. Give a decorative fallback image an empty alt.
  • Keyboard. The drawing ignores pointer events and takes no focus. Links and controls inside the element work as usual.
  • Idle cost. The animation stops while the element is off screen, while the tab is hidden, and on a low battery.
