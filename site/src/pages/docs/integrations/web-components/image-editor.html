image-editor

<image-editor> lets a visitor crop, rotate, flip, resize and filter an image in the browser, then export it. It reads Vanilla Breeze design tokens and follows the active theme and light or dark mode with no setup.

Install

Load the editor from a CDN with one script tag. Add the second tag only if you use <image-convert>.

Or install it from npm and import it in your own script.

npm install @profpowell/image-editor import '@profpowell/image-editor'; import '@profpowell/image-editor/convert';

Use 0.2.0 or later. Version 0.1.0 could run script hidden in an image's metadata, and 0.2.0 fixes that.

Demo

The editor opens with a photo loaded. Try the crop, rotate and filter tools, then undo. The line under the editor reports the events it fires.

Usage

Load an image and set the export format. The editor is 500 pixels tall unless you set height.

Leave out src to start with an empty drop zone. Content inside the element replaces the default message, and aspect-ratio locks the crop shape.

Drop a cover photo here, or click to choose one.

Read the edited image from script, for example to upload it.

const editor = document.querySelector('image-editor'); editor.addEventListener('image-edit', (event) => { console.log('Edit applied:', event.detail.action); }); const blob = await editor.getBlob('webp', 0.9); const body = new FormData(); body.append('photo', blob, 'photo.webp'); await fetch('/upload', { method: 'POST', body });

Use <image-convert> when visitors only need to change an image's format. They drop a file, pick a format and download the result.

Methods and properties

Members of <image-editor>. The attributes above are also available as properties: src, mode, format, quality, maxHistory, readonly, noToolbar and aspectRatio.

MemberPurpose
loadImage(source)Loads an image from a URL, a File or a Blob. Returns a promise.
crop(x, y, w, h), resize(w, h)Crop to a region, or resize, in pixels.
rotate(degrees), flipHorizontal(), flipVertical()Rotate in steps of 90 degrees, or mirror the image.
applyFilter(name, value), resetFilters()Apply or clear filters. Names and ranges: brightness and contrast 0.5 to 2, saturate 0 to 3, blur 0 to 10 pixels, grayscale and sepia 0 to 100 percent.
undo(), redo(), reset()Step through the edit history, or return to the image as loaded.
zoomTo(level), zoomToFit()Set the zoom, where 1 is 100 percent, or fit the image in the workspace.
getBlob(format?, quality?), getDataURL(format?, quality?)Return the edited image as a Blob (in a promise) or as a data URL.
download(filename?, format?, quality?)Saves the edited image through the browser's download.
imageWidth, imageHeight, hasImage, isDirtyRead-only. The image size in pixels, whether an image is loaded, and whether it has been edited.
canUndo, canRedo, historyLength, zoomLevel, currentToolRead-only. The state of the history, the zoom and the open tool.
sourceFormat, exifDataRead-only. The file type of the loaded image and its EXIF metadata (data a camera stores in the file). The metadata comes from the file, so treat it as untrusted.
supportedFormats, supportsFiltersRead-only. The formats this browser can export, and whether it can apply filters. Where it cannot, the Filters tool is hidden and applyFilter() does nothing.

<image-convert> has the properties mode, format, quality, accept and the read-only supportedFormats, and one method, loadFile(file).

With Vanilla Breeze

The editor reads Vanilla Breeze tokens directly. Custom properties inherit into the shadow DOM, so no setup is needed. Theme and mode changes apply at once, without losing edits.

TokenDrives
--color-surfaceEditor background
--color-surface-raisedToolbar, tool options bar and status bar background
--color-surface-sunkenWorkspace behind the image
--color-border, --border-width-thinBorder color and width
--color-text, --color-text-mutedText; button icons and the status bar
--color-interactive, then --color-primaryAccent color: the active tool, crop border and handles, slider thumbs
--color-text-on-interactive-auto, then --color-text-on-primaryText on accent-colored buttons
--color-hover-bgButton hover background
--focus-ring-color, then --color-focus-ring; --focus-ring-widthFocus outline
--font-sans, --font-size-xs, --font-size-sTypeface and text sizes
--size-3xs to --size-xlPadding, gaps and control sizes
--radius-s, --radius-mCorner radius of buttons and of the editor frame
--duration-fastTransition speed

The fallback order for each value is: the --image-editor-* property if you set it, then the Vanilla Breeze token, then a built-in default. Without Vanilla Breeze the built-in defaults apply.

For light and dark mode the editor looks at data-mode on the nearest ancestor, then the inherited color-scheme, then the system setting. Setting mode="dark" on the editor also sets data-mode on it, so Vanilla Breeze works out its dark tokens for that element. The README notes one limit: Vanilla Breeze 0.5.0 can only scope data-mode="dark" regions, so mode="light" inside a dark page stays dark on that version.

image-editor.avatar { --image-editor-accent-color: var(--color-accent); --image-editor-toolbar-bg: var(--color-surface); --image-editor-border-radius: var(--radius-l); --image-editor-margin: 0; }

Accessibility

  • The README states full keyboard navigation. Version 0.2.0 added keyboard access to the drop zone and the image workspace.
  • Toolbar buttons and inputs have text labels for screen readers, such as "Crop" and "Rotate right 90°".
  • Crop and pan work with touch as well as a mouse.
KeyAction
Ctrl or Cmd + ZUndo
Ctrl or Cmd + Shift + ZRedo
