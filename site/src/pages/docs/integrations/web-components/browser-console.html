browser-console

A web component that captures the page's console calls and shows them in a panel, with color for each log level and value type, tables, timers, groups and stack traces. The Vanilla Breeze stylesheet sets all of its colors from the active theme.

Install

Load the component from a CDN. It is one file with no dependencies and no stylesheet.

Or install it from npm and import it in your own script.

npm install @profpowell/browser-console import '@profpowell/browser-console';

Demo

A console panel on a Vanilla Breeze page. The buttons call console methods in the page, and the panel shows each call.

Usage

Add the element and give it a height. It fills the height of its container, so without one it has no room to show logs. From the moment it is on the page it captures every console call the page makes. The calls still reach the browser's own console.

browser-console { block-size: 25rem; }

To show only entries you choose, turn off capture and add entries yourself.

Methods and properties

MemberPurpose
hookConsole()Starts capturing console calls.
unhookConsole()Stops capturing and restores the original console methods. Also runs when the element is removed.
addLog(entry)Adds an entry. entry is { method, data, timestamp }, where data is an array of values and timestamp is a Date.
clearLogs()Removes all entries.
setFilter(level)Shows one level: 'log', 'info', 'warn' or 'error'. Pass null to show all.
setSearchQuery(text)Shows only entries that contain the text.
setTheme(theme)Sets the theme attribute to 'light' or 'dark'.
copyLogs()Copies the visible entries to the clipboard as plain text. Returns a promise.
getExpansionStates(), restoreExpansionStates(states)Reads and restores which objects and groups are expanded, as a Map.
logsArray of captured entries.
filter, searchQuery, theme, maxLogsCurrent filter level, search text, theme and entry limit.

The component fires no custom events. It captures log, info, warn, error, debug, table, dir, trace, assert, clear, time, timeEnd, timeLog, count, countReset, group, groupCollapsed and groupEnd.

With Vanilla Breeze

A token is a CSS custom property that holds one design value, such as --color-surface. This component does not read VB tokens itself. Each color is a --bc-* property with a built-in dark or light value behind it.

The connection is a token bridge in the VB stylesheet: a rule with the selector browser-console that sets every --bc-* property from a VB token. It ships in vanilla-breeze.css and vanilla-breeze-core.css, so there is no extra file to load and no attribute to add.

VB tokenSet on
--color-surfacePanel background and scrollbar track
--color-surface-raisedHeader, inputs, buttons and table header
--color-hover-bgHover background of rows and buttons
--color-textText, and the accent of log and table entries
--color-text-mutedTimestamps and labels, debug and timer entries, and null values
--color-borderBorders, table borders and the scrollbar thumb
--color-infoinfo entries, numbers and dates
--color-warningwarn entries and their row tint, and booleans
--color-errorerror entries and their row tint, and regular expressions
--color-successStrings
--color-accentFunctions
--color-primaryDOM elements
--color-interactiveActive filter button and focus outline

The order is: the --bc-* property if it is set, then the built-in color for the current theme. With VB loaded, the bridge sets all 34 properties, so the panel follows the VB theme in both light and dark mode. The theme attribute and the theme button in the panel's header then change none of those colors.

Without the VB stylesheet the panel is dark by default and does not follow the page. Set theme="light" for the light palette.

The bridge sits in a cascade layer, so any rule you write outside a layer wins. To change one panel, set the property on it.

browser-console#build-log { --bc-bg-primary: var(--color-surface-sunken); --bc-color-error: var(--color-primary); --bc-value-string: var(--color-text); }

Accessibility

  • The list of entries has role="log" and is a polite live region, so screen readers announce new entries without interrupting.
  • The header is a toolbar with a labeled search field. The filter buttons report which one is active with aria-pressed.
  • Objects, arrays, groups and stack traces can be expanded from the keyboard: move to one with Tab, then press Enter or Space.
  • Transitions are turned off when the reader has asked for reduced motion.
