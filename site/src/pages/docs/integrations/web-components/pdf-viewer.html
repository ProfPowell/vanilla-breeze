pdf-viewer

<pdf-viewer> shows a PDF document in the page with a toolbar for page navigation, zoom, search, thumbnails, download and print. Its toolbar, sidebar and borders read Vanilla Breeze design tokens, so they follow the active theme.

Install

Load the component from a CDN with one script tag. The file is about 2.4 MB because it contains PDF.js.

Or install it from npm and import it in your own script.

npm install @profpowell/pdf-viewer import '@profpowell/pdf-viewer';

Demo

A five-page sample document with the thumbnail sidebar open. Change the site theme to see the toolbar and sidebar change with it.

Usage

Point src at a PDF file. The viewer is 600 pixels tall unless you set a height in CSS.

Open on a given page, fit the page to the width of the viewer, and show the thumbnail sidebar and the search bar.

Load a file the visitor picks, and listen for the event that reports the page count.

Methods and properties

The properties src, page, zoom, mode and view mirror the attributes of the same name and can be set from script.

MethodPurpose
nextPage(), prevPage(), goToPage(n)Move between pages.
getPageCount(), getCurrentPage()Return the number of pages and the current page number.
zoomIn(), zoomOut(), setZoom(level)Change the zoom. setZoom() takes a number or 'fit-width', 'fit-page', 'auto'.
setData(source)Loads a PDF from an ArrayBuffer, a Uint8Array or a File. Returns a promise.
openFile()Opens the browser's file chooser so the visitor can pick a PDF.
download(), print()Download or print the current document. Both return a promise.
search(query), clearSearch()Search the document text, and clear the search.
toggleFullscreen(), toggleThumbnails(), toggleSearch()Turn fullscreen, the thumbnail sidebar and the search bar on or off.

With Vanilla Breeze

The component reads Vanilla Breeze tokens directly. Custom properties inherit into the shadow DOM, so no setup is needed.

TokenDrives
--color-surfaceViewer background
--color-surface-raisedToolbar background
--color-surface-sunkenThumbnail sidebar background
--color-border, --border-width-thinBorder color and width
--color-text, --color-text-mutedText and secondary text
--color-interactiveAccent color
--color-errorThe load error message
--font-sansTypeface
--font-size-2xs, --font-size-xs, --font-size-lText sizes in the toolbar and overlays
--size-3xs, --size-2xs, --size-xs, --size-s, --size-mPadding and gaps
--radius-xs, --radius-s, --radius-mCorner radius of buttons, inputs and the viewer frame
--shadow-s, --shadow-m, --shadow-lShadows

The fallback order for each value is: the --pdf-viewer-* property if you set it, then the Vanilla Breeze token, then a built-in default. Without Vanilla Breeze the built-in defaults apply.

Three of the names the component looks for are not Vanilla Breeze tokens: --color-surface-hover, --font-size-sm and --font-size-base. Button hover backgrounds and most text sizes therefore use the built-in defaults (13px and 14px text) on a Vanilla Breeze page. Set --pdf-viewer-hover-bg and --pdf-viewer-font-size to change them.

The page of the PDF stays white in light and dark mode. This is deliberate and matches how a PDF prints.

For light and dark mode the component watches data-mode, data-theme and a dark class on the page and updates when they change. Set the mode attribute to force one.

pdf-viewer.report { block-size: 32rem; --pdf-viewer-accent-color: var(--color-accent); --pdf-viewer-toolbar-bg: var(--color-surface); --pdf-viewer-hover-bg: var(--color-hover-bg); --pdf-viewer-sidebar-width: 10rem; }

Accessibility

The README has no accessibility notes. The points below come from the code of version 0.2.0.

  • The element adds tabindex="0" to itself so it can take keyboard focus. The shortcuts work while focus is inside the viewer.
  • Every toolbar button has a text label for screen readers, such as "Next page" and "Zoom in".
KeyAction
Right arrow, Down arrow, Page DownNext page
Left arrow, Up arrow, Page UpPrevious page
Home, EndFirst page, last page
+, -Zoom in, zoom out
0Fit to width
Ctrl or Cmd + FOpen or close the search bar
EscapeClose the search bar, or leave fullscreen
