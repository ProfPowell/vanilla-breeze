marquee-wc

<marquee-wc> scrolls its content at a constant speed, as a replacement for the retired <marquee> tag that pauses when asked and stops for reduced motion. Its modes (named looks such as a stock ticker or a news bar) take their colors, fonts and spacing from Vanilla Breeze tokens.

Install

From a CDN. The script is all you need: on first load it adds the component's styles to the page.

The package also ships the same styles as a file. Linking it is optional. It is useful when you want the styles in place before the script runs.

Or with npm:

npm install @profpowell/marquee-wc import '@profpowell/marquee-wc'; // Optional: the same styles as a stylesheet import '@profpowell/marquee-wc/style.css';

With Vanilla Breeze

The component's styles name Vanilla Breeze tokens directly, so a themed page needs no setup.

TokenDrives
--color-surfaceBackground of ticker.
--color-surface-sunkenBackground of code-block.
--color-backgroundBackground of screen-saver, credits and dot-matrix; letter color of invert.
--color-textText of ticker, code-block and credits.
--color-accentText of screen-saver, the lights of dot-matrix, the chips of ransom, and the highlight in pop and chase.
--color-errorBackground of breaking-news.
--color-successText of leet and decode.
--color-text-on-error-auto, --color-text-on-accent-autoText on the breaking-news bar and on ransom chips. These tokens pick black or white to suit the fill.
--font-mono, --font-sans, --font-serifTypeface of each mode: mono for ticker, code-block, dot-matrix, leet and decode; sans for breaking-news, screen-saver and ransom; serif for credits.
--font-size-sText size of ticker and code-block.
--size-xs to --size-3xlGaps, padding and fade widths.
--radius-mCorner radius of code-block.

For each value the styles use the first of these that is set: the --marquee-* property, then the Vanilla Breeze token, then a built-in default. Set the property on one element to change that element only.

.release-ticker { --marquee-bg: var(--color-surface-sunken); --marquee-fg: var(--color-primary); --marquee-gap: var(--size-3xl); }

All the styles sit in the cascade layer web-components, which is one of Vanilla Breeze's own layers. Theme packs can therefore restyle a marquee, and your unlayered CSS overrides it without !important. Because spacing uses the --size-* scale, marquees grow and shrink with the rest of the page.

marquee-wc or data-effect="marquee"

Vanilla Breeze has a CSS-only scroll, data-effect="marquee". Use it for a plain strip of content with no script. Use marquee-wc when you need the same speed whatever the content length, vertical or back-and-forth motion, automatic filling of short content, pausing while off screen, events, or any of the modes.

Accessibility

  • Reduced motion. All motion stops when the operating system asks for reduced motion, and also when Vanilla Breeze's own setting puts data-motion-reduced on <html>. It keeps running only if you set reduced-motion="ignore".
  • Screen readers. Your original content stays in the accessibility tree and is read once. The copies added to make the loop continuous are aria-hidden and inert, and their id attributes are removed.
  • Keyboard. The copies are out of the tab order. With pause-on-hover, the marquee also pauses while focus is on a link or control inside it.
  • Idle cost. The marquee pauses while it is off screen and while the tab is hidden.
