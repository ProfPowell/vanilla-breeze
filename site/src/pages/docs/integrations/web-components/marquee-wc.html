marquee-wc

The <marquee> tag reborn as an accessible, constant-velocity web component — tickers, breaking-news bars, credit rolls, dot-matrix boards, and 15 per-letter motion modes. It renders in light DOM and reads VB --color-*, --font-*, --size-* and --radius-* tokens directly, so no bridge is needed.

Where to find it

  • npm: @profpowell/marquee-wc
  • GitHub: ProfPowell/marquee-wc
  • Live demos: profpowell.github.io/marquee-wc
  • License: MIT

Install

Via CDN — the component is light DOM, so load its stylesheet as well as the script:

Or via npm:

npm install @profpowell/marquee-wc import '@profpowell/marquee-wc'; import '@profpowell/marquee-wc/style.css';

Not currently bundled into Vanilla Breeze. There is no build coupling between the two repos; the interface is purely CSS custom properties.

Demo

A Vanilla Breeze page with a handful of <marquee-wc> modes. Surfaces, text, fonts and spacing all resolve from VB tokens, and text on coloured fills (breaking-news, ransom chips) uses --color-text-on-*-auto to stay readable. Switch the site theme to see them re-skin.

Quick reference

Attribute / APIPurpose
modeSurface theme (ticker, breaking-news, code-block, screen-saver, credits, dot-matrix) or per-letter motion (bounce, wave, ransom, decode, …).
directionleft (default), right, up, down.
behaviorloop (default), slide, alternate.
speedPixels per second (default 50). Velocity stays constant whatever the content length.
unitletter (default) or word — granularity for motion modes.
pause-on-hoverPause on hover and on keyboard focus.
fadeMask the leading and trailing edges.
reduced-motionrespect (default) or ignore.
.start() / .stop() / .toggle()Legacy <marquee>-compatible playback control.
--marquee-gap, --marquee-fade-sizeSpacing overrides. Default to VB --size-* tokens.
--marquee-bg, --marquee-fgColour overrides for the themed modes. Beat the VB tokens.

Fires marquee-start, marquee-pause and marquee-cycle. See the API reference for everything else.

VB integration

  • Tokens: themed modes read --color-surface, --color-background, --color-text, --color-accent, --color-error, --font-mono/-sans/-serif, --radius-m, and the --size-* scale. A --marquee-* override wins; otherwise the VB token applies; otherwise a built-in fallback.
  • Cascade layer: all styles live in @layer web-components, so they slot into VB's layer order and theme packs can restyle marquees.
  • Spacing: because gaps and paddings use --size-*, data-fluid and the a11y-large-text theme scale marquees along with the rest of the page.
  • Reduced motion: both prefers-reduced-motion and VB's <html data-motion-reduced> toggle stop all motion, including the JS-driven decode scramble.

Requires marquee-wc 1.7.0 or later; earlier versions predate the layer, spacing-token and motion-toggle support.

marquee-wc or data-effect="marquee"?

VB's built-in data-effect="marquee" is a CSS-only scroll for a simple strip of content. Reach for marquee-wc when you need constant velocity regardless of content length, vertical or alternating motion, auto-fill clones, off-screen pausing, playback events, or the themed and per-letter modes.
