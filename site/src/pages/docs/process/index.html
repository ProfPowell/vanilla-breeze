The approach

Every stage of a project produces HTML. The plan is a set of pages. The prototype is the real page with placeholder content. The design system is a theme and the pages that describe it. Nothing is drawn in one tool and rebuilt in another, so work done at one stage is still there at the next.

The library covers the middle of that sequence itself. Two companion packages, published separately and built on the same tokens, cover planning and design-system documentation.

The stages and their tools

Stage What you make Tool Comes from
Plan Personas, user stories, a board, a roadmap, a risk register and decision records, as pages in the project Planning elements such as <user-story> and <kanban-board>. For structure, <site-map> and <flow-diagram> The @profpowell/vb-project-planning package. The two structure elements are in Vanilla Breeze
Prototype The real markup, filled with placeholder images and text, shown as a sketch until the layout is agreed data-mock, data-lorem, data-wireframe, data-loading="skeleton" Vanilla Breeze. Wireframe mode is in the development add-on
Design system A theme, and pages that show its colors, type, spacing and components Themes and tokens, then specimen elements such as <token-specimen> and the theme tools Themes and tokens are in Vanilla Breeze. Specimens and tools are in @profpowell/vb-design-system
Hand off The theme as a file other design tools can read A DTCG token file for every bundled theme, and export and import elements Token files are in Vanilla Breeze. The elements are in @profpowell/vb-design-system
Debug A page that works The data-debug check, the browser's own tools and the troubleshooting guide Vanilla Breeze development add-on

The stages overlap. A prototype usually starts before the plan is finished, and a theme usually starts as a few token overrides in the prototype.

One page, from sketch to finished

The demo is one section of markup. The control changes the value of data-wireframe on it and nothing else. The sketch and the finished page are the same elements, so a layout agreed on the sketch does not need to be built again.

Prototyping explains each level and how to switch between them.

What is handled and what you provide

Area The library or package handles You provide
Planning Elements that lay out a persona, a story, a board, a schedule or a matrix from plain markup, in the page's theme The content, and the habit of editing it as the project changes
Placeholder content A labelled box for any image, video, frame or canvas, and filler text by word, sentence or list item Real content before release, and the removal of the placeholder attributes
Wireframe mode A sketch rendering of your markup at three levels of detail, with labels and review notes The decision about when to stop sketching. Leave the development add-on out of the released site
Design system Tokens, themes, and specimens that read the live token values, so the documentation cannot drift from the theme The brand decisions, and the written guidance on how to use them
Token exchange A DTCG file beside every bundled theme, and elements that export and import the format A check of the result in the other tool
Debugging A check on the structure of cards that outlines the element at fault and logs a warning, and a list of known symptoms with their causes The browser's developer tools, and a small page that reproduces the problem

What to load

The tools on these pages are not all in the main bundle. The file names are relative to dist/cdn/ in the vanilla-breeze package.

Feature Files npm import
data-mock, data-lorem vanilla-breeze.css and vanilla-breeze.js. With the core bundle, add packs/prototype.full.css and packs/prototype.full.js vanilla-breeze/prototype-css, vanilla-breeze/prototype-js
data-loading="skeleton" Any Vanilla Breeze stylesheet vanilla-breeze/css
data-wireframe, data-debug, VanillaBreeze.wireframe, VanillaBreeze.mock vanilla-breeze-dev.css and vanilla-breeze-dev.js vanilla-breeze/dev-css, vanilla-breeze/dev-js
Planning elements A separate package @profpowell/vb-project-planning
Specimens and theme tools A separate package @profpowell/vb-design-system

Load the add-on while you work and remove both lines before release.
