CSS Shapes: Advanced

Cutouts (evenodd), shaped borders (two-layer technique), and shape morphing animations.

Cutouts

Using data-cutout with the evenodd fill rule to punch shapes through elements. The hole also removes the element's own content, so each label sits in the caption.

Shaped Borders

Using data-border-shape: a ::before layer paints the border colour across the shape and the image is clipped to the same shape --shape-border inside it. The last frame wraps a link: tab to it and the border turns to the focus-ring colour.

Shape Animation

Using data-morph for keyframe morphing between matching-point shapes. One cycle by default; the last card adds data-morph-loop, which pauses on hover and while focus is inside. Respects prefers-reduced-motion.
