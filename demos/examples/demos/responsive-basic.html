data-responsive

Each placeholder prints its own size in the corner, so you can see which candidate the browser picked. Resize the window and reload: sizes follows the rendered width.

Measured sizes (srcset in markup)

The srcset is written in the markup, so the browser can choose from it while parsing. data-responsive measures the rendered width and writes it to sizes.

Srcset shorthand

data-responsive="400,800,1200" on responsive.svg generates responsive-400.svg 400w, responsive-800.svg 800w, responsive-1200.svg 1200w. The script runs after the parser has requested src, so this costs a second request; write srcset in markup when that matters.

In a grid

Narrow grid cells measure narrow, so the small candidate is enough.
