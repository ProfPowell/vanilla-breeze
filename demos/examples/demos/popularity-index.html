Popularity Index

The aggregated counterpart to <recently-visited>. Fetches a { pages: […] } payload from any compatible endpoint; the default is /api/analytics/popular.

Live endpoint

On the deployed site this reads /api/analytics/popular, a Pages Function over the D1 analytics hits. Anywhere the endpoint is missing (local preview, a site without analytics) the panel settles to data-state="unavailable" and shows a short generic note; sites can hide that state with CSS.

With a stub payload

Pointing analytics-src at a hand-authored JSON shows what the rendered list looks like once the endpoint exists.

Nested heading level

Inside a section that already has an <h2>, set data-heading-level="3" (or 0 for no heading).
