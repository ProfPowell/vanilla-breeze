Callout Blocks

The default parser turns :::type … ::: blocks into styled callouts. No extra import is needed.

# Callout Blocks

Callouts come in five types. Text after the type replaces the default title:

:::warning
**Careful!** This action cannot be undone. Make sure you have a backup before proceeding.
:::

:::info
The markdown-viewer component loads `marked` as its default parser. GFM is enabled by default.
:::

:::tip
Use the `highlight` attribute to fire per-block events for syntax highlighting integration.
:::

:::danger Trust boundary
Never set `sanitize="off"` on markdown that users or other origins can influence.
:::

:::note
Each callout is an `aside` with `role="note"` and a visible title, so its kind is not conveyed by colour alone.
:::

## Regular Content

Paragraphs, **bold**, *italic*, and `code` still work as expected alongside callouts.
