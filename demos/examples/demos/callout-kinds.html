Callouts

Kinds

Note

The default kind. A bare data-callout looks the same.

Info

Background context the reader may want.

Tip

A shortcut or a better way to do something. Links stay focusable.

Warning

Something that can go wrong if ignored.

Danger

Data loss, security or anything that cannot be undone.

Shapes

A speech callout: the tail is painted behind the text, so nothing is clipped.

Notched info

A kind and a shape combine in one token list. The bevel follows --shape-bevel.
