Getting Started

Hover over any heading to see the anchor link icon appear. Click to copy the link to your clipboard.

Installation

Install the package using your preferred package manager.

Configuration

Configure the component by setting data attributes.

Features

The heading-links component adds clickable anchor links to all matching headings.

Auto-generated IDs

Headings without IDs get them automatically based on their text content.

Accented letters are kept: this heading's ID is café-crème.
