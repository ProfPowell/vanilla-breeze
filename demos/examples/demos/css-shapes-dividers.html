Section Edges — Bottom Only

Using data-shape-end on sections to clip the bottom edge.

Wave bottom edge

data-shape-end="wave"

Chevron bottom edge

data-shape-end="chevron"

Scallop bottom edge

data-shape-end="scallop"

Diagonal bottom edge

data-shape-end="diagonal"

Section Edges — Top Only

Using data-shape-start on sections to clip the top edge.

Wave top edge

data-shape-start="wave"

Chevron top edge

data-shape-start="chevron"

Scallop top edge

data-shape-start="scallop"

Diagonal top edge

data-shape-start="diagonal" (mirrors in right-to-left pages)

Section Edges — Mixed Start and End

Any start shape combines with any end shape on one element. The padding on each shaped side always matches the clip depth, so the text below stays clear of the edge on narrow screens too.

Diagonal top, wave bottom

data-shape-start="diagonal" data-shape-end="wave"

A link near the shaped edge keeps its full focus ring.

Scallop top, chevron bottom

data-shape-start="scallop" data-shape-end="chevron"

Custom Depth

Override --shape-depth to control how dramatic the edge shape is.

Subtle wave

--shape-depth: 1.25rem

Dramatic wave

--shape-depth: clamp(3rem, 10vw, 7rem)
