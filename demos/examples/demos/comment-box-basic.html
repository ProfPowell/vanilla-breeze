comment-box

Form-associated comment form composing <markdown-editor>. Submit fires comment-box:submit; the first box hands a mock request to waitUntil(), which fails every other time so you can see the text kept for a retry.

Default — top-level comment form

Edit mode — pre-filled value, with Cancel

Length-limited (280 chars) with toolbar slot

Inside a parent <form> (form-associated)
