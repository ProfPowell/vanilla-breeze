When to use which

<bdi>
User-generated content, database values, API responses — any text whose direction you don't control.
<bdo>
Forcing character order — reversed text, or showing right-to-left text in its storage order. Not needed to embed right-to-left text in running prose; the bidirectional algorithm handles that.
