Level 4: Token-Driven Elements

Elements and components read tokens via var(), so the same markup, with no styling classes, produces different results per theme.

data-theme="swiss"

New

The badge, the buttons and the link all take their colour from the theme’s primary token: Swiss red, sharp corners.

data-theme="cyber"

New

Same markup, but now the primary token is cyan and the radius, type and surface come from Cyber.
