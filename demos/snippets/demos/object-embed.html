Object and Embed

<object> — SVG with fallback

width/height are the fallback size; data-ratio="4:3" keeps the box in proportion when the container is narrower than 400px.

<object> — HTML document in a ratio box

The data-media wrapper sets the ratio; the object fills it. Embedded HTML runs with no sandbox — prefer <iframe sandbox> for anything you don't control.

<embed> — SVG (no fallback)

<embed> is a void element — no fallback content possible. Prefer <object> or semantic alternatives.

Prefer modern alternatives

  • <img> for images (including SVG)
  • <svg> for inline vector graphics
  • <video> for video content
  • <audio> for audio content
  • <iframe> for embedded pages
