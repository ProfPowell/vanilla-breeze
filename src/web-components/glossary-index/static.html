Glossary

Without JavaScript this is a plain, linkable glossary: the jump links scroll to each letter and every term has its own fragment id.

  1. A
  2. P
  3. S

A

accessibility
a11y
Making content usable by everyone, including people using assistive technology.
attribute
A name–value pair in markup that configures an element.

P

progressive enhancement
Start with working HTML, then layer CSS and JavaScript on top.
See also semantic HTML.

S

semantic HTML
Using elements for their meaning, not their default appearance.
